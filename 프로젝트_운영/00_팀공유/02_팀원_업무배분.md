# 팀원 업무 배분

> 출처: `4인_팀_업무배분_기준`. 실명 적용본. 역할 매핑은 [역할책임분담표 RACI](../../산출물/00_프로젝트관리/역할책임분담표_RACI.md)와 일치한다.
> 현재 제품은 DL-018 이후 **하모니(harmony) 악기 합주 미니앱**이다. 아래 배분은 2026-06-22 `review/fullstudio` 통합 상태를 기준으로 한다.

## 1. 배분 원칙

1. 모든 작업에 `사람 책임자 1명`, `실무 수행자 1명`, `검토자 1명`을 지정한다.
2. 같은 사람이 구현과 최종 승인을 동시에 맡지 않는다.
3. 한 사람의 동시 작업은 `주 작업 1개 + 검토 1개`로 제한한다.
4. 문서 전담 인력을 두지 않는다. 기능 책임자가 관련 설계·테스트 문서를 함께 갱신한다.
5. AI는 수행·검토를 보조하지만 일정·위험 수용·병합·배포·완료 판정은 사람이 책임진다.
6. 30분 이상 막힌 문제는 혼자 붙잡지 않고 [00_진행사항](00_진행사항.md) 차단 이슈에 올린다.
7. 작업은 4~8시간 안에 검증 가능한 TASK로 나눈다.

## 2. 역할 (실명)

| 구분 | 이상혁(A) | 곽소정(B) | 김민혁(C) | 양록빈(D) |
|---|---|---|---|---|
| 주 역할 | 팀장·제품·정책·통합 | UX·프런트엔드 | 백엔드·데이터·보안 | QA·DevOps·릴리즈 |
| 핵심 책임 | 범위·우선순위·정책·수락 기준·발표 | Figma·미니앱 UI·접근성·사용자 흐름 | API·DB·인증·권한·데이터 무결성 | 테스트·CI/CD·배포·증거·시연 |
| 주 사용 AI | ChatGPT Pro + Claude Code | Claude Code + Codex | Claude Code + Codex | Codex + Claude Code + ChatGPT Pro |

- **이상혁(A):** 범위·문제·우선순위·WBS·회의 진행. 앱인토스 정책·제출 요건을 수락 기준으로 변환. 전체가 하나의 사용자 흐름으로 이어지는지 최종 확인. 발표·시연·종료보고서 총괄. 관리자 화면·설정·콘텐츠 등 경계가 명확한 구현도 가능.
- **곽소정(B):** Figma 화면·컴포넌트·상태별 UI·오류/빈 화면·접근성. 핵심 사용자 흐름 구현. API 계약 소비자 관점 검토. 프런트 단위테스트·사용자 매뉴얼 초안. (보안 역량 보유 → 인증·권한·개인정보·신고 2인 교차검토 참여.)
- **김민혁(C):** API·테이블·상태 전이·인증·권한·입력 검증·감사 로그. 중복 요청·경쟁 조건·데이터 무결성·개인정보 삭제 경로 검토. 서버 배포 설정·마이그레이션을 양록빈과 확정. 곽소정과 API 계약 조기 고정.
- **양록빈(D):** 테스트 전략·단위/통합 계획·결과·결함 분류. CI·빌드·환경 분리·배포·스모크·롤백. 출시 후보 판정표·증거. 실기기 시연·영상 백업·발표 복구 시나리오.

## 7. 일일 운영

1. 팀원은 팀장 미팅 전 [00_진행사항](00_진행사항.md) 본인 행 갱신.
2. 팀장(이상혁)은 09:05 보고에 `어제 완료`·`오늘 계획`·`차단 이슈`만 가져간다.
3. 팀 미팅 30분 이내, 결정은 회의록·진행사항에 반영.
4. TASK는 사람 배정 후 Claude/Codex 실행, 다른 계열 AI 교차검토.
5. 작업 종료 전 [01_인수인계](01_인수인계.md)가 다음 사람이 바로 실행 가능한지 확인.
6. 완료 판정은 AI 합의가 아니라 실제 팀원의 증거 확인 후.
