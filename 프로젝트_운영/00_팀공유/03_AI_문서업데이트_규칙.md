# AI의 팀 공유 문서 업데이트 규칙

## 1. 목적

Claude Code, Codex, ChatGPT Pro가 세션 초기화와 담당 변경에도 동일한 프로젝트 상태를 유지하도록 `00_진행사항.md`와 `01_인수인계.md`를 공통 운영 인터페이스로 사용한다.

## 2. 세션 시작 시

모든 에이전트는 다음 순서로 읽는다.

1. `프로젝트_운영/00_팀공유/00_진행사항.md`
2. `프로젝트_운영/00_팀공유/01_인수인계.md`
3. `프로젝트_운영/00_팀공유/02_팀원_업무배분.md`
4. `프로젝트_운영/00_현재상태/`의 기술 현황
5. 현재 TASK 작업패킷과 관련 산출물

읽은 뒤 실제 Git 상태와 문서가 다르면 문서를 임의로 믿지 않고 diff, 로그, 테스트 결과를 확인한다.

## 3. 업데이트 의무가 발생하는 시점

- TASK를 시작하거나 담당자가 바뀔 때
- 상태가 `진행 중`, `AI 검토`, `사람 확인`, `완료`, `차단`으로 바뀔 때
- 테스트·빌드·배포 결과가 새로 생길 때
- P0·P1 결함 또는 주요 의사결정이 생길 때
- 교차검토 쟁점이 열리거나 닫힐 때
- 세션을 종료할 때
- 팀 미팅 전후

단순 조사, 오탈자 확인, 읽기 전용 검토처럼 프로젝트 상태가 바뀌지 않은 경우에는 변경 이력 한 줄만 남기기 위해 문서를 억지로 수정하지 않는다.

## 4. 문서별 쓰기 책임

### `00_진행사항.md`

- Claude Code: 구현·통합 상태, 변경 근거, 다음 행동을 갱신한다.
- Codex: 본인이 수행한 구현·검증 또는 교차검토 결과를 갱신한다.
- ChatGPT Pro: 요구사항, 위험, 일정, 출시 판정 변경안을 작성한다. 저장소 접근이 없으면 적용 가능한 정확한 수정 블록을 반환한다.
- 사람: 역할, 목표일, 범위 변경, 위험 수용, 최종 완료를 승인한다.

### `01_인수인계.md`

- 마지막으로 쓰기 작업을 수행한 주체가 초안을 작성한다.
- 구현자는 변경 파일, 실행 명령, 남은 작업을 기록한다.
- 검토자는 열린 쟁점과 재검증 조건을 기록한다.
- 인수자는 `사람 확인 전용` 구역에서 실제 인수 여부를 확정한다.

## 5. 수정 방식

1. 문서 전체를 다시 쓰지 않고 변경된 표 행과 섹션만 수정한다.
2. 기존 사람 메모와 승인 기록을 삭제하거나 축약하지 않는다.
3. 모든 상태 변경에는 시각, 갱신자, 근거 링크를 남긴다.
4. `완료`, `통과`, `배포됨`은 실행 로그 또는 사람이 확인한 증거가 있을 때만 사용한다.
5. 실행하지 않은 검증은 `Not Run`, 확인되지 않은 상태는 `확인 전`으로 적는다.
6. 완료율을 추측하지 않고 `완료 수 / 전체 수`로 기록한다.
7. 비밀값, 토큰, 실제 개인정보, 개인 연락처는 기록하지 않는다.
8. AI는 `HUMAN_APPROVAL_START`와 `HUMAN_APPROVAL_END` 사이를 수정하지 않는다.

## 6. 동시 수정 방지

- 한 시점에 팀 공유 문서의 주 편집자는 한 명만 둔다.
- 구현 중에는 주 작성 에이전트가 갱신하고, 교차검토자는 검토서에 먼저 기록한다.
- 검토 결과가 확정되면 주 작성 에이전트가 팀 공유 문서에 반영한다.
- 충돌이 발생하면 최신 파일을 기준으로 사람 기록을 보존하며 수동 병합한다.

## 7. 세션 종료 트랜잭션

세션을 끝내기 전에 다음을 하나의 묶음으로 처리한다.

1. 현재 TASK 결과와 증거 갱신
2. `00_진행사항.md` 갱신
3. 기존 `01_인수인계.md`를 `인수인계_이력/HANDOFF-YYYYMMDD-HHMM.md`로 복사
4. `01_인수인계.md`를 최신 상태로 교체
5. 기술용 `프로젝트_현황판.md`와 `최신_인수인계.md` 동기화
6. `node tooling/scripts/팀공유문서_검증.mjs` 실행

검증에 실패하면 성공했다고 기록하지 않고 누락 항목을 남긴다.

## 8. 사람에게 보여줄 업데이트 형식

AI의 세션 종료 보고는 다음 네 줄을 우선 제공한다.

- 완료: 실제로 완료한 작업
- 검증: 실행 명령과 결과
- 남은 위험: 차단·미검증·결정 대기
- 다음 행동: 담당자와 첫 실행 단계
