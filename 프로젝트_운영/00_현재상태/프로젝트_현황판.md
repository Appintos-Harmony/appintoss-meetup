## 출시 전 필수 확인

- `apps/miniapp/granite.config.ts`: `appName='meetup-lite'`는 임시값. 하모니 앱 등록 후 실제 등록 ID로 교체.
- `apps/miniapp/.env`: `VITE_API_BASE=https://3.39.167.74.nip.io` 주입 없이 빌드하면 기기에서 공유 API가 `localhost`로 향함.
- `apps/miniapp/src/lib/identity.ts`: 현재 crypto 128bit 난수 폴백(약한 해시 제거). 실제 앱인토스 WebView 출시 전 `getAnonymousKey` 교체 필요(TASK-20260622-033).
- `산출물/06_테스트/앱인토스_실기기검수표.md`: RT-01~15는 사람 폰으로 Pass/Fail 기록 필요.
- `.claude/launch.json`: 옛 머신 경로(`C:/Users/DEV-PC/...`)가 남아 있어 VS Code `dev:web` 실행이 깨짐. 현재 경로로 교체 필요(기록물 13개의 `DEV-PC` 언급은 역사라 보존).

## 운영 스크립트

- `node tooling/scripts/세션_시작_컨텍스트.mjs` — 세션 시작 상태 출력.
- `node tooling/scripts/검증_전체.mjs` — 하네스 기본 검증.
- `npm --prefix apps/miniapp test` — 단위 테스트.
- `npm --prefix apps/miniapp run build:web` — 웹 빌드.
