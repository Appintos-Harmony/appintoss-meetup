# 프로그램 목록 (하모니)

> 실제 소스 기준. 미니앱(`apps/miniapp`) + 백엔드(`apps/api`).

## 미니앱 — 화면/진입
| 파일 | 역할 |
|---|---|
| `src/main.tsx` | 진입점. `TDSMobileAITProvider`로 앱 래핑. |
| `src/App.tsx` | 라우터(홈/스튜디오/설정) + 온보딩 게이트(닉네임 없으면 온보딩). |
| `src/theme.css` | 라이트 테마 토큰(TDS 정렬, DL-019 100% 라이트). |
| `src/routes/Onboarding.tsx` | 닉네임 입력 + getAnonymousKey(가입/로그인 아님). TDS Button. |
| `src/routes/Home.tsx` | 인사 + 최근 곡(localStorage) 목록·열기·삭제. TDS Button. |
| `src/routes/Studio.tsx` | 연주·녹음·메트로놈·저장·공유·받기·얹기·합주듣기 통합 화면. |
| `src/routes/Settings.tsx` | 최소 설정(고객센터=토스 공통). |

## 미니앱 — 도메인 로직
| 파일 | 역할 |
|---|---|
| `src/audio/chordReducer.ts` | **순수함수 reducer**: tick 이벤트 기록(중복 noteOn 금지·전환 off/on·터치 우선·200ms 제스처 재개). 단위테스트 7/7. |
| `src/audio/chordReducer.test.ts` | reducer 단위테스트(vitest). |
| `src/audio/engine.ts` | Tone.js 합성: AudioContext unlock·음색·코드 on/off·메트로놈 클릭·합주용 트랙별 보이스. |
| `src/audio/transport.ts` | Tone.Transport 클럭: BPM/박자·메트로놈·tick↔ms 변환. |
| `src/audio/gesture.ts` | MediaPipe HandLandmarker: 카메라·손 위치→코드존·편손/주먹 판정. |
| `src/lib/identity.ts` | getAnonymousKey(mock fallback)·닉네임 저장. |
| `src/lib/storage.ts` | 로컬 곡 저장/목록/삭제(localStorage). |
| `src/lib/share.ts` | 합주 백엔드 클라이언트(생성/조회/얹기)·클립보드·프리로드 폴백. |

## 백엔드
| 파일 | 역할 |
|---|---|
| `apps/api/server.mjs` | node:http+node:sqlite 무의존 API. `GET /healthz`·`POST /sessions`·`GET /sessions/:code`·`POST /sessions/:code/tracks`. |
| `apps/api/deploy/*` | systemd(`harmony-api.service`)·nginx·certbot·`deploy.sh`(배포 스크립트). |

## 설정·빌드
| 파일 | 역할 |
|---|---|
| `apps/miniapp/granite.config.ts` | 앱인토스 앱 설정(appName·brand·permissions camera). |
| `apps/miniapp/vite.config.ts` | Vite + React + React 단일화(dedupe, TDS 중복 방지). |
| `apps/miniapp/.env` | `VITE_API_BASE`(백엔드 URL, gitignore). |
