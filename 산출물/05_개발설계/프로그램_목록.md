## 미니앱 · 도메인 로직
| 파일 | 역할 |
|---|---|
| `src/audio/engine.ts` | **오디오 엔진 v2**: setVoice·28코드 buildChord(통일 옥타브)·downChord/downNote·triggerHit·createVoice(time 인자)·audioNow. 실제 샘플(Sampler/Buffer)+합성 폴백·드럼킷·음량. **lookAhead 0.02(라이브 지연↓ ≈20ms)·오디오 클럭 샘플정확 스케줄**. |
| `src/audio/events.ts` | 이벤트 계약 v2: `NoteEvent`(코드/멜로디/드럼) + `normalizeEvents`(하위호환)·drumKey. |
| `src/audio/chordReducer.ts` | 순수 reducer: tick 이벤트(중복 금지·전환·터치우선·폴리포니·드럼 hit). |
| `src/audio/transport.ts` | Tone.Transport 클럭: BPM/박자·메트로놈·tick↔ms. |
| `src/audio/gesture.ts` | MediaPipe HandLandmarker(양손·존/2D키트·손바닥/손가락·facingMode) + **FaceDetector(헤드뱅잉용 얼굴중심, 베스트에포트)**. |
| `src/audio/gestureFx.ts` | 제스처 효과음: 손 흔들기(flutter)→탬버린·박수→박수·헤드뱅잉→귀여운 + handWaving(1명 연주 겹침 방지). |
| `src/audio/tuning.ts` | (김민혁 029) 평균율 A4=440 음정 단일 진실원. import만. |
| `src/lib/notes.ts` | 음 이동(transpose)·한글 계이름(solfa) · 지판/에디터용. |
| `src/lib/noteEdit.ts` | 음 편집 핵심: 이벤트↔편집노트 변환·퀀타이즈(순수, 테스트). |
| `src/lib/settings.ts` | 개발자 모드·**제스처 효과음 on/off** 플래그(localStorage). |
| `src/lib/identity.ts` | getAnonymousKey 2트랙(토스 실호출 / 브라우저 익명 폴백, 머지 f506717)·닉네임·**이모지 프로필**(getEmoji/EMOJI_CHOICES) 저장. |
| `src/lib/storage.ts` | 로컬 곡 저장/목록/삭제(localStorage). |
| `src/lib/likes.ts` | 커뮤니티 좋아요(로컬 토글 + 결정적 기본수). 실제 networked 집계는 후속. |
| `src/lib/share.ts` | 합주 백엔드 클라이언트(생성/조회/얹기)·클립보드·핑·프리로드 폴백. |
