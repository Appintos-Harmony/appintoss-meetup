## 3. 오디오 엔진 v2
- **28코드:** `buildChord(root,quality)` = 7루트 × 4종류(maj/m/7/m7). 실제 음정은 `voiceFreqs`가 **통일 옥타브**로 산출(루트 음정클래스+인터벌). tuning의 `CHORD_NOTES`는 코드마다 옥타브가 달라(C·D=4, E~B=3) 진행이 들쭉날쭉 → 엔진에서 통일(피아노/기타 = 옥타브3 트라이어드).
- **악기×스타일:** 피아노/기타/베이스/드럼 × 2스타일. 화면 동일·소리만(`setVoice` 단일 수렴).
- **실제 샘플 + 합성 폴백:** 악기별 실제 녹음 샘플을 `Tone.Sampler`(피치악기)·`Tone.ToneAudioBuffer/ToneBufferSource`(드럼)로 로딩. **로딩 전/실패 시 합성(PRESETS/makeDrumKit)으로 폴백 → 항상 소리는 남.** 음원 출처는 §8.
- **베이스 분리:** 코드모드는 **근음만**(옥타브2, velocity 0.4로 작게 = 째짐/과음 방지), 멜로디(지판)는 실제 베이스기타 튜닝(E1·A1·D2·G2) 그대로·음량 키움.
- **드럼:** 8피스(크래시·하이햇·라이드·하이탐·미드탐·스네어·킥·플로어탐). 킥/스네어/하이햇/탐은 실제 킷 샘플, 크래시/라이드는 합성. 출력 게인 `Tone.Volume(+9)`로 보강.
- **음량 밸런스(실기 청취 튜닝):** SAMPLE_VOLUME piano 0 / guitar −7 / bass −6 / drum 0(+drumOut), PRESET_VOLUME(폴백·예시) piano −1 / guitar −9 / bass −8 / drum 3. 기타를 기준으로 피아노·드럼·베이스 상향.
- **리듀서:** `chordReducer`에 드럼 `hit` 액션 추가(off 없이 1이벤트). 멜로디 폴리포니(`poly`)는 029 유지.

## 4. 입력 UI
- **28코드 매트릭스(`ChordMatrix`):** 7×4, 최대 6선택, 빠른 팝 4코드 프리셋, n/6 카운터.
- **악기/스타일 콤보(`InstrumentCombo`):** 바텀시트, 악기→스타일 종속. 스타일명 = 피아노 1/2·기타 1/2·베이스 1/2·드럼 1/2.
- **멜로디 피아노 건반:** 흰7+검5, 옥타브 이동, 한글 계이름.
- **기타/베이스 패드(`NotePadGrid`):** **크로매틱(한 칸=반음)** 계이름 패드(실제 지판 X). 일반 6프렛 / 전체화면 13프렛, 가로 스크롤. 개방현 = 실제 튜닝.

## 5. 카메라 제스처
- MediaPipe HandLandmarker. **한 손/양손 토글**(numHands 2, 루프에서 1/2 제한).
- **코드:** 수평 존(일반 4 / 전체화면 6). 손바닥(편손)/손가락(검지) 인식 모드. 양손 = 두 코드 동시(직접 발음+녹음 적재). 현재 울리는 코드 **색 하이라이트**.
- **드럼:** 가라지밴드 SoCal풍 **2D 드럼킷 8모양**, 손을 모양 위로 가져가 타격(가장 가까운 모양, 상승엣지 1타). 타격 시 모양 **번쩍**. 양손 = 양손 드럼.
- **카메라 컨트롤:** 전체화면·**가로 회전(CSS 90°)**·손바닥/손가락·줌(±)·전·후면 전환. 컨트롤바는 어두운 띠+파란 `‹ 나가기`로 또렷.
- 음정/존 매핑은 거울(전면) 보정.
