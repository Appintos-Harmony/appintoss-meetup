## 9. 디자인 컨셉 가드 (필수 — 기존 토스급 룩 깨지지 않게)
기존 `apps/miniapp/src/theme.css`(DL-019: **100% 라이트**)의 **디자인 토큰·클래스를 그대로 재사용**한다. 새 색/폰트/라운드/그림자/디자인 언어를 **새로 만들지 않는다.** 신규 화면도 기존 온보딩/홈/스튜디오와 시각적으로 이어져야 한다.

- **색:** `--blue #3182f6` · `--bg #f2f4f6` · `--surface #fff` · `--text #191f28` · 서브 `--sub`. 트랙 구분은 **시그니처 컬러** `--t-blue/coral/mint/violet/amber`.
- **폰트:** Pretendard. 타이포 `.t-display/.t-title/.t-body/.t-cap`.
- **모양·그림자·모션:** 라운드 `--r-sm~xl`(12~24px), elevation `--e1~e3`·`--e-inset`, 모션 `--spring`(bounce)·`--ease`.
- **신규 컴포넌트는 기존 클래스 확장(새 룩 금지):**
  - 연주 패드(28코드·계이름 패드블록·드럼 패드) = **`.pad`**(OP-1풍 입체, 눌림 `data-on="true"`). 동일 촉각감 유지.
  - 모드/입력 토글([코드|멜로디], [터치|제스처]) = **`.segment`/`.seg`**.
  - 코드 칩·빠른 프리셋 = **`.chip`/`.chip-ghost`**.
  - 악기▾/스타일▾ 콤보·받기/음색 선택 = **`.sheet`/`.backdrop`/`.sheet-row`**(바텀시트).
  - 커뮤니티 곡 카드 = **`.card`**, 트랙 아바타 = **`.track-av`**(재생 시 `bounce`), 셸 = **`.screen/.appbar/.content`**, CTA = **`.btn`**, 입력 = **`.input`**.
- **금지:** 다크모드(심사 리스크), 새 폰트·색 팔레트 도입, 자체 뒤로가기 UI, 핀치줌(off 유지), 과한 애니메이션(데모 안정·Tone 스레드 경합 방지 — `scale(.95~.97)`+`--spring` 수준).
- **새 토큰이 꼭 필요하면** theme.css에 변수로 추가 제안만 하고 김민혁/조장과 합의(임의 인라인 스타일 남발 금지).
