# TASK-20260620-016 · 서비스 기능 정의서 및 요구사항 추적표 작성

## 1. 배경과 문제
PRD(develop 머지 `5888cbf`)에 FR-001~014·NFR-001~005·POL-001~004가 정의됐으나, 각 요구사항이 화면·API·테이블·테스트로 추적되지 않는다. Gate 1(기획·설계)은 "모든 MVP 기능에 요구사항 ID·수락 기준"과 추적성을 요구한다(CLAUDE.md §10·§18).

- 비목표: 화면·API·테이블·테스트의 실제 설계/구현(별도 TASK), PRD 수정, SDK·정책 확정.

1. 서비스 기능 정의서가 **FR-001~014 전부**를 사용자 기능 단위로 다룬다(기능명·주체·선행조건·정상 흐름·예외/오류·안전/정책 연계·관련 FR).
