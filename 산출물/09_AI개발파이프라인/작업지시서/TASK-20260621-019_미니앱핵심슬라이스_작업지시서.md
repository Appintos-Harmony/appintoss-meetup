1. **스캐폴드**: Vite+React+TS, `npm install`, `build`/`test` 동작 확인.
2. **도메인**(`src/domains/meetup`): 타입 + 순수 로직(상태 전이, 정원 계산, 중복 신청 차단, 승인 권한) + Vitest 단위 테스트(서버 강제 규칙을 도메인에서 우선 검증, NFR-002).
3. **식별**(`src/shared/identity`): `getAnonymousKey` 래퍼(개발: mock hash / 실제: 앱인토스 SDK). 클라이언트 식별 한계 주석.
4. **저장소**(`src/shared/store`): 인터페이스 + 데모용 in-memory/localStorage 구현(서버 교체 가능하게 분리). **데모 단계 한계 명시**(서버 강제 아님 → 후속).
5. **UI/흐름**(`src/routes`): 모임 생성·초대코드 입장·상세·신청·주최자 승인 화면. CTA 명확, 로딩/빈/오류 기본 상태.
