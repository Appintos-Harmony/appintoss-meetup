## 1. 배경
하모니 백엔드 = Node24 `node:sqlite` 무의존(`apps/api/server.mjs`), AWS에 nginx+HTTPS 배포(`https://3.39.167.74.nip.io`). 현재 세션 단건 GET만 있고, **"공유/음원추가 페이지"용 목록 API가 없다**(와이어프레임: 제목·제작자·음 길이·들어보기 리스트).

## 2. 목표
- **`GET /feed`** (또는 `/tracks`) · 최근 공개 세션/트랙 목록: `{code, name, owner, trackCount, createdAt}[]`. 최신순·limit 파라미터.
- **하드닝:** 입력 검증 강화, 간단 rate-limit(IP·시간당), payload 크기 제한 점검, 세션코드 충돌/만료.
- **재배포 + 검증**(healthz + 신규 엔드포인트 200).

## 3. 비목표
미니앱 UI(클라) 수정 금지(이상혁 스트림). 계정/인증 추가 금지.

## 4. 수락 기준
신규 목록 엔드포인트 JSON 배열 반환 · 기존 4개(healthz·POST/GET sessions·POST tracks) 회귀 없음 · curl/Invoke-RestMethod 검증 로그 첨부 · 배포 후 라이브 URL 200.

## 5. 변경 허용/금지
허용 `apps/api/**`. **금지** `apps/miniapp/**`·`theme.css`·타인 영역.

## 6. 검증
로컬 `node apps/api/server.mjs` → `curl localhost:8080/feed`. 배포=인수인계 문서의 재배포 절차(scp→cp→**chmod -R a+rX**→reload).
