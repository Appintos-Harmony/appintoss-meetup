# TASK-20260621-022 — UI 리디자인(토스 앱 수준)

## 1. 배경
프로토타입 디자인이 약함. 화면설계서 §1.1 디자인 품질 기준(토스 수준)에 맞춰 UI를 재구현한다. 근거: [[design-toss-grade]] 사용자 요구.

## 2. 목표/비목표
- 목표: TDS 정렬 디자인 시스템(theme.css 토큰 + ui.tsx 컴포넌트) + 전 화면(SCR-001~005)을 토스 수준으로 재구현.
- 비목표: 백엔드, 신고/운영(후속 SCR), TDS 패키지 직접 설치(리스크 → 핸드크래프트 후 매핑).

## 3. 진행 (단계)
1. ✅ 디자인 시스템: `theme.css`(Pretendard·토큰·컴포넌트 클래스·모션) + `ui.tsx`(Screen/AppBar/Card/Button/Field/BottomBar/Badge/Empty).
2. ✅ App 셸 + 온보딩(SCR-001) + 홈(SCR-002) 재구현. 빌드·프리뷰 렌더 확인(콘솔 0).
3. ⏳ 모임 생성(SCR-003) + 상세 참가자/주최자(SCR-004/005) 재구현 → styles.ts/common.tsx 제거.
4. ⏳ 상태(로딩 skeleton·빈·오류) 보강, 프리뷰 스크린샷 검증.

## 4. 수락 기준
- 전 화면 동일 디자인 시스템 사용(혼재 제거), `npm run build`·`npm test` 통과, 콘솔 에러 0.
- 화면설계서 §1.1 토큰 준수(색·타이포·간격·radius·모션). 접근성(터치·대비) 반영.
- 프리뷰 스크린샷으로 품질 확인. 완료 주장 전 실측.

