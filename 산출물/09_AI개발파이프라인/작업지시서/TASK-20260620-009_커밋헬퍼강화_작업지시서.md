## 결정(제안)
- **C1 — main 기본 차단:** 현재 브랜치가 `main`이면 커밋을 **중단**한다. `--allow-main`(부트스트랩 1회 예외)일 때만 허용하고, 콘솔에 "부트스트랩 예외" 경고를 남긴다.
- **C2 — 명시 스테이징:** `git add -A`를 제거한다.
  - `--paths "p1 p2 …"`: 지정 경로만 스테이징.
  - `--all`: 전체 스테이징(명시 옵트인, 경고 + 스테이징 목록 출력).
  - 둘 다 없으면 중단하고 사용법을 출력한다.
  - 커밋 직전 `git status --short`로 **스테이징/미스테이징 미리보기**를 출력한다.
