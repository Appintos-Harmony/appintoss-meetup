## 1. 한 문장
Ready 작업 1건을 **코드로 강제되는 안전 게이트** 안에서 구현·검증·커밋하고 `AI Review`에서 사람을 기다리는, 반복 가능한 엔지니어링 루프.

## 2. "API 없이"의 두 층
| 층 | 외부 유료 API | 구현 |
|---|---|---|
| 결정론 엔진(선택·게이트·가드·테스트) | **없음** | 순수 Node(`node:*` 내장만). 토큰·비용 0 |
| AI 스테이지(구현·검토) | **API 키 코드 없음** | Claude Code 내장 `/loop`+서브에이전트(구독 세션)가 구동 |

엔진은 무추론·무비용으로 항상 동작하고, 모델 추론은 코드에 API 키를 박지 않고 Claude Code가 수행한다.

## 3. 구성요소 (모두 신규, 제품 코드 무변경)
| 파일 | 역할 | 종료코드 |
|---|---|---|
| `tooling/scripts/작업_인덱서.mjs` | TASK 파싱 → Ready 큐 → 경로안전(공유 `canonicalize`) → 결정론 선택(lowest-id 단조) | 3=후보 없음 |
| `tooling/scripts/루프_가드.mjs` | preflight · check-diff(allowed⊆·forbidden·보호구역·무게이트코드, `--staged`) · 단조 반복캡 | 10/11=STOP · 12=캡 |

| `.claude/commands/loop-engineer.md` | 8스테이지 드라이버(AI 오케스트레이션 계약) | - |

코드 게이트는 별도 신규 파일 대신 **기존 `검증_전체 --code`**(`코드검증.mjs`, 항상 실행하는 tsc+vitest)를 쓴다. 구현 초기의 `코드게이트.mjs`는 중복(+no-op 버그)이라 [REVIEW-035](독립검토서/REVIEW-20260623-035_루프엔지니어링_검토.md) 후 폐기했다.

기존 자산 재사용: `검증_전체.mjs --code` · `커밋.mjs`(+`--guard-task` 추가, push 안함·main 차단) · git 훅(비밀값·pre-push) · `.claude/agents`·skills.

## 4. 루프 스테이지
`ITERATION(캡) → SELECT → PREFLIGHT → CLAIM(브랜치) → IMPLEMENT → VERIFY(검증_전체 --code) → REPAIR(≤2) → STAGE+CHECK-DIFF(--staged) → COMMIT(green만, --guard-task) → REVIEW(초안) → REPORT+STOP(AI Review)`

## 5. 비협상 안전 게이트 (코드로 강제)
| 게이트 | 강제 |
|---|---|
| 푸시·머지·배포·태그 = 사람 | 커밋.mjs(push 안함) + pre-push(main 차단) + settings(ask). 루프는 커밋에서 정지 |
| green-only 커밋 | `검증_전체 --code`(docs+links+secrets+tsc+vitest, exit0). 커밋 경계는 `커밋.mjs --guard-task`가 재강제 |
| 보호구역 불가 | 루프_가드 `isForbidden`: settings·git-hooks·헌장·`HUMAN_APPROVAL` 파일. 인덱서 `pathSafety`와 단일 기준 |
| 범위 준수 | check-diff: 모든 변경이 작업 `allowed_paths` 안 |
| 폭주 방지 | 반복 하드 캡(기본 8) + lowest-id 단조 큐 |
| 정직성 | 로그에 게이트 원문 출력 첨부. 미실행=Not Run. 가짜 수치 금지 |
| 자기보호 | 루프가 settings·훅·이 커맨드·가드를 수정 못함(forbidden_paths) |
