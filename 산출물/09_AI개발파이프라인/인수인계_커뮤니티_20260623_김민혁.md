## 4. 남은 작업 (에이전트가 이어받을 것)

> **2026-06-23 재개 진행(Claude Code, 머신 이동 후):** **A** 좋아요 서버 reactions 진짜 구현+보드 노출(OQ-D 조장 결정), **B** IP 레이트리밋·report 제한·시드 hide 거부(403)·crypto 128bit 익명키·RATE/IDEMP sweep(※ 다중트랙 트랜잭션은 `server.mjs`에 이미 구현돼 있었음), **C** 출처 카피 협업 톤, 모두 구현·로컬검증(tsc 0·vitest 58/58·백엔드 스모크 11/11+좋아요 8/8). 추가 수정: nginx `/community` 라우팅·`X-Forwarded-For` 누락(운영 보드 깨짐·IP 레이트리밋 무력화) 정정 + `cleanText` 리터럴 NUL 제거(소스 텍스트화). **남은 것: D 머지(조장)·2장비 리허설(§5)·독립검토(Codex)·푸시(사람 게이트)·OQ-B(공개 보드 심사 분류) 선결.**

### A. 좋아요 진짜 구현
- `server.mjs`: `CREATE TABLE IF NOT EXISTS reactions(code TEXT, anon_key TEXT, created_at INTEGER, UNIQUE(code,anon_key))`. `POST /sessions/:code/like` 토글(INSERT OR IGNORE/DELETE → `{liked,count}`), IP 레이트리밋. `GET /community`·`GET /sessions/:code`에 `likeCount`(COUNT) 추가.
- `share.ts`: `toggleLike(code, authorKey): Promise<{liked:boolean; count:number}>`.
- `Community.tsx`: 기존 하트 버튼을 **서버 toggleLike로 재배선**(로컬 `likes.ts` 미사용·보드에서 제거; 파일은 보존). `likeCount`는 `listCommunity` 응답에서.

### B. MED 보강
- 레이트리밋 키 `author_key`→**IP 기준**(`server.mjs` rateOk), `report` 엔드포인트에도 추가.
- publish 다중트랙 **트랜잭션**(BEGIN/COMMIT) 또는 published=0→완료 후 1.
- 시드(SEED01/02) **hide 거부**(`author_key==='seed'`면 403).
- 익명키 **crypto.getRandomValues 128bit**(`identity.ts` getUserKey).
- `RATE`/`IDEMP` Map **TTL/sweep**(메모리 바운드).

### C. 출처 카피 정정 (Q3)

## 5. 2장비 리허설 시나리오 (같은 wifi + HTTPS)
**환경 셋업(PC):**
1. API: `cd apps/api` → `set PORT=8080` → `node server.mjs`.
2. 앱: `cd apps/miniapp` → `npm run dev:web`(vite, host:true).
3. **HTTPS 터널 2개**(폰 접속용): vite(5173)용 + **API(8080)용**: 페이지가 https면 API도 https여야 함(mixed-content 차단 회피). vite 빌드/실행 시 `VITE_API_BASE=<API 터널 https URL>` 주입.
   - 예: `cloudflared tunnel --url http://localhost:5173` + `cloudflared tunnel --url http://localhost:8080`.

**시연(A·B 2장비):**
1. A: 온보딩(닉네임) → 스튜디오 녹음 → 더보기 **"커뮤니티에 올리기"** → 보드 확인.
2. B: 커뮤니티 → **pull-to-refresh** → A 곡 보임(=서버 공유 증명).
3. B: 들어보기(트랙별 음색) → 담기(1개) → 스튜디오에 얹기 → 한 겹 녹음 → **"커뮤니티에 올리기"**(출처 박힘).
4. 보드: B 파생곡 등장 + 카드 **"소스: A의 음원 사용"** + A 원곡 **파생수 +1** 확인. → 합주 듣기.
5. B: 댓글 작성 → A 새로고침 시 보임. 같은 댓글 **신고 3건 → 숨김** 확인.
6. 폴백: 오프라인 시 시드곡 표시 / 공유 연타 시 **멱등**(중복 카드 안 생김).
**통과 기준:** 2~4번(서버 공유 + 출처 루프 + 파생수)이 핵심. 실패 시 §4-A/B 우선 점검.
