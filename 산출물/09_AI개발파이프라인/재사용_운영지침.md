# 재사용 운영지침

> 다음 프로젝트에서 초기 세팅을 줄이기 위한 플레이북. 현재까지 실제로 만든 재사용 자산만 적는다.

## 재사용 가능한 자산

| 자산 | 경로 | 재사용 방법 |
|---|---|---|
| 3에이전트 헌장·지침 | `CLAUDE.md`·`AGENTS.md`·`CHATGPT_PRO_운영지침.md` | 프로젝트명·팀·앱 ID만 교체 |

| 작업/검토/결정 템플릿·공통 계약 | `산출물/09_AI개발파이프라인/*` | 그대로 복사 |

## 새 프로젝트 부트스트랩 순서

1. 위 자산 복사 → 프로젝트명·팀·앱 ID 치환.
2. `git init -b main` + `git config core.quotepath false` + `git config core.hooksPath tooling/git-hooks`.
3. `node tooling/scripts/세션_시작_컨텍스트.mjs`로 상태 확인.
4. `node tooling/scripts/검증_전체.mjs`로 문서·링크·비밀값 검증.
5. 사람이 권한(settings.json) 검토·적용(아래).
6. 부트스트랩 커밋 후 `git switch -c develop`. 이후 작업은 `feature/fix/chore/docs/TASK-…` 브랜치 → `develop` merge(독립검토 후). `main` 병합은 이상혁 승인 + 검증(--strict) + 독립검토서. 브랜치 전략 정본: `.claude/rules/git.md`.

## 팀원·후배 온보딩 (재사용 시작점)
1. `하네스_소개.md` 1쪽으로 큰 그림 파악 → `라이프사이클_흐름.md`로 작업 흐름 이해.
2. `README.md`의 "여기서 시작하세요" 5단계 수행.
3. 새 프로젝트면 아래 "새 프로젝트 부트스트랩 순서" 따라 복사·치환·검증.
4. 막히면 `프로젝트_운영/00_팀공유/00_진행사항.md` 차단 이슈에 올린다.

## 권장 `.claude/settings.json` (사람이 검토 후 적용 · AI 자동 생성 금지)

AI가 자기 권한을 넓히는 자기수정은 자동 분류기가 차단한다(정상 동작). 아래 내용은 **사람이** `/permissions` 또는 직접 파일로 적용한다.

```json
{
  "permissions": {
    "allow": ["Bash(node tooling/scripts/*)", "Bash(git status:*)", "Bash(git diff:*)", "Bash(git log:*)", "Bash(git add:*)", "Bash(git commit:*)"],
    "ask": ["Bash(git push:*)", "Bash(git merge:*)", "Bash(git tag:*)"],
    "deny": ["Bash(git push --force:*)", "Bash(rm -rf:*)", "Read(./.env)", "Read(./.env.*)"]
  }
}
```
