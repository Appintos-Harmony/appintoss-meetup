## 결정이 필요한 사항

리허설 피드백 수정(FB2 중복방지·FB5/FB6 신고)을 구현하면서, 코드로 단정하면 안 되는 **정책·보안 결정 3건**이 도출됐다. 이 중 FB6-보안(신고 키 회전 검열 벡터)은 신고자 식별을 IP로 전환해 코드상 해소됐고(72cdfbf), 남은 사람 판정 항목은 **OQ-B(자동숨김 무통지 투명성)와 FB2(중복방지 시간창·이름 포함) 2건**이다. AI는 구현 가능 부분(버그 픽스·임계 상수화·dedup 메커니즘)만 반영했고, 아래 정책 의존부는 사람 판정이 필요하다.

## 선택지

### OQ-B. 작성자 무통지 자동숨김(shadow moderation)의 앱인토스 UGC 투명성 정책 부합 여부

- 확인된 사실: 서로 다른 신고자 `REPORT_HIDE_THRESHOLD`(현 3)명 누적 시 댓글 `hidden=1`로 자동 숨김. 작성자에게 통지·이의제기 경로 없음. 복구(unhide) 미구현(비가역, 운영자 수동 DB만).
- **선택지 A (현행 유지·정직 고지):** 자동숨김 유지 + 매뉴얼/UI에 "여러 이용자 신고 시 자동 숨김" 1줄 고지. 장점: 데모 단순·구현 완료. 단점/위험: 작성자 무통지 = 투명성 정책 위반 소지(앱인토스 공식 가이드 미검증, P-10/P-13).
- **선택지 B (운영자 큐 완화):** 임계 도달 시 즉시 삭제가 아니라 `hidden=1`(노출만 차단) + 운영자 검토 큐로 보내고 복구 경로(unhide) 제공. 장점: 오신고·검열 위험 완화. 단점: 운영자 화면·복구 라우트 추가 구현(일정 부담).
- **선택지 C (심사 제출본 비공개 트랙):** 공개 보드를 끄고 code 기반 비공개로 제출(OQ-B 기존 논의와 연동). 자동삭제 노출 자체를 회피.

### FB6-보안. 신고 distinct 카운팅의 키 회전 검열 벡터 (코드상 해소됨)

- 확인된 사실(갱신): 신고자 식별을 클라 자기신고 `author_key`가 아니라 **서버 도출 IP**로 변경해 해소했다(`apps/api/server.mjs`의 `reporter = ip`, `author_key`는 신고자 식별에 미사용; 커밋 72cdfbf). X-Forwarded-For 위조 차단(소켓 주소·신뢰 헤더만 사용)도 함께 적용돼, 한 사람이 localStorage 키를 회전해 distinct 신고자를 위조하고 자동숨김을 트리거하는 1인 검열 벡터는 더 이상 성립하지 않는다. 따라서 아래 선택지는 사실상 IP 기반 보강(선택지 A 방향)으로 이미 반영됐고, 잔여 리스크는 공유 IP false-merge뿐이다.
- **선택지 A (보강) — 채택·반영됨:** 신고자 카운팅을 IP 기준으로 전환해 같은 IP의 다중 키를 1로 접는다. node 무외부의존 내에서 반영 완료(72cdfbf).
- **선택지 B (한계 기재만):** 더 이상 해당 없음. 잔여 리스크인 공유 IP false-merge는 정책준수표 Known Limitation에 기재.

### FB2-정책. 중복방지 키의 시간창·이름 포함 여부

- 확인된 사실: dedup 키 = `author_key + 첫 트랙 콘텐츠 해시`, `origin_code IS NULL`·실 클라 키일 때만. 현재 시간창 = 영구(published·미숨김 존재 시), 이름은 키에서 제외(콘텐츠 해시만).
- **시간창:** 영구 vs 최근 N분. 영구면 같은 콘텐츠 재게시 영구 차단(단, 내가 hide하면 재게시 가능; author_key 소실 시 hide 불가→영구 갇힘 위험). N분이면 잠깐 뒤 재게시 허용.
- **이름 포함:** 미포함(현행)=같은 첫트랙이면 제목 달라도 dedup. 포함=제목 다르면 별개 허용(의도적 재업로드 자유).

## 확인된 사실과 미확정 항목

- 사실(실DB 디핑): 리허설 중복 2건(3B78BP=guitar 1트랙, D8LN9K=guitar+piano)은 whole-content 다르고 **첫 트랙만 동일** → first-track 해시 dedup 채택. F2LXNP(정상 파생)는 D8LN9K와 byte-identical이라 `origin_code IS NULL` 가드 필수(없으면 파생→원곡 collapse).
- 미확정: OQ-B·FB2 2개 정책(FB6-보안은 IP 보강으로 코드상 해소, 72cdfbf). AI는 'Go' 단정 금지(CLAUDE.md §4·§7.5).

## 에이전트별 의견

- Claude Code(구현): 버그 픽스·dedup 메커니즘·임계 상수화는 정책 무관이라 선반영. 정책 의존부(자동삭제 동작·무통지·IP 보강)는 미확정으로 분리.
- 자체회의(백엔드·QA·정책·레드팀): 4역할 중 3역할이 키 회전 검열 벡터를 일치 지적(다수결 아닌 근거 기준 수렴). 자동삭제→운영자 큐 완화를 사람 게이트 선택지로 권고.

## 권고안

- OQ-B: **선택지 B(운영자 큐 완화)** 또는 발표 데모 한정 **선택지 A + 정직 고지**. 공개 출시면 B 권장.
- FB6-보안: **선택지 A(IP 보강) 반영 완료**(reporter=IP, 72cdfbf). 추가 결정 불요. 잔여 공유 IP false-merge는 한계 기재로 관리.
- FB2: 시간창 **영구 + 이름 미포함**(현행) 유지하되 author_key 소실 케이스를 매뉴얼에 고지.
