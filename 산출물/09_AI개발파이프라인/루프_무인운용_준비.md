# 루프 무인운용(cron) 승급 준비 (P4 선결조건)

## 구조적 한계 — 훅 우회 (Codex X4·X5, cron 전 필독)
Codex가 실증: `git commit --no-verify` 또는 `git -c core.hooksPath=<빈값> commit`은 **pre-commit 훅 백스톱을 완전히 우회**한다. 이는 git 자체의 구조적 한계로 **로컬 훅만으로는 코드로 막을 수 없다.**
- **유일한 in-process 코드 경계는 `커밋.mjs --guard-task`**(git commit 호출 전에 가드 실행 → `--no-verify`로 못 건너뜀). 루프는 **반드시 헬퍼 경유로만** 커밋해야 한다(raw `git commit` 금지 — 드라이버 계약).
- **무인 cron 최종 방어는 서버측**: GitHub branch protection(필수 검증·리뷰 게이트), protected branch, PR 필수. 로컬 루프가 무엇을 커밋하든 develop/main 반영은 서버 게이트가 막는다.
- 따라서 cron 승급 전 **GitHub 측 보호 설정**을 선결조건에 추가한다(사람).

### #5 GitHub branch protection 설정 절차 (사람, GitHub UI)
CI는 갱신 완료(`.github/workflows/ci.yml`에 `verify-docs` + `verify-code` job — `검증_전체 --code`·`루프엔진_검증` 실행). 머지 기준 remote(harmony=Appintos-Harmony / origin=somoim-team)에 적용한다.

저장소 **Settings → Branches → Add branch ruleset**(또는 Add rule), 대상 `develop`·`main`:
1. ☑ **Require a pull request before merging** — Required approvals **1** (직접 push 금지).
2. ☑ **Require status checks to pass** → ☑ Require branches to be up to date → 목록에서 **`verify-docs`·`verify-code`** 선택. (status check는 CI가 한 번 돌아야 목록에 뜬다 — PR 1회 후 선택.)
3. ☑ **Block force pushes**.
4. ☑ **Do not allow bypassing the above settings**(admin 포함 우회 금지).

적용 후엔 로컬 루프가 무엇을(`--no-verify` 포함) 커밋하든 develop/main 반영은 **PR + CI 통과 + 사람 리뷰**를 거쳐야 한다 → 훅 우회의 영향이 로컬 작업 브랜치에 갇힌다(X4/X5 최종 방어).

## 권한 (사람이 직접 적용 — AI는 자기 권한을 못 넓힘)

자동 분류기가 AI의 권한 자가확대를 차단한다. 아래 1줄은 **사람이** `.claude/settings.json`의 `allow`에 추가한다.

```diff
   "permissions": {
     "allow": [
       "Bash(node tooling/scripts/*)",
       "Bash(git status:*)",
       "Bash(git diff:*)",
       "Bash(git log:*)",
       "Bash(git add:*)",
-      "Bash(git commit:*)"
+      "Bash(git commit:*)",
+      "Bash(git checkout:*)",
+      "Bash(git switch:*)"
     ],
```

- 이유: 루프 CLAIM 단계의 작업 브랜치 생성(`git checkout -b`)이 무인에서 멈추지 않도록.
- `git push`·`git merge`·`git tag`는 **계속 `ask`로 유지**(사람 게이트). `bypassPermissions` 모드는 쓰지 않는다(푸시까지 열림).
- 코드 게이트(`검증_전체 --code`)·인덱서·가드는 이미 `Bash(node tooling/scripts/*)`로 커버됨.

## 무인 실행 시 권장 형태
- `node tooling/scripts/루프_가드.mjs --reset --max <N>` 로 1회 한도 고정(절대상한 20).
- 한 작업 처리 후 `AI Review`에서 정지 → 다음 사람 검토. 무인이라도 **머지·푸시는 안 함**.
- 실패·캡·STOP은 `평가증빙/루프실행_로그/`에 남기고 종료.

## 아직 켜지 않는 이유
조건 1·2·4 충족(B2 백스톱·권한·Codex Conditional Go). 남은 건 **#3 headless DENY 전용 실증**과 **#5 GitHub branch protection 적용**(사람). 본 문서는 준비 상태만 기록한다. cron 등록은 5개 모두 충족 + 조장(이상혁) 최종 승인 후.
