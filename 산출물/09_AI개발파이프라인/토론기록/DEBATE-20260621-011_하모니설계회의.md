## 합의점
- **라이트 TDS 셸 + 연주 영역만 제한적 다크 패널**(전면 다크 X · 비게임 심사 위험).
- MVP: 피아노 1·고정 4코드(C·Am·F·G)·제스처 4영역·4/4 BPM100·1마디 카운트인·≤4마디 이벤트 녹음·친구 기본트랙+내 오버더빙 1레이어·재생/뮤트/삭제·로컬저장+복구·이벤트 JSON+비공개 공유 링크·예외처리.
- 컷: 드럼·기타/베이스 지판·공개 피드·3/4·6/8·웹 반응형 패널·별도 설정/문의/메트로놈 페이지·자체 회원가입·외부 오디오 업로드.
- 킬러 데모 루프: 친구 4마디 트랙 열기 → 제스처 4코드 → 카운트인 녹음 → 동시 재생 → 뮤트로 차이 → 재공유.
- 이벤트 계약: tick 기반 Session/Event/Track(벽시계 ms 금지).
- 일정: feature-complete 6/22~23(검토 3영업일·토스앱 테스트 1회 선행).
