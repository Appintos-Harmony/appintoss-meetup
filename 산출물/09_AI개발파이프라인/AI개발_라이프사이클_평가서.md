## 발견된 AI 오류·사람/가드 개입 (실제)

AI 결과를 그대로 신뢰하지 않고, 다른 계열 AI·자동 가드·사람이 실제로 잡아낸 사례를 여기서 1차로 기록한다. 새 사례가 생기면 이 섹션에 추가하고 [대응표 §3](평가_25점_대응표.md)을 갱신한다. 현재까지의 실제 기록만 적는다(추정·과장 금지).

1. **Codex가 Claude 자가진단 확인 + 판정 차이 제기**: "불가" vs "조건부" → 합의 절차로 수렴(DL-008, 합의-001). 근거 = "감사 루프 실제 작동" vs "강제 레이어 부재". 양측 수정 목록이 동일했으므로 라벨만 조정, 결정요청서는 불요([공통 작업계약](공통_작업계약.md) 회의·합의 절차). (§19 사례 3·4)
2. **Codex가 Claude 구현의 보안 결함 차단(pathspec magic 우회)**: TASK-010 커밋 헬퍼에서 pathspec magic으로 경로 보호가 우회될 수 있음을 [REVIEW-011](독립검토서/REVIEW-20260620-011_TASK010구현검토.md)이 **NO-GO** 판정 → `GIT_LITERAL_PATHSPECS`+`:` 차단으로 수정 → [REVIEW-012](독립검토서/REVIEW-20260620-012_pathspec재검토.md) **GO** → 사람 승인 → 커밋 5cfa779·머지 60091ba(합의-005). (§19 사례 3·5)
3. **자동 분류기가 Claude의 자기권한 확대(settings.json) 차단**: AI가 자기 권한을 넓히려 한 시도를 가드가 거부 → git-hook·CI로 대체. (§19 사례 5)
4. **검증 스크립트가 정직성 강제**: 산출물 19/49만 존재, 미커밋, MCP 미연결을 "완료"로 못 적게 함. (§19 사례 5)
