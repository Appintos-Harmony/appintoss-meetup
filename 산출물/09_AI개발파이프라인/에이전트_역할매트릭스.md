# 에이전트 역할 매트릭스

이 문서는 3에이전트 운영의 **역할·배정 단일 기준본**이다(CLAUDE.md §6 근거). 누가 어느 작업을 주도하고, 누가 독립 검토하며, 누가 승인하는지는 여기에서 정한다. 에이전트 정의 스냅샷은 [에이전트 목록 및 역할](에이전트_목록및역할.md), 저장소 구조·자동화는 [멀티에이전트 하네스 구성도](멀티에이전트_하네스_구성도.md), 작업·결과 계약은 [공통 작업계약](공통_작업계약.md)을 따른다.

> AI는 승인자가 아니다. 문서의 `owner`·`reviewer`·`approver`와 모든 P0 승인에는 실제 팀원(이상혁·곽소정·김민혁·양록빈)만 기록한다.

## 3층 구조

| 층 | 주체 | 책임 |
|---|---|---|
| 통제면 | ChatGPT Pro | 요구사항·정책·작업지시·독립 감사·출시 판정 |
| 실행면 | Claude Code | 저장소 오케스트레이션·아키텍처·통합 구현·문서 동기화·Codex 결과 검토 |
| 실행면 | Codex | 격리 구현·자동 테스트·결함 수정·Claude 변경 독립 검증 |
| 승인면 | 사람(팀원 4) | 범위·병합·배포·문서 최종 승인 및 책임 |

핵심 원칙:

- 같은 모델이 초안과 최종 승인을 모두 맡지 않는다(자기검토 금지).
- 모든 P0 작업에는 주 구현 에이전트 1, 다른 계열의 독립 검토 에이전트 1, 사람 승인자 1이 있어야 한다.
- 에이전트 간 상태 전달은 대화 기억이 아니라 작업지시서·결과서·diff·테스트 로그·ADR로 한다.

## 단계별 역할 매트릭스

| 단계 | ChatGPT Pro | Claude Code | Codex | 실제 팀원 |
|---|---|---|---|---|
| 요구사항 | 주도 | 구현 가능성 검토 | 기술 리스크 표본 검토 | 승인 |
| 정책 조사 | 주도 | 공식 문서 재확인 | 적용 코드 점검 | 승인 |
| 아키텍처 | 독립 검토 | 주도 | 구현 타당성 검토 | 승인 |
| 구현 | 수락 기준 감사 | 통합·복합 작업 | 경계가 명확한 작업 | diff 검수 |
| 테스트 | 계획·누락 감사 | 통합 상태 검토 | 실행·수정 | 결과 승인 |
| 배포 | 출시 판정 초안 | 절차·통합 준비 | 회귀 검증 | 실제 실행 |
| 발표 | 공격 검토 | 기술 근거 제공 | 데모 안정성 검증 | 발표 |

## 작업 유형별 기본 배정 (CLAUDE.md §6.7)

| 작업 유형 | 주 담당 AI | 독립 검토 AI | 사람 승인 |
|---|---|---|---|
| 과제·정책·시장 조사 | ChatGPT Pro | Claude Code | Product & Policy Lead |
| PRD·수락 기준·범위 | ChatGPT Pro | Claude Code | Product & Policy Lead |
| 시스템·데이터·API 설계 | Claude Code | ChatGPT Pro 및 Codex 타당성 점검 | Backend & Data Lead |
| 여러 패키지에 걸친 세로 기능 | Claude Code | Codex | 해당 기능 담당자 |
| 경계가 명확한 화면·API·테스트 구현 | Codex | Claude Code | 해당 기능 담당자 |
| 테스트 계획·실패 시나리오 | ChatGPT Pro | Claude Code | QA & Release Lead |
| 테스트 실행·회귀 수정 | Codex | Claude Code | QA & Release Lead |
| 문서와 코드 추적성 동기화 | Claude Code | ChatGPT Pro | 문서 owner |
| 출시 판정·발표 공격 검토 | ChatGPT Pro | Claude Code | 팀장 및 QA Lead |
| 실제 merge·배포·심사 제출 | AI는 준비만 수행 | AI는 체크리스트 검토 | 실제 팀원 |

작업 특성상 배정을 바꾸면 작업지시서에 이유를 기록한다.

## 상호검증 규칙 (CLAUDE.md §7.4)

- Claude 구현 → Codex가 diff·테스트·예외 흐름 검증 → ChatGPT Pro가 요구사항·산출물 정합성 표본 감사 → 사람 승인
- Codex 구현 → Claude가 아키텍처·보안·문서 동기화 검토 → ChatGPT Pro가 수락 기준·사용자 시나리오 표본 감사 → 사람 승인
- ChatGPT Pro 기획·정책 결과 → Claude가 공식 문서·구현 가능성 확인 → 실제 Product Lead 승인
- 출시 후보 → Codex 회귀 명령 실행 → Claude 통합 상태 확인 → ChatGPT Pro 증거 기반 출시 판정 초안 → 실제 QA Lead 승인

merge·migration·데이터 삭제·production 배포·심사 제출은 항상 사람 승인 후 실행한다.
