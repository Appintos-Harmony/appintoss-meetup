# 공통 작업 계약

## 목적

ChatGPT Pro, Claude Code, Codex가 서로 다른 인터페이스에서 작업하더라도 동일한 상태와 완료 기준을 사용하기 위한 계약이다.

## 단일 작성자 원칙

한 작업의 쓰기 단계에는 주 구현 에이전트가 하나만 존재한다. 다른 에이전트는 읽기·검토만 수행한다. `allowed_paths`가 겹치지 않는 별도 작업만 병렬로 진행한다.

## 독립 검토 원칙

P0·P1 변경은 구현 에이전트와 다른 계열의 AI 검토와 실제 사람 승인을 거친다.

- Claude 구현 → Codex 검토
- Codex 구현 → Claude 검토
- ChatGPT Pro 기획 → Claude 타당성 검토

## 증거 원칙

- 실행 명령과 원문 로그가 없는 테스트는 완료 증거가 아니다.
- 접근하지 못한 자료는 `Not Available`로 표시한다.
- 실행하지 않은 검증은 `Not Run`으로 표시한다.
- 추정은 사실과 분리한다.

## 완료 조건

수락 기준 충족, 자동 검증, 독립 검토, 사람 승인, 요구사항 추적표와 관련 문서 갱신이 모두 끝나야 `Done`이다.

## 회의·합의 절차 (에이전트 간)

에이전트 간 합의는 대화 기억이 아니라 저장소 문서로 한다(§7 원칙).

1. 주 구현 에이전트가 결과(diff·결과서)를 남긴다.
2. 다른 계열 에이전트가 `독립검토서`(REVIEW-…)로 confirm/dispute 한다.
3. **합의(일치):** 결과를 수용하고 우선순위·후속 TASK를 확정한다.
4. **불일치:** 다수결하지 않는다. `결정요청서`(DECISION-…)를 만들고 **공식 문서 → 요구사항 → 재현 로그 → 테스트 결과** 순으로 근거를 비교한다.
5. 합의·결정은 `의사결정_기록.md`에 DL 번호로 남긴다.
6. **사람 승인:** 범위·병합·배포·git·삭제는 실제 팀원이 최종 승인한다. AI는 승인자가 아니다.
7. **외부 평가(선택):** 양측이 끝내 불일치하거나 "객관적 충분성"의 제3자 검증이 필요하면 외부 모델(예: Gemini)에 동일 입력을 주고 판정을 받는다. 외부 판정도 사람 승인을 대체하지 않는다.

### 행동 단위 검토 캐던스 (표준 리듬, DL-010)

**모든 행동(action)은 Codex 독립 검사와 Claude-Codex 토론을 거친다.**

- "행동 단위" = 하나의 TASK 또는 의미 있는 변경 묶음(거버넌스·하네스 변경 포함). 사소한 오타 1건마다 전체 검토를 강제하지 않는다(일정 보호). 묶어서 1 TASK로 검토.
- 루프: `Claude 행동 → Codex 독립 검사(REVIEW-…) → Claude-Codex 토론 → 합의 또는 결정요청서 → 사람 승인 → 다음 행동`.
- 같은 모델이 초안과 최종 검토를 동시에 맡지 않는다(주 구현이 Claude면 검토는 Codex, 반대도 동일).
- Claude는 각 행동을 마치면 그 행동에 대한 **Codex 검사 프롬프트**를 사람에게 제공한다. 검사 결과가 합의될 때까지 다음 행동을 확정하지 않는다.
- 모든 검사·합의는 `독립검토서`/`의사결정_기록`으로 남긴다(대화 기억 의존 금지).
