## 1. 무엇을 했나
- 하모니 **아키텍처 다이어그램 7종** 제작/갱신. 각 **PNG(보기) + .drawio(편집본)** — **SVG는 생성 안 함**(요구사항).
  1) 전체 시스템 아키텍처 2) 합주 공유 서비스 흐름 3) AWS 배포 4) 배포·서비스 구성도(Apps-in-Toss 프로덕션) 5) 데이터 모델 ERD(**DA# 표기**) 6) 신뢰경계 DFD 7) 라이프사이클 상태도
- 위치: `산출물/04_시스템설계/`. 아이콘 원본 `아키텍처_아이콘/`, 생성기 `_build/`.

## 2. 정본 기준 (중요)
- **GitHub 기본/정본 브랜치 = `develop`** (`origin/HEAD → develop`). **`main` 브랜치는 origin에 없다**(로컬 main은 앱 없는 옛 부트스트랩). "main 기준" 요청은 사실상 develop 기준.
- 사실 근거 = `apps/api/server.mjs`(develop): 5테이블(sessions·tracks·comments·comment_reports·reactions)·**9경로/10오퍼레이션**·`REPORT_HIDE_THRESHOLD=3`·`server.listen(PORT,HOST)` 127.0.0.1 바인드·1.5초 폴링·`sessions.origin_code` 자기참조.
- 인프라: 단일 AWS EC2(Ubuntu)+nginx(443 TLS·Let's Encrypt·3.39.167.74.nip.io)+Node 무의존(node:http+node:sqlite, 127.0.0.1:8080)+SQLite 파일+systemd. 프론트=`ait deploy`→Apps-in-Toss(토스 콘솔 심사·유통), 백엔드=AWS `deploy.sh`. CI=GitHub Actions.
- **날조 금지**(그리면 안 됨): Docker·K8s·Redis·Kafka·MQ·Spring·FastAPI·Oracle·RDS·LB·AutoScale·Multi-AZ·CDN·별도 인증서버·WebSocket·SSE·실시간 스트리밍. (하모니에 없음)

## 3. 제작 파이프라인 / 환경 (재생성 방법)
- 생성기(`_build/`): `build_arch.mjs`(시스템+흐름) · `build_aws.mjs` · `build_deploy.mjs` · `build_erd.mjs`(DA# SVG) · `build_dfd.mjs` · `build_state.mjs` → SVG 문자열. `build_drawio.mjs`(시스템/흐름/AWS/배포 drawio) · `build_erd_drawio.mjs`(ERD DA# drawio).
- **PNG 렌더**: 이 PC엔 ImageMagick·Python·drawio CLI **없음** → **Edge 헤드리스 `--screenshot`로만**. `msedge.exe` 경로 = `C:/Program Files (x86)/Microsoft/Edge/Application/`. 잔존 프로세스가 프로파일 락을 걸어 연속 렌더가 실패하니 **PowerShell `Start-Process -Wait` + 매 렌더 전 `Stop-Process -Name msedge`** 권장. 한글 경로 `file://` 이슈 회피용 ASCII 임시폴더 `C:/Users/Public/arch_tmp` 사용. 2x는 2000px 초과로 내 뷰엔 안 열리니 검증은 1x로.
- 텍스트가 박스를 넘지 않게 생성기에 **`fitAttr`**(폭 초과 시 SVG `textLength`로 자동압축) 적용.
- drawio 검증: `view_drawio.mjs`로 diagrams.net 뷰어 HTML 생성 → Edge `--virtual-time-budget`로 렌더(읽기전용). `extract_drawio.mjs`로 drawio 노드/엣지 텍스트 추출.

## 4. 현재 상태 / 주의 (gotcha)
- ⚠️ **PNG는 김민혁이 draw.io에서 직접 export 중**(생성기 PNG와 분리). **drawio가 정본 비주얼.** 산출물 폴더 PNG는 일부만 있을 수 있음(사용자가 export로 채움). drawio↔PNG 불일치 시 drawio 우선.
- ⚠️ **`build_drawio.mjs` / `build_erd_drawio.mjs` 를 재실행하면 사용자의 draw.io 수동 편집을 덮어쓴다.** 사용자 확인 없이 실행 금지. drawio 수정은 **기존 파일을 surgical하게 Edit**(전체 재생성 X). 사용자가 draw.io 데스크톱(Electron)으로 재저장하므로 **편집 전 반드시 다시 Read**.

## 5. 의사결정 (baked-in)
- **약점/한계 주석은 발표·심사용으로 "치명적인 것" 제거**(정직성 규칙보다 사용자 판단 우선).
  - 제거됨: 백업공백 카드(시스템)·잔여위험(DFD)·getAnonymousKey mock·appName 임시(배포)·users/auth 없음 콜아웃(ERD)·healthz 모니터링 공백(시스템)·익명키 신원보증아님(시스템)·(인증X)(흐름도)·★유일 자동전이(상태도).
  - 유지: HA/오토스케일/LB 없음(**단일 인스턴스 의도 근거**)·코드=접근권한·untrusted·cloudflared=CDN 아님.
- **외부 연동 박스 미추가**: 하모니 실제 외부 의존 = 토스/Apps-in-Toss·Let's Encrypt·nip.io·Cloudflare(백업)뿐. 행안부/기상청/Kakao류 공공·AI API는 없음(넣으면 날조). 필요 시 이 4개만 박스화 가능.
- **흐름도 fork 버그 수정**: `forkCount`는 `origin_code`로 파생 세션 publish할 때(POST /sessions) 증가 — POST /tracks 아님. ⑪에서 제거 → 출처 루프 엣지로 이동(상태도와 일치).
- **ERD DA# 표기**: reactions/comment_reports = 대리키 없는 복합 UNIQUE를 식별자로(식별 관계·실선), tracks/comments = 대리키 id+FK(비식별·점선), sessions.origin_code 자기참조(비식별).
