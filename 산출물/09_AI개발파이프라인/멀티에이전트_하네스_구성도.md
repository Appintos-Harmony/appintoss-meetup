## 작업 흐름 (Git 문서 = 메시지 버스, §7)

```text
작업지시서(TASK-…, Ready)
  → 주 구현 에이전트(Claude 또는 Codex) 구현 + 검증 명령
  → 다른 계열 에이전트가 독립검토서(REVIEW-…)
  → 불일치 시 결정요청서(DECISION-…)  (근거: 공식문서>요구사항>로그>테스트)
  → 사람 승인(HUMAN_APPROVAL)
  → Done(추적표·문서·증거 갱신)
```

상태: `Proposed → Ready → In Progress → AI Review → Human Approval → Done`(↘ Rework/Rejected)

## 주의 — settings.json 권한

`.claude/settings.json`(권한 allow 규칙)은 **AI가 자기 권한을 넓히는 자기수정**이라 자동 분류기가 생성을 차단했다(2026-06-20). 권한은 사람이 `/permissions` 또는 직접 검토 후 적용한다. 권장 내용은 [재사용 운영지침](재사용_운영지침.md) 참조. 강제는 git-hook·CI로 대체했다.
