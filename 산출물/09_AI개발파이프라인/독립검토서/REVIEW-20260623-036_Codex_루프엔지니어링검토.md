## 8. 남은 위험과 수정 제안(diff 개념)

1. `pathSafety()`는 raw path의 절대경로, drive prefix, traversal evidence를 canonicalize 전에 별도로 거부해야 한다.

```diff
+ const raw = String(g).normalize('NFC').replace(/\\/g, '/').trim();
+ if (/^[a-zA-Z]:\//.test(raw) || raw.startsWith('/') || raw.split('/').includes('..')) {
+   violations.push(`allowed_paths '${g}'에 절대경로 또는 traversal 사용`);
+   continue;
+ }
```

2. `withinAllowed()`는 재사용 안전성을 위해 보호경로를 false로 반환하거나, 함수명을 `withinAllowedIgnoringForbidden`처럼 명시해야 한다.

```diff
 export function withinAllowed(path, allowed) {
+  if (isForbidden(path)) return false;
   const p = canonicalize(path);
```

3. `changedPaths()`는 untracked directory를 파일 단위로 확장해야 한다. 최소 수정은 `git status --porcelain -uall`, 보수적 보강은 `p === 'packages' || p === 'infra' || p === 'apps'`도 ungated로 취급.

```diff
- const raw = staged ? tryGit(['diff', '--cached', '--name-only']) : tryGit(['status', '--porcelain']);
+ const raw = staged ? tryGit(['diff', '--cached', '--name-only']) : tryGit(['status', '--porcelain', '-uall']);
```

4. 상태 파일은 보호경로에 포함해야 한다.

```diff
   'CHATGPT_PRO_운영지침.md',
+  '평가증빙/루프실행_로그/_상태.json',
```

5. `preflight()`는 기존 `activeTask`가 다른 작업으로 설정되어 있으면 사람 `--reset` 없이는 덮어쓰지 않아야 한다. 가능하면 `_상태.lock` 같은 advisory lock을 사용한다.

```diff
 const s = readState();
+if (s.activeTask && s.activeTask !== id) {
+  out(`STOP: 다른 활성 작업 ${s.activeTask} 존재. 사람이 --reset 해야 함.`);
+  process.exit(10);
+}
 s.activeTask = id;
```

6. Windows ADS/colon spelling은 `pathSafety()`에서 `:` 포함 세그먼트를 거부하거나, 보호 파일명 앞부분(`CLAUDE.md:...`)을 보호 파일로 접어야 한다.

7. `--no-verify`/`core.hooksPath`는 로컬 훅으로 완전 방어할 수 없다. 루프 커밋은 `커밋.mjs --guard-task` 경유만 허용하고, 서버/PR 측 보호(필수 검증, protected branch, review gate)로 최종 방어해야 한다.
