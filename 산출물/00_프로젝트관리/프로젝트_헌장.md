## 제품 한 문장 (CLAUDE.md §3.1)

사용자가 코드·멜로디·드럼을 연주하고, 친구가 공유 코드로 트랙을 얹어 한 곡을 완성하는 앱인토스 악기 합주 미니앱.

## 목표 (기한 내 실제 증거 포함)

1. 앱인토스에서 실행 가능한 비게임 미니앱
2. AWS HTTPS에 배포된 공유 API와 미니앱 정적 빌드
3. 과제 필수 산출물 15종 — [산출물 목록](산출물_목록.md)
4. 실제 실행 결과가 포함된 단위·통합 테스트 보고서
5. 재사용 가능한 멀티에이전트 파이프라인
6. 5분 내 안정적으로 시연 가능한 제품

평가: 발표·시연 50% / 산출물 25% / AI 파이프라인 25% / 앱인토스 배포 가산 10%.

## 범위 (출시 우선 전략, §3.2)

- P0: 스플래시, 닉네임 온보딩, 악기 선택, 코드/멜로디/드럼 연주, 녹음/재생, 노트 편집, 로컬 저장, 공유 코드 기반 비동기 합주.
- P0 정책: 자체 로그인 없음, 토스 로그인 없음, `getAnonymousKey` 익명 식별, 위치·결제·광고 없음.
- 제외(기본): 실시간 채팅, 공개 소셜 피드 확장, 결제, 광고, 랭킹, 추천 알고리즘, 서버 계정 시스템.

## P0 핵심 사용자 흐름 (§3.3)

진입 → 닉네임 온보딩 → 홈 → 스튜디오 → 악기/연주법 선택 → 연주·녹음 → 재생/편집 → 저장 → 공유 코드 생성 → 다른 기기에서 받기 → 트랙 얹기 → 합쳐 듣기.
