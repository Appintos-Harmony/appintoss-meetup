## DL-018 — 주제 전환 제안: 소모임 밋업 → 악기 합주 미니앱 (팀 합의 대기)
- 날짜: 2026-06-21 · 상태: **Proposed** (팀 합의 대기 — 주제는 자유, 팀이 비즈니스 검토 후 확정)
- 배경: 조장이 주제 재검토. 후보 = **악기 합주(밴드/합주) 미니앱**. 사업자 없음 유지.
- 제안 제품: 가상 악기(피아노·기타·베이스·드럼) + 간단 코드 반주(개러지밴드식) + 개별음(일부 음역) + 메트로놈(on/off·BPM). **합주 = 비동기 루프 레이어("남의 트랙에 얹기")** — 실시간 오디오 스트리밍은 레이턴시로 제외, 공유 클릭(메트로놈)에 맞춰 각자 녹음→레이어. 입력 = 터치 + 기기모션(기본) + **카메라 손 제스처(플래그십)**.
- 기술 검증(완료): 스파이크 `apps/miniapp/public/gesture-spike.html`(커밋 923e545, MediaPipe Hands + Tone.js) — 손 제스처 4코드 연주 + 이벤트 녹음/재생. **모바일 브라우저서 카메라·핸드트래킹·녹음 작동 확인**(대기 ~45 / 연주 ~30fps, 단일 손·480×360 최적화 후). 녹음=이벤트 기반(음/좌표 데이터, 마이크 불필요).
- 정책 검증: [공식문서_근거목록](../02_정책준수/공식문서_근거목록.md) #8~#10 — 표준 Web API(오디오) 허용·비게임·getAnonymousKey 유지 가능·음악앱 출시 금지 아님·어뷰징 정책상 "목적 다른 앱"이면 별도 등록 가능. 핀치줌 비활성 메타 필수.
- 영향: ① DL-002(초대코드형 모임)·DL-016(모임 인증)·DL-017(Gate 0=소모임 밋업/meetup-lite) **재검토 필요** — 앱 이름·카테고리(엔터>음악) 불일치 → 새 미니앱 등록 또는 임시저장 등록 교체 + Gate 0 재실행. ② 제품 문서(PRD·기능정의서·화면·테이블·API) 전면 재작성. ③ 백엔드: 솔로는 클라이언트 완결(서버 불필요), 합주/저장만 스토리지 → Oracle ADR-001 보류·축소. ④ 보존: 디자인 시스템·식별(getAnonymousKey)·스캐폴드·하네스·파이프라인(토론기록 10건)·정책검증 그대로 재사용. meetup 제품 코드는 피벗 리셋으로 제거(커밋 9ac9af2), 다른 브랜치·GitHub 백업.
- 미해결: ⓐ **팀 주제 최종 확정**(비즈니스 검토 후) ⓑ **토스 WebView 카메라 실기기 테스트**(샌드박스 QR — 모바일 브라우저는 통과, 토스 WebView 미확인) ⓒ 4-AI(ChatGPT Pro·Gemini 포함) 주제 토론 → DEBATE 기록.
