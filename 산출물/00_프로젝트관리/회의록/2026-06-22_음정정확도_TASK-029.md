## 1. 제기된 문제
- 풀버전(악기 4종, 피아노 2종) 도입에 앞서, 연주 시 **출력 음정이 요구한 음과 다르게 들린다**는 우려 제기.

## 2. 진단 (정적 분석 결과)
- `engine.ts`의 코드 구성음 표(C·Am·F·G)와 멜로디(C4~C5) 음이름은 **음악적으로 정확**.
- Tone.js는 음이름을 평균율(A4=440)로 **올바른 주파수**로 변환 → *코드 테이블에 틀린 음이 박힌 결함은 없음.*
- 결론: 즉각적 "틀린 음" 버그는 코드상 확인되지 않음. 다만 ① 음정 변환이 코드 곳곳에 흩어져 검증 불가, ② 곧 도입할 **실제 피아노 샘플은 음정 드리프트 위험**이 있어 가드가 필요.

## 3. 결정
1. **TASK-20260622-029 발행**: 음이름→주파수를 단일 모듈(`tuning.ts`)로 분리 + 음정 자동 검증(vitest) + `engine.ts` 배선(동작 보존).
2. 작업 경로 = `apps/miniapp/src/audio/**` 한정(클라 단일 스트림과 충돌 방지).
3. 실제 피아노 샘플(그랜드/전자) 도입은 **후속 TASK**(에셋 번들/CDN·라이선스 결정 후).
4. **커밋 정책(조장 지시): 작성자 = 이상혁, 커밋에 AI 서명 없음.** AI 활용 증거는 평가증빙(`평가증빙/`)·작업지시서에 분리 보존(`.claude/rules/git.md` §9 일관).

## 4. 처리 결과 (본 세션)

- 검증: `npm test` 16/16 PASS, `npx tsc --noEmit` exit 0.
