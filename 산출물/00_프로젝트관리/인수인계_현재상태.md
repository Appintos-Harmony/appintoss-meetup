# 인수인계 · 현재 상태 (하모니) — 새 세션/새 컴퓨터 "첫 읽기" 문서

> ⚠️ Claude 자동 메모리(`~/.claude/.../memory`)는 **이 컴퓨터에만 있음 → 새 컴퓨터엔 안 옴.** 이 문서가 git으로 넘어가는 인수인계 기준이다. **새 컴퓨터: 저장소 clone → `CLAUDE.md` + 본 문서 읽기 → 바로 작업.**

## 0. 새 컴퓨터 첫 셋업 (clone 직후 — repo엔 `node_modules`·`.env` 없음)
1. `git clone https://github.com/somoim-team/appintoss-meetup.git` (또는 `git pull`)
2. **Node.js 설치** (웹 테스트는 아무 LTS면 됨. 백엔드를 로컬 구동할 때만 ≥22.5 — 단 백엔드는 AWS에 떠 있어 로컬 불필요)
3. **`npm --prefix apps/miniapp install`** (node_modules 복원, package-lock 기준)
4. **`apps/miniapp/.env` 생성**(gitignore라 repo에 없음):
   ```
   VITE_API_BASE=https://3.39.167.74.nip.io
   ```
   ⚠️ 안 만들면 `localhost`로 빌드돼 합주(공유) 안 됨.
5. 실행 `npm --prefix apps/miniapp run dev:web` → http://localhost:5173 · 빌드 `npm --prefix apps/miniapp run build:web` → `dist`
6. (토스 샌드박스 `granite dev` / `ait deploy` 쓸 때만) ait·granite CLI + adb 별도 설치.
> `apps/api`는 무의존(node_modules 없음). 백엔드는 AWS 운영 중이라 새 PC서 안 돌려도 됨.

## 4. 실행 / 배포
- 로컬 미리보기: `npm --prefix apps/miniapp run dev:web` (vite, :5173). 토스 샌드박스: `cd apps/miniapp && granite dev` (**ASCII 경로 필수** — 한글 경로 헤더 버그).
- 빌드: `npm --prefix apps/miniapp run build:web` → `dist`.
- **서버 재배포:** dist를 scp → `sudo cp -rT ~/distXXX /opt/harmony-web && sudo chmod -R a+rX /opt/harmony-web && sudo systemctl reload nginx`. **chmod 필수**(안 하면 nginx가 못 읽어 흰 화면).
- SSH: `ubuntu@3.39.167.74` (Ubuntu 26.04), 키=`Downloads\RSA_AppInToss_pem.pem`(**저장소 금지**, TEMP 사본+icacls 후 사용). 조장 승인 하 AI SSH 허용(DL-021). systemd: `harmony-api`·`nginx`·`certbot.timer` 모두 enabled(24/7).
