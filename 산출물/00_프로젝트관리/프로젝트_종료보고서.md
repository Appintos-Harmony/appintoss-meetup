# 프로젝트 종료 보고서 (하모니)

> CLAUDE.md §11.2 필수 12항목 기준. 본 보고서는 요약·판정만 담고, 상세 수치·로그는 각 기준 문서(테스트 결과서·배포 절차서·의사결정 기록 등)를 단일 출처로 링크한다. 작성 시점 2026-06-24, 발표 2026-06-26 14:00. 실측 사실과 가정(Assumption)·미해결(Open Question)을 구분해 적는다.

## 1. 프로젝트 목적

앱인토스에 등재 가능한 비게임 미니앱을 7일 안에 실제 배포·시연 가능한 상태로 완성하고, ChatGPT Pro(통제면)·Claude Code·Codex(실행면)·사람(승인면)의 3에이전트 라이프사이클을 재사용 가능한 형태로 증명하는 것이다(CLAUDE.md §1·§19).

최종 제품은 **하모니(harmony)** — 앱인토스 안에서 피아노·기타·베이스·드럼을 터치와 카메라 손 제스처로 연주하고, 혼자 여러 악기를 비동기 레이어로 쌓아 합주를 만든 뒤 코드·커뮤니티로 공유하는 미니앱이다. 초기 주제는 오프라인 소모임 밋업이었으나 2026-06-21 악기 합주 앱으로 전환했다([의사결정_기록](의사결정_기록.md) DL-018, DL-019).

## 2. 최종 범위와 제외 범위

### 포함(구현·develop 통합 완료)
- 닉네임 온보딩 + `getAnonymousKey` 익명 식별(계정·로그인 없음, DL-016)
- 풀스튜디오: 악기/스타일 콤보, 28코드 매트릭스(7루트×4종류), 멜로디 건반, 기타/베이스 크로매틱 패드, 드럼 8패드
- 카메라 손 제스처 연주(MediaPipe HandLandmarker) + 제스처 효과음, 터치 폴백
- 녹음(activeChord 변경 기록 reducer)·구간 반복·음 편집(피아노롤)·재생바(스크럽)
- 비동기 합주: 공유 코드 생성/조회/얹기(1.5초 polling, 실시간 아님)
- 커뮤니티 보드: 게시·들어보기·좋아요·다중 가져오기·댓글·신고(임계 3명 자동 숨김)
- 백엔드 AWS 배포(HTTPS), 정적 앱 + API 동일 도메인 서빙

### 제외(범위 밖·후속)
- WebSocket 실시간 합주(레이턴시로 비동기 채택, DL-019)
- 토스 로그인·실명 신원·계정/권한 시스템(비사업자, DL-016)
- 오디오 파일 업로드, 결제, 인앱 광고
- 합주 듣기 시 트랙별 실제 샘플 음색(현재 합성 폴백, 구현내역 §10)
- 운영자 화면(커뮤니티 신고는 임계 자동 숨김으로 대체)

스코프는 축소 MVP(DL-019)에서 조장 권한으로 풀버전(DL-022)으로 확대됐다. 일정 리스크를 안고 핵심(피아노 코드+멜로디+합주)부터 단계 빌드했다.

## 4. 아키텍처 요약

- **미니앱**(`apps/miniapp`): React + TypeScript + Vite + Granite(앱인토스 프레임워크). 라우터(홈/스튜디오/커뮤니티/설정) + 온보딩 게이트. 오디오 엔진 v2(Tone.js, 실제 샘플 + 합성 폴백), 제스처(MediaPipe), 순수 도메인 로직(chordReducer·tuning·events·loop·noteEdit·notes)을 분리해 단위테스트 대상으로 둠.
- **백엔드**(`apps/api/server.mjs`): Node 24 `node:http` + `node:sqlite`, **외부 의존성 0**. 엔드포인트 = `GET /healthz`·`GET /community`·`POST /sessions`·`GET /sessions/:code`·`POST /sessions/:code/tracks`·댓글/신고/숨김. 인증 없음(코드=접근, author_key=클라 자기신고 약한 소유권, 데모 한정). 멱등 마이그레이션·콘텐츠 해시 기반 중복방지·신고 임계 자동 숨김 포함.
- **합주 모델**: 실시간 스트리밍 대신 공유 코드 + 1.5초 polling 비동기 레이어. 트랙별 owner·events·instrument·style 저장.
- **인프라**: AWS Ubuntu 26.04 · Node 24.17 · systemd `harmony-api`(:8080) + nginx(정적 `/opt/harmony-web` + API 리버스프록시, 동일 HTTPS 도메인) + Let's Encrypt(certbot.timer 자동갱신). 운영 URL `https://3.39.167.74.nip.io`.

상세: [프로그램_목록](../05_개발설계/프로그램_목록.md), [하모니_스튜디오_구현내역](../05_개발설계/하모니_스튜디오_구현내역.md), [배포_실행절차서](../07_배포운영/배포_실행절차서.md).

## 9. AI 파이프라인 적용 결과

3에이전트 구조(ChatGPT Pro 통제면 / Claude Code·Codex 실행면 / 사람 승인면)를 작업지시서(TASK)·독립검토서(REVIEW)·결정요청서(DECISION)·의사결정 기록(DL)이라는 문서 메시지 버스로 운영했다. P0 작업은 주 구현 1 + 다른 계열 독립 검토 1 + 사람 승인 1을 거쳤다(CLAUDE.md §6·§7).

단계별 역할·입출력·자동 검증·사람 승인, 발견된 AI 오류·사람 개입 실제 사례는 [AI개발_라이프사이클_평가서](../09_AI개발파이프라인/AI개발_라이프사이클_평가서.md)와 [평가_25점_대응표](../09_AI개발파이프라인/평가_25점_대응표.md)를 단일 기준본으로 둔다(중복 작성 금지).

## 10. 사람 검토와 수정 사례

평가서 §"발견된 AI 오류·사람/가드 개입"에 기록된 실제 사례 중 대표:

- **독립검토가 PR을 Rework로 차단**: 오디오 PR(코드 품질 GO 수준)을 REVIEW-032가 소유권 문서 불일치로 Rework 판정 → 조장(이상혁)이 소유권 확정(DL-20260622)하고 증빙을 연결한 뒤 GO.
- **자기권한 확대 차단**: AI가 `settings.json` 권한을 스스로 넓히려 한 시도를 자동 분류기 가드가 거부 → 사람이 권한을 적용(DL-012·DL-014).
- **보안 결함 차단**: Codex가 커밋 헬퍼의 pathspec magic 우회를 NO-GO(REVIEW-011) → 수정 후 GO(REVIEW-012) → 사람 승인 후 커밋.
- **조장 슈퍼권한 결정**: 스코프 축소→풀버전 복귀(DL-022), 주제 전환(DL-018) 등 범위·규칙 변경은 이상혁(조장)이 결정하고 AI가 그대로 실행, AI 자기수정 가드레일은 별도 유지.

근거·연결: [의사결정_기록](의사결정_기록.md), [AI개발_라이프사이클_평가서](../09_AI개발파이프라인/AI개발_라이프사이클_평가서.md).

## 11. 재사용 가능한 구성요소

다음은 제품(하모니)에 특화되지 않아 다음 앱에서 그대로 재사용 가능하다.

- **3에이전트 하네스**: `CLAUDE.md`·`AGENTS.md`·`CHATGPT_PRO_운영지침.md`, `.claude/`(agents 9·skills 5·rules 4), `.agents/skills/`, `산출물/09_AI개발파이프라인/`(공통 작업계약·역할매트릭스·TASK/REVIEW/DECISION 템플릿).
- **검증·자동화 스크립트**: `tooling/scripts/`(검증_전체·링크_검증·세션_시작_컨텍스트·팀공유문서_검증·커밋.mjs), git hook(pre-commit 비밀값·pre-push main 보호), `.github/workflows/ci.yml`.
- **운영 규칙**: 한글 산출물 경로 규칙, 문서 메타데이터·사실/가정 구분, 커밋 자동·푸시 사람 게이트(DL-012), 브랜치 전략(DL-014).

제품 특화(재사용 불가): 오디오 엔진·제스처·악기 UI·합주 백엔드·하모니 화면. 구분 상세는 [평가_25점_대응표 §4](../09_AI개발파이프라인/평가_25점_대응표.md).

## 12. 다음 프로젝트에서 개선할 사항

- **플랫폼 등록을 일정 초반에 차단 해소**: appName·앱 등록이 막판 크리티컬 패스가 됐다. Gate 0에서 실제 등록 ID까지 확정해 `granite.config`에 박아두면 막판 교체 리스크가 사라진다.
- **실기기 검수를 구현과 병행**: 헤드리스로 못 잡는 소리·카메라·2기기 항목이 마지막까지 미검증으로 남았다. 실기기 회귀를 일일 캐던스로 끌어올린다.
- **주제 확정을 Gate 0 전에 동결**: 6/21 주제 전환으로 밋업 기준 산출물이 폐기됐다. 주제 토론·확정을 착수 직후 끝내 재작업을 줄인다.
- **번들 스플리팅·CSP 사전 검증**: MediaPipe WASM·외부 오디오 샘플의 토스 WebView CSP, 단일 청크 번들을 미리 검증·분할한다.
- **익명키 등 SDK 연동을 mock으로 미루지 않기**: 식별 같은 핵심 SDK 호출의 실연동·실패 폴백을 초반에 끝낸다.
