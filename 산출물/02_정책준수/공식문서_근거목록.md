## 현재 상태

2026-06-21 앱인토스 `ax`(MCP/CLI) 연결 완료. 위 표는 `ax search docs` / `ax get doc`로 **공식 문서 원문을 직접 확인**해 기록했다. SDK 함수·정책은 공식 근거로만 기록하며 미확인 항목은 추정하지 않는다. 관련: [리스크 관리대장](../00_프로젝트관리/리스크_관리대장.md) R-001(해소).

## 검증 체크리스트 (CLAUDE.md §4)

| 항목 | 상태 | 비고 |
|---|---|---|
| 현재 지원 SDK·생성 도구 | 확인 | SDK+API, 디자인=앱빌더/Figma+TDS (#5) |
| 비게임 출시 체크리스트 | 부분 | 상위 가이드 스텁 → 기능별 sub-page 추후 |
| WebView 렌더링 제약 | 부분 | iframe 금지 확인(#6), 세부 추후 |
| 앱 번들 빌드 방식 | 미확인 | 추후 |
| 샌드박스·실제 토스 앱 테스트 절차 | 부분 | 샌드박스 mock·실기기 QR(#4) |
| 사용자 식별·토스 로그인 조건 | 확인 | 토스 로그인만/비사업자 불가/getAnonymousKey 대안 (#2~#4) |
| 사업자 필요 기능 | 확인 | 수익화·토스 로그인만 사업자 필요 → 우리는 불필요(DL-016) |

| 내비게이션 바·뒤로가기 동작 | 미확인 | 자체 뒤로가기 UI 금지(§12) |
| 외부 API·CORS·서버 간 인증 | 부분 | mTLS 필요(#6) |
| 소셜·만남·채팅 분류 기준 | 확인 | 명시 금지 없음, 초대 코드형 안전 (#1) |
| 신고·차단·운영 요건 | 미확인 | 저작권 신고 가이드만 확인, 일반 신고 추후 |
| 개인정보 수집·삭제 요건 | 부분 | 최소 수집 방침, 세부 추후 |
