# 통합 테스트 계획서 (하모니)

> 계획만 담는다. 실행 결과는 [통합테스트_결과서](통합테스트_결과서.md).

## 1. 대상과 목적
클라↔백엔드↔여러 사용자 흐름 + 실기기(소리·카메라·2기기 합주) 검증.

## 2. 범위
- 헤드리스: `/healthz`·`/community`·`/sessions`·`/tracks`·`/comments`·`/report`·`/like`·`/hide` + 클라 흐름
- 실기기(아이폰 13·갤럭시 S23 Ultra): 실제 소리·카메라 제스처·2기기 합주(IT-RT)

## 3. 통합 테스트 시나리오
ID: API `IT-API`, 보안 `IT-SEC`, 클라 `IT-CL`, 실기기 `IT-RT`.
