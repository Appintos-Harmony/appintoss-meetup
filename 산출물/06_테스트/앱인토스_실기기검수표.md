# 앱인토스 실기기 검수표 (하모니)

브라우저 헤드리스에서 못 잡는 항목(소리, 카메라, 2기기 합주)을 실기기에서 사람이 직접 확인한다. 결과 칸은 실제로 본 것만 적는다(미검증/Pass/Fail). 안 돌려본 항목은 미검증으로 둔다.

## 실행 절차 (토스 샌드박스)

1. ASCII 경로에서 `cd apps/miniapp` 후 `granite dev`. 한글 경로면 `x-react-native-project-root` 헤더 버그가 난다.
2. Android USB를 파일전송 모드로 연결하고 `adb reverse tcp:5173 tcp:5173`, `adb reverse tcp:8081 tcp:8081`.
3. 토스 샌드박스 앱에서 비즈니스 로그인 후 앱 선택, 토스 인증, 등록 ID `harmony`로 진입. `intoss://meetup-lite`는 과거 RT 검증 당시 사용한 테스트 진입값일 뿐 현재 진입값이 아니다. (2026-06-25 정식 등록·심사 제출 → 2026-06-26 테스트 트랙 출시(20260626-1) → 2026-06-26 정식 전체공개(프로덕션) 출시 완료. 등록 ID로 재진입해 RT 재확인 가능.)
4. 백엔드는 `.env`의 `VITE_API_BASE`=`https://3.39.167.74.nip.io`를 그대로 쓴다(고정 HTTPS).
