# 앱인토스 실기기 검수표 (하모니)

> **헤드리스(브라우저)에서 검증 못 한 항목**을 실기기에서 사람이 검증한다. 결과 칸은 실제 확인 후 채운다(미검증/Pass/Fail).

## 실행 절차 (토스 샌드박스)
1. ASCII 경로에서 `cd apps/miniapp` → `granite dev` (한글 경로 시 헤더 버그).
2. Android USB(파일전송 모드) 연결 → `adb reverse tcp:5173 tcp:5173` + `adb reverse tcp:8081 tcp:8081`.
3. 토스 샌드박스 앱 → 비즈니스 로그인 → 앱 선택 → 토스 인증 → `intoss://meetup-lite`.
4. 백엔드는 고정 HTTPS(`.env` `VITE_API_BASE`=`https://3.39.167.74.nip.io`) 자동 사용.
