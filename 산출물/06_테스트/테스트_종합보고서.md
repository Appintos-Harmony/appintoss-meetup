## 4. 실기기 검수 (예정)

브라우저 헤드리스가 못 잡는 항목(실제 소리·카메라 손 인식·2기기 합주)을 토스 샌드박스 실기기에서 사람이 확인한다. 현재 15항목 중 대부분 **미검증**이며, 카메라 권한 허용·프리뷰 표시만 부분 확인됐다.

| 구분 | 항목 | 현황 |
|---|---|---|
| 부분 확인 | RT-04 카메라 권한·프리뷰 | 2026-06-21 S23 Ultra 샌드박스에서 권한 허용·프리뷰 표시 확인. 손 추적·제스처 매핑은 미검증 |
| 부분 확인 | RT-06 카메라 거부 폴백 | 카메라 자체 동작은 확인. 권한 거부 폴백 경로는 별도 실측 필요 |
| 미검증 | RT-01~03, 05, 07~15 | 진입·소리·메트로놈·녹음재생·저장복구·2기기 합주·합쳐듣기·뒤로가기·핀치줌·네트워크 |

P0(데모 필수): RT-02(터치 코드 소리)·RT-04(카메라 손 인식)·RT-05(제스처 연주)·RT-10(2기기 공유→받기)·RT-11(합주 합쳐듣기 소리). 하나라도 Fail이면 발표 시연 대안으로 전환. 절차·항목·판정 기준은 [앱인토스_실기기검수표](앱인토스_실기기검수표.md), 카메라 WebView 검증 절차는 [토스WebView_카메라_샌드박스_테스트절차](토스WebView_카메라_샌드박스_테스트절차.md).

참고: 제스처 핸드트래킹은 모바일 브라우저 스파이크에서 검증됨(커밋 923e545, 45/30fps). 토스 WebView 내 동작은 위 부분 확인까지 진행됐고 손 추적 매핑은 미검증으로 남았다.

## 6. 독립 검토 현황 (정직 표기)

- 단위·통합 실행은 Claude Code 하네스가 수행했다(투명 기록).
- **Codex 독립 검토는 본 종합 보고서에 대해 미실시(Codex 예정).** 과거 폴리포니 회귀 세트는 독립검토서 REVIEW-20260622-032 M-3 근거로 추가됐다(단위 계획서 §3.2 인용).
