# 단위 테스트 계획서 (하모니)

> 계획만 담는다. 실행 결과는 [단위테스트_결과서](단위테스트_결과서.md)가 담당한다.

## 1. 대상과 목적
악기 합주 미니앱 「하모니」의 **순수 로직 모듈**(Web Audio·Tone.js·카메라 비의존)을 헤드리스(vitest)로 검증한다.

## 2. 범위
- 포함: `chordReducer.ts`·`tuning.ts`·`events.ts`·`loop.ts`·`noteEdit.ts`·`notes.ts`
- 제외(실기기): 실제 소리·제스처·카메라 → [앱인토스_실기기검수표](앱인토스_실기기검수표.md)
