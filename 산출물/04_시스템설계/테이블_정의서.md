# 테이블 정의서 (하모니)

> 백엔드 `apps/api/server.mjs`의 실제 SQLite 스키마. 합주 공유만 서버 저장(솔로 곡은 클라 localStorage).

## sessions — 합주 세션
| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| code | TEXT | PK | 6자리 공유 코드(혼동문자 0/1/I/O 제외) |
| name | TEXT | | 세션 이름(기본 "하모니 세션") |
| bpm | INTEGER | | 박자(기본 100) |
| created_at | INTEGER | | 생성 epoch(ms) |

## tracks — 트랙(레이어)
| 컬럼 | 타입 | 제약 | 설명 |
|---|---|---|---|
| id | INTEGER | PK AUTOINCREMENT | 트랙 ID |
| code | TEXT | (sessions.code 참조) | 소속 세션 |
| owner | TEXT | | 작성자 닉네임 |
| events | TEXT | | 코드 이벤트 JSON 배열(아래) |
| created_at | INTEGER | | 생성 epoch(ms) |

> 외래키 제약은 미설정(앱 레벨에서 세션 존재 확인 후 insert). 한 세션에 N개 트랙 = 비동기 합주 레이어.

## events JSON 요소 (`ChordEvent`)
`apps/miniapp/src/audio/chordReducer.ts`와 계약 일치.
| 필드 | 타입 | 설명 |
|---|---|---|
| tick | number | 세션 공통 tick(4/4·BPM100, 1박=4tick) — 기기 간 정렬 |
| phase | 'on' \| 'off' | noteOn / noteOff |
| chord | 'C'\|'Am'\|'F'\|'G' | 코드 |
| source | 'touch'\|'gesture' | 입력 방식(기록용) |

## 인덱스·정합성
- `sessions.code` PK(고유). 코드 생성 시 중복 검사 후 재생성.
- `tracks` 조회는 `WHERE code=? ORDER BY id`(생성 순).
- 무결성: `events`는 서버에서 `Array.isArray` 검증 후 저장. 손상 JSON은 조회 시 방어(클라).
