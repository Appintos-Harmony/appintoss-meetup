# 서비스 기능 정의서 (하모니)

> ⚠️ 본 문서는 **하모니(악기 합주) 기준으로 재작성**됨(피벗 DL-018). 이전 소모임 밋업 FR-001~014는 폐기.
> 제품 한 줄: 토스 안에서 **악기를 연주하고, 친구 트랙 위에 내 악기를 얹어** 한 곡을 완성하는 미니앱. 실제 구현 기준.

## 기능 요구사항 (FR)
| ID | 기능 | 설명 | 상태 |
|---|---|---|---|
| FR-ID-01 | 익명 온보딩 | getAnonymousKey + 닉네임 1회(가입/로그인 아님) | 구현 |
| FR-PLAY-01 | 코드 연주 | C·Am·F·G 기본 패드 + 코드 직접 고르기(28코드 중 최대 6), AudioContext unlock | 구현 |
| FR-PLAY-02 | 제스처 연주 | 카메라 손 위치→코드존, 편손=지속/주먹=멈춤, 카메라 실패 시 터치 폴백(동시 바인딩 금지) | 구현·실기기 RT-04·05·06 아이폰 13·갤럭시 S23 Ultra 육안 성공(EV-203·204·205) |
| FR-PLAY-03 | 멜로디 연주 | 피아노 건반 / 기타·베이스 계이름 패드, 옥타브 이동 | 구현 |
| FR-PLAY-04 | 드럼 연주 | 드럼 패드(킥·스네어·하이햇 등), 코드/멜로디 무관 | 구현 |
| FR-PLAY-05 | 악기·음색 선택 | 피아노/기타/베이스/드럼 선택, 악기별 음색 2종(녹음 중 변경 차단) | 구현 |
| FR-REC-01 | 메트로놈·카운트인 | 3/4·4/4·6/8 선택(기본 4/4)·BPM100, 1마디 카운트인, tick 클럭 | 구현 |
| FR-REC-02 | 이벤트 녹음·재생 | tick 기반 코드 이벤트 기록/재생 | 구현 |
| FR-SAVE-01 | 로컬 저장·복구 | localStorage 저장·홈 목록·열기·삭제·재진입 복구 | 구현 |
| FR-SHARE-01 | 공유 | 내 트랙 업로드→코드 발급→클립보드 | 구현 |
| FR-SHARE-02 | 받기 | 코드/클립보드로 친구 트랙 로드(실패 시 프리로드 폴백) | 구현 |
| FR-SHARE-03 | 얹기 | 세션에 내 레이어 추가(비동기 합주) | 구현 |
| FR-SHARE-04 | 동기화 | 1.5초 polling으로 새 트랙 반영(실시간 아님) | 구현 |
| FR-JAM-01 | 합주 합쳐듣기 | 세션 전체 트랙을 트랙별 음색으로 동시 재생 | 구현·실기기 RT-11 아이폰 13·갤럭시 S23 Ultra 육안 성공(EV-208) |
| FR-COMM-01 | 커뮤니티 보드 | 공개 게시물 목록(최신순/인기순), 카드(제목·제작자·코드·재생수·파생수) | 구현 |
| FR-COMM-02 | 들어보기 | 게시물 트랙별 음색 미리듣기 | 구현 |
| FR-COMM-03 | 가져오기·합주 올리기 | 게시물 가져와 스튜디오 로드(출처 보존)→내 레이어 얹어 발행(파생수 +1) | 구현 |
| FR-COMM-04 | 댓글·신고·숨김 | 댓글 작성, 신고 누적 시 자동 숨김(비가역) | 구현 |

## 비기능 요구사항 (NFR)
| ID | 내용 |
|---|---|
| NFR-01 | HTTPS 필수(토스 WebView) — nginx+Let's Encrypt |
| NFR-02 | 핀치줌 비활성, 자체 뒤로가기 UI 금지(토스 공통) |
| NFR-03 | 비게임=TDS 사용(@toss/tds-mobile) |
| NFR-04 | 100% 라이트 테마(DL-019) |
| NFR-05 | TypeScript strict, reducer 단위테스트(vitest 7파일 58케이스) |
| NFR-06 | 오디오 지연 체감(목표 수치 미정, 정량 측정 미실시 — 실기기 RT-02·08·11 육안) |
| NFR-07 | 앱인토스 앱 등록·심사 제출 → 2026-06-27 정식 전체공개(프로덕션) 출시 완료 |
| NFR-08 | 동기화는 1.5초 폴링(WebSocket 아님), 새 트랙 반영 ≤3초 |
| NFR-09 | 트랙=코드+tick 이벤트 경량 저장(곡당 수 KB, localStorage ≤5MB) |
| NFR-10 | 토스 WebView 표준 Web API만(오디오·카메라), 네이티브 의존 없음 |
| NFR-11 | 카메라·오디오·네트워크 실패 시 폴백 보장(연주 중단 없음) |

## 정책 요구사항 (POL)
| ID | 내용 |
|---|---|
| POL-01 | 토스 로그인만 허용·자체 로그인/회원가입 금지 → getAnonymousKey(DL-016) |
| POL-02 | 비게임 카테고리(엔터>음악), 표준 Web API(오디오/카메라) |
| POL-03 | 합주·커뮤니티는 코드/공개 게시 기반(불특정 사용자 추천/연결·1:1 채팅 없음) |
| POL-04 | 성인·연령 확인 미구현(MVP 비범위), 정식 운영 확대 시 검토 |

## 범위 외(컷)
WebSocket 실시간 합주(1.5초 폴링으로 대체) · 계정/권한 체계(POL-01 익명키) · 오디오 파일 업로드(코드+tick 이벤트 경량 저장으로 대체) · 운영자 화면(신고 누적 자동 숨김으로 대체) · 사용자 추천·근처 연결(POL-03) · 성인·연령 확인(POL-04).

> 비고: 드럼·기타/베이스·3박자(3/4·6/8)·코드 직접 선택·멜로디·공개 커뮤니티는 초기 축소(DL-019) 당시 비범위였으나 **풀버전(DL-022)에서 구현 완료**되어 위 FR로 편입됨.
