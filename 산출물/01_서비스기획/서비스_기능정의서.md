# 서비스 기능 정의서 (하모니)

> ⚠️ 본 문서는 **하모니(악기 합주) 기준으로 재작성**됨(피벗 DL-018). 이전 소모임 밋업 FR-001~014는 폐기.
> 제품 한 줄: 토스 안에서 **악기를 연주하고, 친구 트랙 위에 내 악기를 얹어** 한 곡을 완성하는 미니앱. 실제 구현 기준.

## 기능 요구사항 (FR)
| ID | 기능 | 설명 | 상태 |
|---|---|---|---|
| FR-ID-01 | 익명 온보딩 | getAnonymousKey + 닉네임 1회(가입/로그인 아님) | 구현 |
| FR-PLAY-01 | 터치 4코드 연주 | C·Am·F·G 패드, AudioContext unlock, 음색 | 구현 |
| FR-PLAY-02 | 제스처 연주 | 카메라 손 위치→코드존, 편손=지속/주먹=멈춤, 카메라 실패 시 터치 폴백(동시 바인딩 금지) | 구현·실기기 RT-04·05·06 아이폰 13·갤럭시 S23 Ultra 육안 성공(EV-203·204·205) |
| FR-REC-01 | 메트로놈·카운트인 | 4/4·BPM100, 1마디 카운트인, tick 클럭 | 구현 |
| FR-REC-02 | 이벤트 녹음·재생 | tick 기반 코드 이벤트 기록/재생 | 구현 |
| FR-SAVE-01 | 로컬 저장·복구 | localStorage 저장·홈 목록·열기·삭제·재진입 복구 | 구현 |
| FR-SHARE-01 | 공유 | 내 트랙 업로드→코드 발급→클립보드 | 구현 |
| FR-SHARE-02 | 받기 | 코드/클립보드로 친구 트랙 로드(실패 시 프리로드 폴백) | 구현 |
| FR-SHARE-03 | 얹기 | 세션에 내 레이어 추가(비동기 합주) | 구현 |
| FR-SHARE-04 | 동기화 | 1.5초 polling으로 새 트랙 반영(실시간 아님) | 구현 |
| FR-JAM-01 | 합주 합쳐듣기 | 세션 전체 트랙을 트랙별 음색으로 동시 재생 | 구현·실기기 RT-11 아이폰 13·갤럭시 S23 Ultra 육안 성공(EV-208) |
