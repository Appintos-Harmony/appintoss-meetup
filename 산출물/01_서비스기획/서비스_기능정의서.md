# 서비스 기능 정의서

> 기준: PRD(develop `5888cbf`). 트랙: **초대 코드형**. 화면/API는 **예정**, 앱인토스 SDK·정책 의존 항목은 **미검증**(추정 금지). 추적: [요구사항_추적표](요구사항_추적표.md).

각 기능 단위: 관련 FR · 주체 · 선행조건 · 정상 흐름 · 예외/오류 · 안전·정책 연계 · 관련 화면/API(예정).

## A. 계정

### A1. 로그인·약관 동의 (FR-001)
- 주체: 사용자 · 선행: 미니앱 진입.
- 정상: 토스 로그인 → 약관·안전 규칙 동의 → 진입.
- 예외: 미동의 시 진입 차단. 로그인 실패 시 재시도 안내.
- 정책: 로그인·약관 구현 사양 **미검증**(MCP 필요, POL-002 연계).
- 화면/API: 예정.

### A2. 최소 프로필 (FR-002)
- 주체: 사용자 · 선행: 로그인.
- 정상: 닉네임·넓은 지역·관심사 입력/수정.
- 예외: 필수값 누락 차단. 불필요 개인정보 미수집(NFR-003).
- 화면/API: 예정.

### A3. 계정 탈퇴·데이터 삭제 요청 (FR-013)
- 주체: 사용자 · 선행: 로그인.
- 정상: 탈퇴/삭제 요청 → 접근 불가 처리.
- 예외: 진행 중 모임 보유 시 처리 정책(예정). 신고 데이터 접근 제한(NFR-003).
- 화면/API: 예정.

## B. 모임

### B1. 모임 생성 (FR-003)
- 주체: 주최자 · 선행: 로그인.
- 정상: 제목·일시·대략 장소·정원·준비물·강도·취소 기준·**안전 규칙** 입력 → 생성.
- 예외: 필수값 누락 시 생성 불가. 과거 일시 차단.
- 안전: §14 안전 규칙(금지구역·무기류·**실제 경찰 제복·표식 혼동 표현 금지**·접촉 기준·음주 금지·악천후 취소·시작/종료 인원·**즉시 중단 신호**·**집결 위치 공개 노출 최소화**·이탈/부상/분쟁 대응)을 생성 단계의 입력/확인 기능으로 포함.
- 화면/API: 예정.

### B2. 초대 코드/링크로 모임 상세 진입 (FR-004)
- 주체: 사용자 · 선행: 유효 초대 코드/링크 보유.
- 정상: 코드 입력/링크 → 모임 상세(일시·넓은 지역·정원·준비물·안전 규칙) 조회.
- 예외: 무효/만료 코드 거부. 비공개 모임은 코드 없이 접근 불가.
- 화면/API: 예정.

### B3. 모임 목록 (FR-014)
- 주체: 사용자 · 선행: 로그인.
- 정상: **내가 만든 모임·신청한 모임·초대 코드로 접근한 모임만** 표시.
- 예외: 공개 추천·탐색·랜덤 노출 없음(타인 모임 비노출). 신규 접근은 초대 코드로만.
- 화면/API: 예정.

## C. 참가

### C1. 참가 신청 (FR-005)
- 주체: 사용자 · 선행: 모임 상세 접근.
- 정상: 신청 → 상태 `대기`.
- 예외: 중복 신청 **서버 차단**(NFR-002). 마감/취소 모임 신청 불가.
- 화면/API: 예정.

### C2. 승인·거절·대기 (FR-006)
- 주체: 주최자 · 선행: 신청 존재.
- 정상: 승인 → `승인`, 거절 → `거절`, 보류 → `대기`.
- 예외: 권한자만(객체 단위 인가, NFR-001). **정원 초과 승인 차단**(NFR-002).
- 화면/API: 예정.

### C3. 참가 취소 (FR-007)
- 주체: 참가자 · 선행: 신청/승인 상태.
- 정상: 취소 → 상태 갱신, **정원 복구**.
- 예외: 종료 모임 취소 정책(예정).
- 화면/API: 예정.

## D. 공지·진행

### D1. 주최자 공지 (FR-008)
- 주체: 주최자 · 선행: 모임 보유.
- 정상: 공지 작성 → 참가자에게 노출.
- 예외: 권한자만. 화면/API: 예정.

### D2. 모집 마감·모임 취소 + 통지 (FR-009)
- 주체: 주최자 · 선행: 모임 보유.
- 정상: 마감/취소 → 참가자 상태 **일관 갱신** + 통지.
- 예외: 권한자만. 상태 전이 서버 강제(NFR-002).
- 화면/API: 예정.

### D3. 참가 코드/QR 체크인 (FR-010)
- 주체: 주최자·참가자 · 선행: 승인 상태.
- 정상: 코드/QR로 출석 확인.
- 예외: **상시 위치 미추적**(POL-003). 화면/API: 예정.

## E. 신고·운영

### E1. 신고 접수 (FR-011)
- 주체: 사용자 · 선행: 로그인.
- 정상: 사용자/모임/콘텐츠 신고 접수.
- 예외: 중복 신고 처리(예정). 화면/API: 예정.

### E2. 최소 운영자 화면 (FR-012)
- 주체: 운영자 · 선행: 운영 권한.
- 정상: 신고 큐 조회 → 모임 비노출/사용자 제재 → **처리 기록(감사 로그)**.
- 예외: 권한 분리(NFR-001), 신고 데이터 접근 제한(NFR-003).
- 화면/API: 예정.
