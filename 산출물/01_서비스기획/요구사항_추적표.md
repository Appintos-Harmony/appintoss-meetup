## 5. 미커버·후속 (정직 표기)

- **FR-REC-01(메트로놈·카운트인)·FR-JAM-01(합주 소리)**: 단위·통합 모두 케이스 없음. 실시간 트랜스포트·실제 동시 재생 소리는 헤드리스로 검증 불가 → RT-07·RT-11(실기기)로만. 둘 다 미검증.
- **실기기(RT-01~15) 전부 미검증** — 사람 검수 대기. P0(데모 필수)=RT-02·RT-04·RT-05·RT-10·RT-11. 하나라도 Fail이면 시연 대안(영상/프리로드).
- **통합테스트 12/12는 과거 스냅샷(6372dc3)** — 이번 추적표 갱신 시 재실행하지 않았다. 단위테스트만 2026-06-23 재실행(58/58, 종료코드 0).
- **커뮤니티(SCR-C01~04)**: 화면명세는 있으나 미구현(스캐폴드). FR 미부여 — 범위 재진입 시 FR·테스트 ID 신규.
- **독립검토(Codex)**: 본 추적표 갱신은 Claude Code 단독 작성. Codex 독립검토 로그 없음 → 미실시(Codex 예정). 사람(이상혁/양록빈) 검토·승인 대기.
