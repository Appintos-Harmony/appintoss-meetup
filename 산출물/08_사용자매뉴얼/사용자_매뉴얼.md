# 사용자 매뉴얼 (하모니)

> 토스 안에서 악기를 연주하고 친구와 합주하는 미니앱.

## 1. 시작하기
- 토스에서 **하모니**를 열면 닉네임을 한 번 정해요(가입·로그인 없음).
- 바로 **스튜디오**로 들어가 연주를 시작해요.

## 2. 연주하기
- **👆 터치:** 화면의 **C·Am·F·G** 패드를 누르면 코드 소리가 나요. (처음 한 번 눌러야 소리가 켜져요)
- **👋 제스처:** 상단에서 제스처를 고르면 카메라가 켜져요. **손 위치 = 코드, 편 손 = 소리 / 주먹 = 멈춤.**
  - 카메라를 못 쓰면 자동으로 터치로 바뀌어요.

## 3. 녹음·재생
- **🥁 메트로놈**으로 박자를 맞춰요(4/4·BPM 100).
- **● 녹음**을 누르면 1마디 카운트인 후 녹음돼요. **■ 정지** → **▶ 재생**으로 들어봐요.
- **💾 이 연주 저장**으로 보관, **홈**에서 다시 열 수 있어요.

## 4. 친구와 합주하기
- **📤 공유:** 내 연주를 올리고 **공유 코드**를 복사해요. 친구에게 코드를 보내요.
- **📥 합주 받기:** 친구 코드를 복사한 상태로 누르면 친구 트랙이 들어와요(없으면 데모 트랙).
- **⬆ 얹기:** 그 위에 내 악기를 녹음해 올려요.
- **🎶 합주 듣기:** 세션의 **모든 트랙을 함께** 들어요(악기별 다른 음색).
- 새 트랙은 약 1.5초마다 자동으로 반영돼요.

## 5. 문제 해결
| 증상 | 확인 |
|---|---|
| 소리가 안 나요 | 코드를 한 번 눌러 소리를 켜고, 기기 음량/무음 모드 확인 |
| 카메라가 안 켜져요 | 권한 허용 또는 터치로 연주(자동 전환) |
| 공유가 안 돼요 | 네트워크 확인. 실패 시 데모 트랙으로 시연 |
| 뒤로 가려면 | 토스 기본 뒤로가기 사용(앱에 별도 버튼 없음) |

## 6. 안내
- 익명 식별(getAnonymousKey)만 사용하고 개인정보를 따로 받지 않아요.
- 합주 공유는 **코드**로만 연결돼요(불특정 사용자 추천 없음).
