# 화면설계서 콘텐츠 초안 (claude.ai 입력용)

> 이 문서는 **최종 화면설계서가 아니라**, claude.ai(클로드 디자인)에 붙여 화면설계서 비주얼(2단: 화면 목업+번호 콜아웃 ↔ Descriptions 패널)을 그리게 할 **화면별 텍스트 콘텐츠 원본**이다.
> 캡처 `C:\Users\DEV-PC\Desktop\화면설계서에 할 사진들\캡쳐 (1)\` 40장을 ux-designer 에이전트가 실제로 열람하고 저장소 코드·명세(`App.tsx`·`Onboarding.tsx`·`Studio.tsx`·`Settings.tsx`·`Community.tsx`, 하모니_화면명세서 등)와 대조해 작성했다. **변형 캡처(패드 눌림·악기 적용 등)는 새 화면이 아니라 기준 화면의 '상태'로 흡수**했다.

## 화면 ID 체계
`ONB`(온보딩) · `HOME`(홈) · `STU`(스튜디오) · `COM`(커뮤니티) · `SET`(설정) + 두 자리. (저장소 추적표는 온보딩=SCR-00이고 홈·설정·스튜디오·커뮤니티는 정식 SCR 번호 미부여 → 본 초안 ID는 작업용. 정식 번호 부여는 아래 '확인 필요' 참조.)

## claude.ai 사용법 (화면별 프롬프트 ②)
```text
화면: [예: 02_홈 / HOME-01 홈 허브]   ← 캡처에 맞게 이 줄만 바꿈
[해당 스크린샷 1장 첨부]

기준 설정(①) 포맷·예시 깊이 그대로, 아래 '핵심 콘텐츠'를 반영해 이 화면의 화면설계서 1페이지(HTML 아티팩트)를 만들어줘.
[여기에 아래 해당 화면 블록을 붙여넣기]
- 번호 배지는 캡처 실제 위치에 얹고, 우측 Descriptions와 1:1로 맞춰. 불확실하면 [확인필요].
```

**⑤ 피아노 건반(연주 영역)** — 2옥타브 동시 표시. 흰건반(도 레 미 파 솔 라 시 ×2옥타브) + 검은건반(도# 레# 파# 솔# 라#). 건반 하단에 한글 계이름 라벨. 누르면 즉시 발음(파랑 하이라이트, 캡처 32의 '미' 키), 떼면 정지. · 검은건반은 실제 피아노 배치(미↔파, 시↔도 사이 없음).

Descriptions
① **앱바** — 좌측 `‹ 스튜디오`(명시 링크, 스튜디오로 복귀) · 중앙 타이틀 `커뮤니티` · 우측 `↻`(새로고침, 목록 다시 불러오기) · `＋올리기`(선택 시 커뮤니티 올리기 시트[COM-04]로 이동). · 토스 공통 내비에 위임하므로 자체 뒤로가기 버튼 없음(`‹ 스튜디오`는 명시 링크).
② **정렬 탭** — `최신순`(기본, 서버 created_at desc) | `인기순`(좋아요(하트) 수 desc, 동률은 최신 순서 유지). 선택 시 같은 목록을 즉시 재정렬(클라 정렬, 새 화면 아님). 기준 캡처는 `최신순` 활성, variant(36)는 `인기순` 활성으로 카드가 하트 많은 순(4→2→0…)으로 재배열됨.
③ **음원 카드(목록)** — 카드마다: 이모지 아바타 · `음원명 – 작성자`(예: `내 합주 – 하모니`, `이상혁의 드럼 – 이상혁`) · 메타 `트랙 N · ▶ 재생수 · 이어 파생수`(예: `트랙 1개 · ▶ 5 · 이어 0`) · (파생곡이면) 보라색 출처 `🎵 소스: A님의 「곡명」 음원 사용`[확인필요: 기준 캡처에는 출처 줄이 보이는 카드 없음, 명세 §7.1 기준] · 버튼행 `[▶ 들어보기][＋ 담기][❤ 좋아요수][💬 댓글수]`.

  - `❤ 좋아요수` 선택 시 좋아요 토글(익명키 기준 1회, 중복 방지). 다른 이용자에게 교차 반영. [확인필요: 좋아요는 발표 빌드 미노출일 수 있음 — 그룹 메모]
  - `💬 댓글수` 선택 시 댓글 패널 열림(평면 댓글 ≤200자, 입력 '한마디 남기기', 보내기). 댓글 행의 신고는 누르면 `신고됨`으로 바뀌고 조용히 접수(즉시 안 사라짐), 서로 다른 3명 누적 시 자동 숨김.
④ **재생 바(트랜스포트, 카드 하단 펼침)** — `들어보기 ▶` 선택 시 노출. 버튼이 `▶ 재생`/`❚❚ 일시정지`로 토글(위치 유지). 진행 바 흰 동그라미 드래그로 스크럽, `0:08 / 0:15` 시간 표시. 다른 카드 재생 시 기존 정지. [확인필요: 기준/variant 캡처에는 재생 바 펼침 상태 미노출, 명세 §7.2 기준]
⑤ **하단 가져오기 바** — 담은 항목 ≥1일 때만 노출(없으면 미노출). `🎚 가져오기 (N개) → 스튜디오에 얹기`. 선택 시 스튜디오로 트랙을 복사해 얹기 준비[SCR-ST-06]. [확인필요: 기준 캡처는 담은 항목 0이라 미노출, 명세 §7.1 기준]
⑥ **페이저** — 하단 `‹ 이전  1 / 2  다음 ›`. 페이지당 개수는 화면 높이에서 동적 산출(하드코딩 없음, 리사이즈·회전 시 재계산·현재 페이지 자동 보정). 선택 시 같은 보드의 다른 페이지로 이동.
