# 하모니 커뮤니티 이미지 명세서 (스케치 → 와이어프레임 → 목업)

> 발표·보고용. **우리가 작업하는 커뮤니티 기능 화면**만 범위로 한정한다. 각 화면을 **스케치(러프) → 와이어프레임(구조·라벨) → 목업(고충실)** 3단계로 한 장에 담았다. **목업은 정합 머지된 `Community.tsx`(as-built) 기준**이라 실제 화면과 일치한다(기능 정의는 [기능명세서 v3](../05_개발설계/하모니_커뮤니티_기능명세서.md)).
> SVG 원본은 `커뮤니티_이미지/` 폴더(브라우저·슬라이드에서 열림). 6시선 검증 통과(경미 레이아웃 메모만).

## 화면 목록
| 화면 | 파일 | 담은 내용 |

## 화면별

### 1. 커뮤니티 보드
![커뮤니티 보드 스케치→와이어→목업](커뮤니티_이미지/커뮤니티_보드.svg)
서버 `listCommunity` 기반 카드 목록. 파생 카드엔 보라색 출처 크레딧("🎵 ○○의 △△ 위에 쌓음"). 좋아요 하트는 발표/심사 빌드 미노출(기능명세 §9).

### 2. 보드 3상태
![커뮤니티 보드 3상태](커뮤니티_이미지/커뮤니티_상태.svg)
로딩·빈·실패 — 빈 보드 콜드스타트는 시드곡으로 방어, 실패는 재시도.

### 3. 댓글 패널
![커뮤니티 댓글 패널](커뮤니티_이미지/커뮤니티_댓글.svg)
평면 댓글(≤200자) + 신고(3건 자동 숨김). 대댓글·멘션 없음.

### 4. 올리기 + 합주해서 올리기
![올리기/합주해서 올리기](커뮤니티_이미지/커뮤니티_올리기.svg)
내 곡 올리기(publish) + 가져온 곡 위 "합주해서 올리기"(출처 origin_code 강제).

## 비고
- 충실도 단계는 보고에서 "스케치로 발상 → 와이어로 구조 → 목업으로 확정"의 진화를 보여주는 용도.
- 목업의 이모지 아바타·카드는 곽소정 UI(정합 보존), 데이터·동선은 서버 보드(김민혁).
- 상세 동작/상태/계약은 기능명세서 v3 §4·§7, 화면 SCR 매핑은 화면명세서 참조.
