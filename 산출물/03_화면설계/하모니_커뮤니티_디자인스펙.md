# 하모니 커뮤니티 디자인 스펙 (피드) — theme.css 기반

> 기능/상태는 [하모니_커뮤니티_화면명세서.md](하모니_커뮤니티_화면명세서.md)(SCR-C01~C04), 데이터/정책은 라운드3(DEBATE-012). 이 문서는 **"어떻게 보이고 움직이나"**를 `apps/miniapp/src/theme.css` 토큰·클래스에 묶어 정한다. **새 색/폰트/디자인 언어 도입 금지, 100% 라이트, 스튜디오·홈과 룩 연속.**

## 0. 원칙
- 데이터 = 연주 이벤트 JSON(오디오 파일 아님). 실시간 = **폴링 1.5~3s + optimistic UI**(WebSocket 없음). 식별 = 익명키, 키 미발급 시 쓰기 503(페일클로즈드).
- 셸 = 기존 `.screen / .appbar("커뮤니티") / .content`. 자체 뒤로가기·핀치줌 금지.

## 1. 피드 (SCR-C01)
- **정렬 탭(상단 고정):** `.segment` + `.seg[data-on]` → `[최신 | 인기]`. 탭 전환 시 `.fade`로 리스트 갱신.
- **곡 카드 = `.card`(radius `--r-lg`, `--e2`), 세로 gap 12px:**
  - 좌: **`.track-av`** 원형 아바타(작성자 시그니처 컬러 `--t-*` + 악기 이모지/이니셜).
  - 중: 제목 `.t-body`(700) / 작성자·길이 `.t-cap .c-sub` (길이 표기 "1:24" 또는 "8마디").
  - 우: **▶ 들어보기** `.chip-ghost` · **❤️ 좋아요** `.chip`(하트+숫자).
- **좋아요 인터랙션(낙관적):** 탭 즉시 +1 반영 → 하트 `scale 1→1.3→1`(`@keyframes beat`, `--spring`) + 숫자 0.3s count-up + (가능 시) haptic. 실패 시 롤백 + 토스트. 서버 정합은 `UNIQUE(pub_id, anon_key)`가 보장(UI는 낙관적).
- **새 곡 등장(폴링):** 새 publication 감지 → 리스트 최상단 `.fade`(`fadeUp`, translateY) 슬라이드인 + 상단에 "새 곡 N개 ↑" `.chip` 노출(탭 시 스크롤 top).
- **소셜 프루프(헤더):** 누적 지표(총 재생수·총 좋아요·"N명이 얹음") — **presence("지금 N명") 금지**(동접 0이면 비참). 시드 데이터로 채울 땐 화면에 **"샘플" 라벨** 필수(문서규칙: 허위 수치 금지).

## 2. 상태 (전 화면 공통)
| 상태 | 디자인 |
|---|---|
| 로딩 | `.card` 형태 **스켈레톤 3~4개** + `--line` shimmer(부드러운 그라데이션). |
| 빈 | 중앙 이모지(🎵) + "아직 올라온 합주가 없어요. 첫 연주자가 되어보세요!" + `.btn` **"연주하러 가기"**(→스튜디오). |
| 오류(네트워크) | "앗, 잠시 연결이 끊겼어요" + `.btn` "다시 시도". |
| 점검(503 페일클로즈드) | "커뮤니티를 점검 중이에요" — 쓰기 막힘 안내(읽기는 가능 시 유지). |

## 3. 상세·듣기 (SCR-C02)
- **`.sheet`(바텀시트)** 또는 풀페이지: 큰 `.track-av` + 제목 `.t-title` + 트랙 구성(작성자·악기 `.chip`들) + **▶재생/정지** + **❤️좋아요** + `.btn` **"내 스튜디오로 얹기"**(fork) + `⋯` 신고.
- 재생: 이벤트 → 스튜디오 오디오 엔진 재사용(`createVoice`). 재생 중 `.track-av[data-playing="true"]` `bounce`.

## 4. 공개하기 (SCR-C03)
- 스튜디오 "올리기/구경 가기"에서 진입. **`.sheet`**: 제목 `.input` + (음색·길이 미리보기) + `.btn` **"공개"**. **5개 초과 시** `.btn` disabled + 토스트 "공개는 5개까지예요".

## 5. 내 음원 (SCR-C04)
- 내 공개곡 `.card` 리스트(좋아요수) + **`5/5`** 표시 + 공개취소/삭제 `.chip-ghost`.

## 6. 신고·차단 (정책 최소 — 심사 전 필수)
- 카드/상세 `⋯` → **신고**(사유 선택 `.sheet`) + **차단**("이 연주자 숨김"). 신고/차단 즉시 **로컬 숨김(optimistic)**. 약관 링크. (운영자 처리·자동 hidden은 백엔드.)

## 7. 컴포넌트 매핑 (theme.css — 새로 만들지 말 것)
| UI | 클래스 |
|---|---|
| 곡 카드 | `.card` |
| 정렬 탭 | `.segment` / `.seg[data-on]` |
| 좋아요·"새 곡"·악기 칩 | `.chip` / `.chip-ghost` |
| 상세·공개·신고 시트 | `.sheet` / `.backdrop` / `.sheet-row` |
| 작성자 아바타 | `.track-av`(재생 시 `bounce`) |
| CTA | `.btn` | 제목 입력 | `.input` |
| 등장/전환 애니 | `.fade`(`fadeUp`) · 좋아요 `beat` · `--spring`/`--ease` |

## 8. 데모 동선 (5분 시연용)
피드(인기) → 카드 **들어보기** → **좋아요(하트 버스트)** → **얹기(fork→스튜디오)** → 새 트랙 녹음 → **공개** → 피드 상단에 내 곡 **슬라이드인**.

## 9. 컷/게이트
- **P0(데모):** 피드(최신/인기) · 좋아요 · 들어보기 · 얹기(fork) · 빈/로딩/오류 상태.
- **게이트:** 신고/차단(심사 전 필수 — 데모엔 버튼/숨김 UI까지) · 소셜프루프 시드 · 상세 시트 고도화.
