## 5. TDS 컴포넌트 매핑 (05 TDS Mapping)

비게임 미니앱은 TDS 적용이 검수 필수다(공식문서 근거). 자체 theme.css 컴포넌트를 TDS Mobile UI Kit으로 치환하되, 악기·연주 전용 컴포넌트는 TDS에 없어 자체 유지한다. 매핑 상세는 [화면명세서 ★.2](하모니_피그마_화면명세서.md)가 기준이며 요약은 아래.

| 자체(theme.css) | TDS 컴포넌트 | 처리 |
|---|---|---|
| `.appbar` | Navigation (큰 제목은 Top) | 교체 |
| `.btn` 주 CTA | Button | 교체 |
| 하단 고정 CTA(저장·공유·합주) | BottomCTA | 교체 |
| `.card` + InfoRow 리스트(설정·곡 목록) | ListRow (+ 섹션 ListHeader) | 교체 |
| `.segment/.seg`(코드/멜로디·최신/인기) | Tab | 교체 |
| 텍스트(display/title/body/cap) | Paragraph | 교체 |
| 상태 라벨(녹음 중·준비됨) | Badge | 교체 |
| `.chip/.chip-ghost`(얹기·적용·전체보기) | Button(weak/small) 또는 자체 | TDS 전용 Chip 미확인 |
| BottomSheet·Toast | UI Kit 확인 후 매핑 | 있으면 교체, 없으면 자체 |
| **InstrumentPad·PianoKeyboard·NotePadGrid·ChordMatrix·CameraBlock·BeatIndicator·TrackAvatar·PianoRollCanvas·NoteBlock·EditToolbar** | **TDS 없음 → 자체 유지** | TDS Screen/Navigation 안에 배치 |

> ⚠️ 실측 주의(이 인계서의 정직 고지): 현재 **코드 저장소에는 TDS import가 0건**이다. `package.json`에 `@toss/tds-mobile` 의존성 선언은 있으나(이는 `@apps-in-toss/web-framework` ≥1.0용 **올바른** TDS 패키지명이다 — 구버전 `@toss-design-system/mobile`은 <1.0용), **코드에서 import 0건**으로 미적용이고, 실제 화면은 자체 `theme.css`로 렌더된다(TDS가 토스 WebView 밖에서 런타임 throw 하므로 웹 배포본에서 제거). 따라서 위 TDS 매핑은 **Figma 디자인 정본의 치환 계획**이며 **코드 적용은 미완(계획)**이다. 출처: [화면설계서.md §디자인 기준](화면설계서.md), [화면명세서 ★.1](하모니_피그마_화면명세서.md). Open Question — 검수 전 TDS 실제 적용 여부·범위 결정 필요.
