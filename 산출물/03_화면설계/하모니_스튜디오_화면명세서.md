# 스튜디오 풀스튜디오 화면 명세서

## 개요

하모니 스튜디오의 풀스튜디오 화면(②~⑤) 합본 명세서다. 코드 탭(28코드)·멜로디(피아노/기타/베이스)·드럼·트랜스포트·커뮤니티 진입점을 한 문서에서 정의한다.

상태: **구현 완료(2026-06-22, TASK-20260622-030).** 처음에는 "곽소정=UI만, 오디오 엔진=김민혁 선행" 전제로 작성됐으나, 조장(이상혁) 승인으로 곽소정이 UI와 오디오 엔진 v2까지 단독 구현했다. 실제 구현·파일·검증(build/test PASS, vitest 58/58)은 [구현 내역](../05_개발설계/하모니_스튜디오_구현내역.md)에 있다. 이 문서는 화면별 동작·상태·입력 계약 기준으로 유지하고, 코드/엔진 세부는 중복하지 않고 구현 내역을 참조한다.

설계 전제:
- 범위는 B안(전부 구현). 공통 셸·트랜스포트·코드 탭·멜로디·드럼·커뮤니티 진입점을 모두 만든다.
- UI는 입력 표면(패드·건반·콤보·트랜스포트)과 상태 표시를 담당하고, 모든 연주 입력은 엔진 공개 API를 거쳐 `NoteEvent`로 발생한다. 입력 표면은 `NoteEvent` 타입을 정의하지 않고 `audio/events.ts`에서 import만 한다.
- 커뮤니티 페이지 본체는 조장(이상혁)이 구현한다. 스튜디오는 진입점과 핸드오프 계약만 제공한다.
- 스타일 = 화면 동일·소리만 다름. 스타일 콤보 선택은 DOM 재배치 없이 `setVoice(instrument, style)` 한 콜로 수렴한다.

구현 후 추가된 항목(조장 승인): 실제 악기 샘플 음원(합성 폴백)·코드 통일 옥타브·한 손/양손 제스처·2D 드럼킷·음 편집 피아노롤(드래그)·개발자 모드·전체화면 가로 회전·카메라 줌/전후면 전환. 상세는 구현 내역 §3~§7.

선행 계약(v1→v2)으로 표시했던 항목은 모두 해소됐다. 경과는 [부록 A](#부록-a--v1v2-경과-해소됨)에 남긴다.

## SCR-ST-00 · 풀스튜디오 공통 셸

### 목적
코드/멜로디/드럼 하위 화면을 감싸는 상단 고정 셸. `[코드|멜로디]` 세그먼트를 계승하고, `[악기 ▾][스타일 ▾]` 콤보를 항상 표시로 둔다.

핵심 계약:
- 모드 토글은 본문(코드/멜로디)만 스왑하고 트랜스포트/녹음 바는 유지한다.
- 악기 선택은 본문 레이아웃을 바꾸지만(건반↔6줄↔4줄↔드럼 패드), 스타일 선택은 화면 변화 없이 소리만 바꾼다. 둘 다 `setVoice(instrument, style)` 한 콜로 수렴한다.

### 레이아웃
- **상단(고정 appbar):** 좌측 '스튜디오' 타이틀, 우측 '홈' 진입점(`go('home')`).
- **셸 헤더 2단:**
  - 1단: `[ 코드 | 멜로디]` 모드 세그먼트(좌우 50:50, `.segment/.seg/data-on` 재사용).
  - 2단: `[악기 ▾]`(피아노/기타/베이스/드럼) + `[스타일 ▾]`(악기 종속 2값) 가로 2콤보, 항상 표시.
- **중단(스크롤):** `children` 슬롯 = 모드/악기별 본문(SCR-ST-02~05).
- **하단(고정 푸터):** SCR-ST-01 트랜스포트 바를 sticky 고정. 세로 WebView에서 본문만 스크롤, 푸터 비스크롤.

### 컴포넌트
- **ModeToggleSegment**: `[ 코드 | 멜로디]` 2-세그먼트. `playMode`(`'chord'|'melody'`) 전환. 멜로디 전환 시 코드모드 제스처가 켜져 있으면 `selectTouch()`로 정리한다. 모드 전환은 `setVoice`를 재호출하지 않는다(악기/스타일 불변). 녹음 중 토글도 허용하되, 전환 직전 진행 중인 sounding을 `allOff()`로 끊고 `active=null`. 악기=drum이면 토글 dimmed(드럼은 코드/멜로디 무관).
- **InstrumentCombo**: 악기 드롭다운. 값=`Instrument`(`piano`/`guitar`/`bass`/`drum`, 라벨 피아노/기타/베이스/드럼, 이모지 ///). 음색 바텀시트 패턴. 선택 시: (1) `instrument` 갱신→본문 레이아웃 결정, (2) 스타일 콤보를 해당 악기 `styleOptions`로 재구성 후 첫 값 리셋, (3) `ensureAudio()` 후 `setVoice(instrument, style)`, (4) 짧은 미리듣기(피아노/기타/베이스=`downChord('C','touch')`→600ms `upChord('C','touch')`, 드럼=`triggerHit('kick','touch')`). 녹음 중 변경 시 토스트 차단.
- **StyleCombo**: InstrumentCombo 종속. `styleOptions`: piano=`['grand'(그랜드),'electric'(전자)]`, guitar=`['acoustic'(통기타),'electric'(일렉)]`, bass=`['precision'(프레시전),'jazz'(재즈)]`, drum=`['analog'(아날로그),'electronic'(전자)]`. 선택 시 화면 변화 없음, 콤보 라벨만 갱신, `ensureAudio()` 후 `setVoice(instrument, style)` 한 콜. DOM/패드/레이아웃 재배치 금지. 녹음 중 차단.
- **BodySlot**: 모드별 본문 마운트 지점. `playMode==='chord'`→SCR-ST-02, `'melody'`→`instrument`에 따라 SCR-ST-03(피아노)/SCR-ST-04(기타·베이스)/SCR-ST-05(드럼). 본문은 입력 UI만, 이벤트는 `audio/events.ts` 계약으로 발생.
- **AppBarEntry**: 우측 상단 '홈' 진입점. 커뮤니티 진입은 SCR-ST-01 하단 칩에서 처리. 토스 WebView 자체 뒤로가기는 두지 않고 appbar 내 명시 네비게이션만 둔다.

### 상태표
| 상태 | 동작 |
|---|---|
| 정상(idle) | 모드 세그먼트·악기/스타일 콤보 활성. 콤보는 현재 라벨 표시. 본문은 선택 모드 UI 렌더. |
| 로딩(unlock 대기) | `ready=false`. 첫 사용자 제스처에서 `ensureAudio()`→`unlockAudio()` 1회. 완료 전 status='눌러서 소리 켜기'. |
| 빈(녹음본 없음) | `hasTake=false`. 셸 자체 정상. 재생/저장 비활성은 SCR-ST-01 소관. 헤더 영향 없음. |
| 오류(setVoice 실패) | 엔진 호출 try/catch. 실패 시 토스트 '소리를 켤 수 없어요 · 다시 시도'. 콤보 라벨을 직전 유효 값으로 롤백. |
| 권한거부(오디오) | 오디오 거부 시 토스트 '소리 권한이 필요해요'+무음 유지. 카메라 권한은 셸 콤보/토글에 불필요(코드/드럼 제스처에서만). |
| 네트워크지연 | 셸은 네트워크 비의존(`setVoice`는 로컬). 영향 없음. |
| 녹음중(countin/recording) | 모드 토글 허용(소리 끊고 전환), 악기/스타일 콤보 비활성+탭 시 토스트 차단(트랙=한 악기). 콤보 dimmed. |

### 인터랙션표
| 트리거 | 결과 | 발생 이벤트 | 엔진 API |
|---|---|---|---|
| `[코드]/[멜로디]` 세그먼트 탭 | `playMode` 전환, 본문 스왑. 진행 중 sounding `allOff`·`active=null`. `setVoice` 미호출. | 없음(입력 모드 전환은 NoteEvent 아님) | 진행 중이면 `allOff()` |
| 악기 콤보 항목 선택 | `instrument` 갱신→본문 레이아웃 변경, 스타일 콤보 첫 값 리셋, 미리듣기 1회. 녹음 중이면 차단 토스트. | 미리듣기에 한해 chord(C) on/off 또는 drum kick hit(녹음 중 아닐 때만, 버퍼 미기록) | `setVoice(instrument,style)`; 미리듣기 `downChord/upChord` 또는 `triggerHit` |
| 스타일 콤보 항목 선택 | style 라벨만 갱신, 화면 변화 없음. 녹음 중이면 차단 토스트. | 없음(또는 선택적 짧은 미리듣기, 버퍼 미기록) | `setVoice(instrument,style)` |
| 우측 상단 '홈' 탭 | `go('home')` 라우팅. | 없음 | 전환 전 `allOff()` 권장 |

### UX 가드
- 악기/스타일 둘 다 항상 표시·`instrument→style` 종속 갱신(악기 바꾸면 스타일 첫 값 리셋).
- 스타일 변경은 화면 변화 없음이 핵심 · DOM 재배치 금지, `setVoice` 한 콜만.
- 녹음 중 악기/스타일 변경 차단(트랙=한 악기). dimmed + 토스트.
- 모드 토글 시 잔류음 방지(`allOff`). 토스 WebView 세로·핀치줌 off·자체 뒤로가기 금지.
- 첫 소리 전 `ensureAudio()`(`unlockAudio` 1회) · 콤보 선택도 사용자 제스처로 간주해 unlock 트리거.

## SCR-ST-01 · 트랜스포트/녹음 바

### 목적
공통 셸 하단에 sticky 고정되는 연주 제어 바. 트랜스포트(메트로놈/녹음/재생)와 `transport.ts`(BPM 100, 4/4, `onBeat` 카운트인 판정, `curTick`)를 묶는다. 구성: `[메트로놈][녹음○(카운트인 4·3·2·1)][▶재생][‖정지]` + 파형 + 'n분 mm초 녹음 중' + 하단 보조 칩. 정지 시 녹음본을 자동저장하고 새 악기 녹음을 준비한다.

### 레이아웃
- **1행 트랜스포트:** `[ 메트로놈]`(토글, metroOn 시 파랑/인셋) · `[● 녹음]`(idle)/`[■ 정지]`(busy) · `[▶ 재생]`(`hasTake && !busy`일 때만 활성) · `[‖ 정지]`(재생/합주 정지).
- **2행 상태:** 박자 도트 4개 + 파형(WaveformMeter) + 'n분 mm초 녹음 중' 타이머(recording 시).
- **3행 보조(가로 스크롤 칩):** `[ 다른 사람 음원 가져오기]`(=`receive`) · `[ 악기 추가]`(현재 트랙 자동저장+새 악기 준비) · `[ 다른 사람 음원 구경 가기]`(→커뮤니티 진입점).

### 컴포넌트
- **MetronomeToggle**: `[ 메트로놈]`. `toggleMetro` 계승: `ensureAudio` 후 `metroOn` true→`startMetronome()`, false→idle이면 `stopMetronome()`+`beat=-1`. 녹음 중 끄면 클릭만 멈추고 Transport 유지(`phase==='idle'`일 때만 실제 stop). `data-on` 시 파랑+`e-inset`.
- **RecordButton**: `[● 녹음]`↔`[■ 정지]` 단일 버튼(`busy=phase!=='idle'`). idle에서 누르면 `phase='countin'`+`startMetronome()`. `onBeat`이 `bar>=1` 도달 시 `stateRef` 초기화+`recordStart=transportSeconds()`+`phase='recording'` 승격. 재탭 시 `allOff()`+sounding=null, recording이었으면 `hasTake=events.length>0`, `phase='idle'`, `metroOn` 아니면 `stopMetronome`+`beat=-1`. 정지(녹음→idle) 시 AutoSaveOnStop 트리거 후 새 악기 준비.
- **CountInOverlay**: `phase==='countin'` 동안 본문 위 풀스크린 카운트. 표시 숫자=`BEATS_PER_BAR-(beat<0?0:beat)` → '4·3·2·1'. 카운트인 동안 입력 패드는 살아있되 녹음 버퍼는 `bar>=1` 전까지 미기록(`curTick`은 recording에서만 >0). 큰 숫자+토스 블루, 매 박 펄스.
- **PlayButton**: `[▶ 재생]`. `disabled={!hasTake||busy}`. 누르면 `ensureAudio`→`allOff`→sounding=null 후 버퍼(`events`)를 `tickToMs`로 `setTimeout` 스케줄 재생. `NoteEvent.kind` 판별로 chord=`downChord/upChord`, melody=`downNote/upNote`, drum=`triggerHit` 분기. 재생 중 status='재생 중'.
- **StopButton**: `[‖ 정지]`. 예약 `setTimeout` 취소(timer id 배열 정리)+`allOff()`+합주 보이스 `dispose`(`stopJam`). 녹음 정지와 구분.
- **WaveformMeter**: 파형. recording 중 입력 이벤트(on/off)와 엔진 출력 레벨을 막대/라인으로 시각화. 엔진 분석 노드가 없으면 `NoteEvent` on/off 타임라인 기반 의사 파형(이벤트 밀도)로 대체. idle=평탄선, recording=활성, playing=진행 커서.
- **RecordTimer**: 'n분 mm초 녹음 중'. recording 진입 시점(`recordStart`) 기준 `transportSeconds()` 경과로 표기(벽시계 ms 금지, Transport 초 사용 · DL-019). 형식: 분=`floor(sec/60)`, 초=2자리. recording 외에는 셸 status 텍스트.
- **AutoSaveOnStop**: recording→정지 전이 시 `events.length>0`이면 `saveSong({id:newSongId(), name:'내 곡 N', bpm:BPM, events, createdAt:Date.now()})`(`saveCurrent` 계승)→토스트 '저장됨'. 저장 후 `stateRef=initialChordState`로 events 비우고 `hasTake` 재계산. `TrackMeta(instrument/style)`를 곡 메타에 함께 기록(트랙=한 악기).
- **AuxActions**: 하단 보조 칩 3개. `[ 가져오기]`=`receive`(클립보드 코드→`getSession`→`confirmReceive` fork). `[ 악기 추가]`=현재 events 자동저장 후 새 악기 준비(합주 세션이면 `addTrack` 얹기). `[ 구경 가기]`=커뮤니티 라우팅(진입점만).

### 상태표
| 상태 | 동작 |
|---|---|
| 정상(idle) | 녹음=`[● 녹음]`, 메트로놈 토글 가능. `hasTake`면 ▶재생 활성. status='준비됐어요'. 파형 평탄. |
| 로딩(unlock 대기) | `ready=false` → status='눌러서 소리 켜기'. 녹음/재생/메트로놈 첫 탭이 `ensureAudio()` 트리거. |

## SCR-ST-02 · 코드 탭 (28코드 매트릭스 + 빠른 프리셋)

### 목적
7행(C,D,E,F,G,A,B)×4열(maj,m,7,m7)=28코드 매트릭스에서 최대 6개를 골라 연주 패드를 구성하고, `[터치|제스처]` 하위탭으로 연주한다. 빈 화면 이탈을 막기 위해 빠른 팝 4코드(C·Am·F·G) 프리셋을 크게 제공한다. 모든 연주 입력은 `downChord/upChord`로 `kind:'chord'` `NoteEvent`를 발생시킨다.

### 레이아웃
- **상단:** 공통 셸(모드 토글 + 악기/스타일 콤보).
- **중단(스크롤):** (a) 빠른 프리셋 바(`[C·Am·F·G]` 큰 버튼 + '내 코드 직접 고르기 ▾') → (b) 28코드 매트릭스(7×4, 토글 선택, 우상단 'n/6' 카운터, 기본 접힘) → (c) `[터치|제스처]` 하위탭 → (d) 선택 코드 연주 패드(터치=그리드 / 제스처=카메라 프리뷰 + 존 오버레이, 제스처 ON 시 패드 dimmed).
- **하단:** SCR-ST-01 트랜스포트.

### 컴포넌트
- **PresetBar**: 빈화면 이탈 방어(가드 2). '기본 팝 4코드' 라벨 + 큰 버튼 4개 `[C][Am][F][G]`(48dp+ 높이, 한 줄, 로마숫자 부제 I·vi·IV·V). 우측 `[내 코드 직접 고르기 ▾]`. 탭 시 `selected=[C,Am,F,G]` 즉시 세팅→ChordPad 바로 연주 가능. ChordMatrix는 기본 접힘. 색상=`ACCENT` 맵(C 블루/Am 퍼플/F 그린/G 코랄).
- **ChordMatrix**: 7행×4열 토글 선택. 칸 라벨은 `NoteEvent.chord` 식별값과 1:1(예: 5행3열='G7'). 헤더: 열 `[maj|m|7|m7]`, 행 `[C|D|E|F|G|A|B]`. 우상단 '선택 n/6'. 칸 탭=토글. 선택칸은 굵은 보더+체크. 6개 상태에서 7번째 탭=거부 + 토스트 '코드는 최대 6개까지 선택할 수 있어요'(2s). 해제는 항상 허용. 선택 순서 보존(push/filter)하여 ChordPad·제스처 매핑 순서로 사용. 칸 44dp+ 터치 타깃.
- **InputSubTab**: `[ 터치 | 제스처]`. 제스처 선택=`ensureAudio()`→`initHandTracking()`→`startCamera()` 순서, 성공 시 `input='gesture'`로 전환하고 ChordPad를 dimmed+`pointer-events:none`(가드 3). 권한 거부/실패 시 `input='touch'` 폴백 + 안내 '카메라를 쓸 수 없어 터치로 연주해요'. 터치 선택=제스처 루프 정지(`cancelAnimationFrame`)+`stopCamera`+`upChord(...,'gesture')`로 잔향 정리. `selectTouch/selectGesture` 재사용.
- **ChordPad**: 선택된 코드(1~6개)만 연주 버튼으로 노출. 터치 레이아웃: 개수별 그리드(1~2=1열, 3~4=2열, 5~6=2~3열). `onPointerDown`→`ensureAudio()` 후 `downChord(chord,'touch')`; `onPointerUp/Leave`→`upChord(chord,'touch')`. 눌린 패드 `data-on` 하이라이트. 제스처 레이아웃: 4:3 카메라 프리뷰(`scaleX(-1)` 미러) 위 존 오버레이(좌→우). rAF 루프 `detect()`로 `zone/open` 판정 → `open && zone!=null`이면 `downChord(selected[zone],'gesture')`, 아니면 `upChord(...,'gesture')`. 일반 모드는 앞 4존, 전체화면은 6존을 매핑한다(구현 내역 §5). 제스처 ON일 때 터치 그리드는 렌더하되 dimmed.
- **Toast**: 일시 알림(2s, 하단 중앙, `flashToast` 재사용). 케이스: 6초과/카메라 거부/제스처 한도/드럼+코드탭/네트워크.

매트릭스 외 코드 색상은 `ACCENT`(4코드)만 정의되어 있어, 나머지는 `SIG` 팔레트 순환으로 채운다(UI 결정, 엔진 무관).

## SCR-ST-03 · 멜로디 · 피아노 건반

### 목적
멜로디 모드의 기본 입력기. 피아노 한 옥타브(흰건반 도~도 8키 + 검은건반 5키)를 개별음으로 연주·녹음한다. 화면은 스타일과 무관하게 동일하며, `instrument='piano'`일 때 노출. 모든 음 입력은 `kind:'melody'` note 이벤트(`downNote/upNote`)로 발생.

### 레이아웃
- **상(공통):** 모드 토글 + 악기/스타일 콤보 + 박자 도트·status.
- **중(이 화면):** MelodyKeyboard · 가로 풀폭 1옥타브. 흰건반 8개(도 레 미 파 솔 라 시 도) 균등 flex, 그 위에 검은건반 5개(도# 레# 파# 솔# 라#)를 흰건반 경계에 absolute 오버레이(미↔파, 시↔도 사이는 없음). 흰건반 높이 ~220px, 검은건반 ~62% 높이·좁은 폭. 멜로디에는 `[터치|제스처]` 하위탭 없음(피아노는 터치 전용).
- **하(공통):** SCR-ST-01 트랜스포트.

### 컴포넌트
- **MelodyKeyboard**: `props: { active: string|null, onDown:(note)=>void, onUp:(note)=>void, disabled?:boolean }`. 데이터: `WHITE=[['C4','도'],['D4','레'],['E4','미'],['F4','파'],['G4','솔'],['A4','라'],['B4','시'],['C5','도']]`, `BLACK=[['C#4','도#',0],['D#4','레#',1],['F#4','파#',3],['G#4','솔#',4],['A#4','라#',5]]`(3번째=왼쪽 흰건반 인덱스). 흰건반: `flex:1`, `borderRadius '6px 6px 14px 14px'`, 평상 white→#eef1f4 그라데이션·`--key-dark` 글자, 눌림 `--blue` 그라데이션·#fff·`--e-inset`. 검은건반: `position absolute`, `left=(afterIndex+1)/7*100%` 기준 -폭/2, `width≈흰건반폭*0.6`, `height 62%`, `#2a2f36→#111` 그라데이션, 눌림 `--blue` 계열, `z-index 2`. 계이름 라벨은 건반 하단.

- **CommonTopBar(재사용)**: 멜로디 진입 시 `selectTouch()`로 제스처 루프 정리(`onClick={()=>{selectTouch();setPlayMode('melody')}}`). 콤보 변경 시 `setVoice` 호출만, 레이아웃 불변.
- **CommonTransport(재사용)**: 멜로디 녹음도 동일. 녹음 시작 시 `instrument/style`을 `TrackMeta`에 1회 기록.

## SCR-ST-04 · 멜로디 · 기타/베이스 계이름 패드 블록

### 목적
`instrument`가 guitar/bass일 때의 멜로디 입력 표면. 실제 지판(프렛+줄) 대신 계이름 패드 블록(기타 6행/베이스 4행 가로 그리드, 각 칸=계이름)으로 팻핑거를 회피한다. 입력 경로는 SCR-ST-03과 동일한 note 경로(`downNote/upNote`, kind:'melody')를 재사용하고, 콤보 값(`setVoice`)만으로 소리를 기타/베이스로 바꾼다. 화면은 줄 수만 다르고 동일 구조.

칸 음정은 크로매틱(한 칸=반음)으로 구현됐다(일반 6프렛 / 전체화면 13프렛, 가로 스크롤, 개방현=실제 튜닝). 초안의 다이아토닉 오프셋(0/+2/+4/+5/+7)은 채택하지 않았다 · 부록 A 참조.

### 레이아웃
- **상(공통):** 모드 토글 + 콤보.
- **중(이 화면):** NotePadGrid · 가로 그리드. 기타=6행(개방현 E2 A2 D3 G3 B3 E4), 베이스=4행(E1 A1 D2 G2). 각 행 왼쪽에 개방현 라벨, 행 내부는 계이름 칸 가로 나열. 행/칸 모두 큰 터치 타깃.
- **하(공통):** 트랜스포트.

### 컴포넌트
- **NotePadGrid**: `props: { instrument:'guitar'|'bass', active:Set<string>, onDown:(note)=>void, onUp:(note)=>void, disabled?:boolean }`. 데이터: `STRINGS_GUITAR=['E2','A2','D3','G3','B3','E4']`, `STRINGS_BASS=['E1','A1','D2','G2']`. 각 줄 칸은 개방현부터 반음씩 누적(크로매틱), 칸 수=일반 6 / 전체화면 13. 각 칸 note=개방현 음을 칸 인덱스만큼 반음 올린 음(예 E2 +1 = F2). 그리드: `gridTemplateRows=줄 수`, 첫 열=개방현 라벨. 칸 스타일 평상 `--surface`+`e2`, 눌림 `--blue`+`e-inset`. 줄간 gap 8~10px, 칸 최소 높이 ~44px.
- **OpenStringLabel**: 각 행 첫 열 개방현 표기. 개방현=영문 줄이름(E·A·D·G·B·E / E·A·D·G) + 작게 옥타브(E2 등), 칸 내부=한글 계이름(도·레…및 #). 줄이름은 관례상 영문(EADGBE)이 표준이라 직관적이고, 칸 계이름은 피아노(SCR-ST-03)와 한글로 통일.
- **InstrumentRowSwitch**: guitar↔bass 전환 시 줄 수(6↔4)만 바뀌고 구조·스타일 동일. 스타일 콤보(통기타/일렉, 프레시전/재즈)는 화면 불변·`setVoice` 인자만.
- **CommonTopBar / CommonTransport(재사용)**: SCR-ST-03과 동일. 녹음 시작 시 instrument(guitar|bass)·style을 `TrackMeta`에 1회 기록.

칸→note 문자열 변환은 엔진 무관 유틸 `lib/notes.ts`로 분리해 단위테스트로 검증한다(구현 내역 §4·§11, `notes.test`). 곽소정은 줄 인덱스+칸 인덱스를 이 유틸에 넘기고 `audio/**`는 수정하지 않는다.

### 상태표
| 상태 | 동작 |
|---|---|
| 정상(idle) | 6행/4행 그리드 표시, 칸 터치 시 발음. status '준비됐어요'. |
| 로딩(언락 전) | 첫 칸 터치에서 `ensureAudio()` 후 발음. |
| 빈(empty take) | ▶재생 disabled, 저장 숨김. 그리드 항상 연주 가능. |
| 녹음중(recording) | 칸 입력이 note 이벤트 적재. status 'n분 mm초 녹음 중'(coral·굵게). 정지 시 자동저장 후 새 악기 준비. |
| 카운트인 | 메트로놈 1마디, '카운트인 n'. 입력 발음. |
| 오류/권한거부(오디오) | unlock 실패 시 토스트·무음. 카메라 무관(기타/베이스 패드는 제스처 미사용). |
| 네트워크지연 | 연주/녹음 로컬·무관. 합주 영역만 공통 하단. |

### 인터랙션표
| 트리거 | 결과 | 발생 이벤트 | 엔진 API |
|---|---|---|---|
| 패드 칸 `onPointerDown` | 줄 개방현+반음 오프셋으로 계산된 단일음 발음, active에 note 추가 | `{kind:'melody',tick,phase:'on',note:'F2'…,source:'touch'}` | `ensureAudio()`→`downNote(note,'touch')` |
| 패드 칸 `onPointerUp/Leave`(눌린 칸) | 발음 종료, active에서 제거 | `{kind:'melody',tick,phase:'off',note,source:'touch'}` | `upNote(note,'touch')` |
| 개방현 라벨(첫 열) 탭 | 줄 개방현 음 발음(칸 step=0와 동일) | `{kind:'melody',tick,phase:'on'|'off',note:openNote,source:'touch'}` | `downNote(openNote,'touch')`/`upNote` |

### UX 가드
- 실제 지판(프렛/줄 시각) 금지 · 계이름 패드 블록만(팻핑거 회피, 본 화면 존재 이유, 가드 1).
- 기타=6행·베이스=4행 가로 그리드. 칸=계이름. 칸 최소 ~44px.

- 스타일은 화면 동일·소리만 · 콤보 값을 `setVoice`로 전달하는 것 외 분기 금지.
- 기타/베이스 패드에는 제스처 미연결(제스처는 코드/드럼 한정, 가드 3).
- `audio/**` 미수정: `setVoice/downNote/upNote` + `events.ts` import만. 음 변환은 `lib/notes.ts`까지.

## SCR-ST-05 · 드럼 (터치 4분할 패드 + 제스처 드럼킷)

### 목적
드럼 입력 화면(코드/멜로디 무관, `instrument='drum'`일 때 진입). 터치=4분할 패드(kick·snare·hat·crash), 제스처=드럼킷(zone→piece). 원샷 이벤트 `{kind:'drum', phase:'hit', piece}`를 `triggerHit(piece,source)`로 발생. 곽소정은 입력 UI + 이벤트 발생까지를 담당한다(재생·합성은 엔진).

> 구현은 8피스 드럼킷(크래시·하이햇·라이드·하이탐·미드탐·스네어·킥·플로어탐)으로 확장됐다(구현 내역 §3). 본 명세의 4분할(kick·snare·hat·crash)은 최소 입력 계약이다.

### 레이아웃
- **상(공통, 모드 토글 dimmed):** 콤보(스타일=아날로그/전자).
- **중:** `[터치|제스처]` 하위탭 + (터치) 4분할 패드(kick·snare·hat·crash) 큰 타깃, 패드별 시그니처 컬러·hit 시 글로우/scale + (옵션) 8스텝 비트그리드(시각 참고만). (제스처) 카메라 PIP + 드럼킷 zone 오버레이(존→piece 라벨).
- **하(공통):** 트랜스포트.

### 컴포넌트
- **DrumPad(터치)**: 패드 그리드, 칸=kick·snare·hat·crash(구현은 8패드 2열). `onPointerDown`→`triggerHit(piece,'touch')` 원샷(지속 없음, down만). 탭 피드백 80ms scale+글로우(경량). 큰 터치 타깃(≥56px).
- **GestureDrumKit(zone→piece)**: 제스처 하위탭. 카메라 PIP + 드럼킷 zone 오버레이. `detect()` zone→piece. 타격 모션 1프레임=원샷 hit(엣지 검출, 연속 프레임 중복 hit 방지 · 손 빠짐/재진입 시 1회만). 존 라벨에 piece명.
- **BeatGridStrip(시각 참고, 경량)**: 8스텝 그리드. 입력 hit를 스텝에 점등(시각 피드백·녹음 가독). 시퀀서 편집 아님(원샷 입력 기록 표시만). 경량 SVG/캔버스.
- **DrumInputSubTab**: `[터치|제스처]`. 제스처 선택 시 카메라 init, 실패 시 터치 폴백+camMsg.

### 상태표
| 상태 | 동작 |
|---|---|
| 정상(터치) | 4분할 패드 활성. 탭마다 원샷 hit. 비트그리드 점등. |
| 정상(제스처) | 카메라 PIP + zone 드럼킷. zone 진입 타격=원샷 hit. 터치 패드 dimmed(단일 입력). 중복 hit 방지(엣지 트리거). |
| 권한거부(카메라) | 제스처 init 실패 → camMsg '카메라를 쓸 수 없어 터치로 연주해요' + 자동 터치 폴백, 하위탭 터치로 강제. |
| 녹음중 | 하위탭 잠금, 패드/존만 활성. hit→tick 기록(phase:'hit' 원샷). RecTimer·파형 표시. |

### 인터랙션표
| 트리거 | 결과 | 발생 이벤트 | 엔진 API |
|---|---|---|---|
| 드럼 패드 탭(터치) | 해당 타악기 원샷 재생 + 피드백 | `{kind:'drum',tick,phase:'hit',piece:'kick'|'snare'|'hat'|'crash',source:'touch'}` | `triggerHit(piece,'touch')` |
| 제스처 zone 타격 | zone→piece 원샷(엣지 트리거 1회) | `{kind:'drum',tick,phase:'hit',piece,source:'gesture'}` | `triggerHit(piece,'gesture')` |
| 하위탭 `[제스처]` 선택 | 카메라 init·드럼킷 오버레이·터치 dimmed. 실패 시 터치 폴백. | 없음 | `initHandTracking()`/`startCamera()` |
| 스타일 콤보(아날로그/전자) 변경 | 드럼 음색만 변경·화면 동일 | 없음(TrackMeta 갱신) | `setVoice('drum',style)` |

### UX 가드
- 드럼은 원샷 · `phase:'hit'`만(on/off 없음). 지속음·중복 hit 금지(제스처는 엣지 트리거).
- 제스처 ON 시 터치 패드 dimmed(단일 입력, 스레드 충돌·이벤트 꼬임 방지, 가드 3).
- 재생/합주 로직은 `audio/**`(엔진) · 곽소정은 입력 UI + `triggerHit` 이벤트 발생까지.
- 비트그리드는 가벼운 시각 점등만(시퀀서 편집 미포함).
- 입력 계약 piece는 kick·snare·hat·crash 4종이 최소이며, 구현 드럼킷은 8피스로 확장된다(구현 내역 §3).

## SCR-ST-06 · 공유/음원추가 진입점 (→ 커뮤니티 페이지)

### 목적
스튜디오에서 커뮤니티(곡목록·들어보기·가져오기(fork)·얹기)로 가는 진입점. 커뮤니티 페이지 본체는 조장(이상혁)이 구현한다, 본 명세는 스튜디오 측 진입 버튼/핸드오프 계약과 '다른 사람 음원 가져오기'(클립보드 자동 인식 → 얹기) 동선만 정의한다. 합주 재생은 트랙별 `TrackMeta`대로 `createVoice(instrument,style)`로 음색을 복원한다.

### 레이아웃
별도 풀스크린 아님 · 셸 하단 트레이의 진입 버튼 2종 + 합주 세션 카드(조건부, `sessionCode` 존재 시).
- `[ 다른 사람 음원 가져오기]`=클립보드 코드 자동 인식→받기 바텀시트(미리듣기·얹기).
- `[ 다른 사람 음원 구경 가기]`=커뮤니티 라우팅.
- JamSessionCard: 코드·트랙수·트랙 아바타(`.track-av` 시그니처 컬러)·`[ 합주 듣기]`·`[ 얹기]`.

### 컴포넌트
- **BrowseCommunityButton**: `[ 구경 가기]` → `go('community')`(라우트 진입만). 페이지는 조장 구현. 라우트 미구현 시 토스트 '곧 열려요' 폴백 가능. 곽소정은 진입점·복귀 동선만.
- **ReceiveAudioButton**: `[ 가져오기]` → 클립보드 코드 인식(`readClipboardCode`), 실패 시 `PRELOAD`/수동 붙여넣기 폴백 → 받기 바텀시트('○○님 트랙을 복사했어요')→`[내 연주에 얹기]`(`confirmReceive`). 받을 트랙 없으면 토스트 '받을 트랙이 없어요'.
- **JamSessionCard(조건부)**: `sessionCode` 존재 시. 세션명(`baseOwner` 있으면 'OOO님과 합주')·코드·트랙수·트랙 아바타. `[ 얹기]`=`overdub()`(`hasTake&&!busy`). `[ 합주 듣기]`=`playSession()`(트랙별 `createVoice(instrument,style)`로 재생, 아바타 펄스, 최대길이+1.5s 후 자동 정지).
- **ReceiveSheet**: pending 트랙 미리보기(이니셜·코드·트랙수). `[내 연주에 얹기]`=`confirmReceive()`(원본복사 새세션 fork: base.events를 내 `stateRef`로 복사, sessionCode/baseOwner/sessionTracks 세팅, `hasTake=true`). `[닫기]`=pending 해제.
- **ForkPreviewRow(커뮤니티 핸드오프 계약, 조장 참고)**: 커뮤니티 곡 항목: 제목·제작자·길이·들어보기(▶)·가져오기(fork). fork=해당 트랙 events+`TrackMeta`를 스튜디오로 로드해 새 레이어로 얹기 준비.

| 상태 | 동작 |

### 인터랙션표
| 트리거 | 결과 | 발생 이벤트 | 엔진 API |
|---|---|---|---|
| `[구경 가기]` 탭 | 커뮤니티로 라우팅(본체=조장). 복귀 시 스튜디오 상태 유지. | 없음 | `go('community')` |
| `[음원 가져오기]` 탭 | 클립보드 코드 인식→받기 시트→얹기 준비(base.events 로드). | 없음(트랙 로드) | · (share.ts `getSession`) |
| 받기 시트 `[내 연주에 얹기]` | 원본 events를 내 `stateRef`로 복사(fork), 세션 참여, `hasTake=true`. | 없음 | · (`confirmReceive` 상태 전이) |

### UX 가드
- 얹기=원본복사 새세션 fork(원본 불변, 내 트랙으로 복제).
- 합주 재생은 트랙별 `TrackMeta`대로 `createVoice(instrument,style)`로 음색을 복원한다.
- `getSession` 실패는 `PRELOAD` 폴백으로 데모 지속, polling 실패는 무음 무시.
- 커뮤니티 본체는 조장 담당 · 곽소정은 진입/연결 UI만.
- 공유/받기/얹기는 네트워크 의존, 로컬 연주·녹음은 무관 항상 동작.

> 합주 듣기는 단일 트랙 음색 복원 경로까지 구현했고, 여러 트랙 동시 재생은 현재 합성 음색으로 동작한다(샘플 미적용, 후속 · 구현 내역 §10). 초안에서 "음색 복원 불가" 사유였던 `TIMBRES` 임의배정과 chord-only 재생 경로는 해소됐다(부록 A).

## 공통 계약

### 이벤트 계약 (NoteEvent · `audio/events.ts`에서 import)

입력 표면은 아래 타입을 직접 정의하지 않고 `audio/events.ts`에서 import해 이 타입의 이벤트만 발생시킨다. 와이어/저장 형식은 백엔드 무수정을 위해 레거시 `{tick,phase,chord,source}` 모양을 유지하며, 드럼은 `chord:'drum:piece'`로 흐른다. 레거시(kind 없음)는 `normalizeEvents`가 chord로 해석한다(구현 내역 §2).

```ts
// audio/events.ts (엔진 v2, 입력 표면은 import만)
export type Source = 'touch' | 'gesture';
export type Instrument = 'piano' | 'guitar' | 'bass' | 'drum';
export type Style =
  | 'grand' | 'electric'        // piano
  | 'acoustic'                  // guitar (electric은 piano와 공유 라벨)
  | 'precision' | 'jazz'        // bass
  | 'analog' | 'electronic';    // drum
export type ChordId =
  | 'C'|'Cm'|'C7'|'Cm7' | 'D'|'Dm'|'D7'|'Dm7' | 'E'|'Em'|'E7'|'Em7'
  | 'F'|'Fm'|'F7'|'Fm7' | 'G'|'Gm'|'G7'|'Gm7' | 'A'|'Am'|'A7'|'Am7'
  | 'B'|'Bm'|'B7'|'Bm7';        // 28종
export type DrumPiece = 'kick' | 'snare' | 'hat' | 'crash';

export type NoteEvent =
  | { kind: 'chord';  tick: number; phase: 'on' | 'off'; chord: ChordId; source: Source }
  | { kind: 'melody'; tick: number; phase: 'on' | 'off'; note: string;  source: Source } // note='C4'|'C#4'…
  | { kind: 'drum';   tick: number; phase: 'hit';        piece: DrumPiece; source: Source };

// instrument/style은 이벤트가 아니라 트랙 메타(녹음=한 악기)
export interface TrackMeta { instrument: Instrument; style: Style; }
```

`Style`의 `electric`은 piano(전자)·guitar(일렉)에서 라벨이 다르지만 값을 공유한다. 콤보 라벨 매핑은 InstrumentCombo가 담당한다.

### 엔진 공개 API

| API | 시그니처 | 용도 |
|---|---|---|
| 음색 설정 | `setVoice(instrument: Instrument, style: Style): void` | 악기/스타일 콤보 변경 시 1콜 |
| 코드 누름 | `downChord(chord: ChordId, source: Source): void` | 코드 패드/제스처 down |
| 코드 뗌 | `upChord(chord: ChordId, source: Source): void` | 코드 패드/제스처 up |
| 음 누름 | `downNote(note: string, source: Source): void` | 피아노/기타/베이스 패드 down |
| 음 뗌 | `upNote(note: string, source: Source): void` | 패드 up |
| 타악기 | `triggerHit(piece: DrumPiece, source: Source): void` | 드럼 원샷 |
| 합주 보이스 | `createVoice(instrument: Instrument, style: Style): Voice` | 합주 재생(트랙별 음색) |
| 전체 정지 | `allOff(): void` | 모드/재생 전환·정지 시 잔류음 정리 |

v2 API는 엔진(`audio/engine.ts`)에 구현됐고 v1 export(`chordOn/chordOff/setTimbre` 등)는 무파괴 보존된다(구현 내역 §2). 입력 표면은 v2 API만 호출한다.

1. **계이름 패드(지판 금지):** 기타/베이스는 실제 지판 대신 계이름 패드 블록. 팻핑거 회피, 소리만 기타/베이스. → SCR-ST-04.
