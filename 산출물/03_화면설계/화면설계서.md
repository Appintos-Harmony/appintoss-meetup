# 화면 설계서 (하모니)

과제 필수 산출물(CLAUDE.md §9)의 화면설계서 인덱스다. 화면별 상세는 아래 명세서를 단일 출처로 둔다(중복을 피하고 여기서는 구성과 링크만 유지).

## 화면 구성

| 화면 ID | 화면 | 상세 명세 |
|---|---|---|
| SCR-00 | 스플래시·온보딩(닉네임·getAnonymousKey) | [하모니_화면명세서](하모니_화면명세서.md) |
| SCR-HOME | 홈 허브(스튜디오/커뮤니티 카드·이어하기) | [하모니_화면명세서](하모니_화면명세서.md) |
| SCR-ST-00~06 | 스튜디오(악기 선택·코드 매트릭스·멜로디·드럼·녹음/재생·음 편집) | [하모니_스튜디오_화면명세서](하모니_스튜디오_화면명세서.md) |
| SCR-C01~04 | 커뮤니티(목록·공유·받기·얹기) | [하모니_커뮤니티_화면명세서](하모니_커뮤니티_화면명세서.md) |
| SCR-SET | 설정·개발자 모드 | [하모니_화면명세서](하모니_화면명세서.md) |

## 공통 상태

각 화면 명세서에 정상·로딩·빈 상태·오류·권한(카메라)·네트워크 지연 상태를 화면별로 기술한다. 토스 내비게이션과 중복되는 자체 뒤로가기 UI는 두지 않는다(§12).

## 디자인 기준

라이트 테마 100%(DL-019). TDS는 토스 WebView 밖에서 런타임 throw가 있어 웹 배포본에서는 제거하고 자체 `theme.css`를 쓴다. 색·간격·모션·컴포넌트는 토스 앱 톤을 따른다.

## MVP 범위

최소/확장 구분은 [MVP_스코프_최소_확장](MVP_스코프_최소_확장.md)을 따른다. 현재는 곽소정 원안 전체(풀버전, DL-022)를 구현했다.
