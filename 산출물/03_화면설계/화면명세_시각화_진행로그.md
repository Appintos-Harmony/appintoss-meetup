# 화면명세 시각화(스케치→와이어프레임→목업) 진행 로그

> 팀장(이상혁) 요청: **발표·보고용 화면 명세서**를 **스케치 → 와이어프레임 → 목업** 3단계로, **현재 브랜치(develop) as-built 기준**으로 시각화. 이 로그는 작업 보류 시점의 핸드오프다.

## 목표 충실도 (사용자 제공 레퍼런스 이미지)
산출물 그림은 사용자가 보여준 레퍼런스 이미지 수준의 **토스 스타일 고충실 목업**으로. 레퍼런스 = 4화면 가로 나열:
1. **온보딩(최초 1회)** — 음표 로고(토스블루 라운드 사각) + "하모니" + 카피 "토스에서 악기를 연주하고, 친구와 한 곡을 완성해요" + 닉네임 인풋("토스밴드") + 안내 "가입·로그인 없어요…" + 파란 '시작하기' 버튼.
2. **홈 허브 · 첫 방문(곡 0)** — 앱바(하모니/기어) + "안녕하세요, 토스밴드님" + "첫 트랙을 녹음해볼까요?" + 스튜디오 카드(파랑 강조·마이크 아이콘) + 커뮤니티 카드(사람 아이콘) + "이어하기 — 곡 0개라 섹션 숨김".
3. **홈 허브 · 재방문(곡 3)** — 인사 + "이어서 만들어볼까요?" + 스튜디오/커뮤니티 카드(가로 2열) + 이어하기 리스트(내 곡 3/2/1, 코드칩 C·G·Am, "2시간 전/어제/3일 전").
4. **설정 시트(바텀시트)** — "닉네임 변경" / "이용약관·개인정보처리방침" / "데이터·익명키 삭제(빨강)" / "앱 버전 1.0.0".

특징: 흰 배경, 토스블루 #3182f6, 깔끔한 아웃라인 아이콘(기어·마이크·사람·문서·휴지통), 코드칩, 둥근 카드, 라이트 테마 100%.

## 확정된 양식
- 화면당 **3패널(스케치 / 와이어프레임 / 목업)**, 모바일 프레임 가로 나열.
- 스케치=러프 배치(아웃라인·색없음) / 와이어=구조·계층·라벨(회색) / 목업=레퍼런스 수준 고충실.
- 홈 허브 3패널 **샘플 위젯**으로 양식 방향 제시함(채팅 인라인, 파일 아님).
- **목업 콘텐츠 = 코드 as-built 기준(날조 금지)**. 충실도(룩앤필)만 레퍼런스 수준.

## 보류된 결정 (재개 시 먼저 확정)
- **범위:** 핵심 4화면(스플래시·온보딩·홈·스튜디오) / 전체 7화면 / 데모 동선만 — **미정**.
- **산출 형식:** ⓐ 화면별 3단계 SVG 파일을 `산출물/03_화면설계/`에 저장 + 마크다운 명세서 임베드 / ⓑ 인라인 미리보기 위주 / ⓒ 한 장 종합 보드 — **미정**.
- (AskUserQuestion으로 위 2개 물었으나 사용자가 중단하고 타 작업 전환.)

## as-built 주의 — 레퍼런스(의도) vs 코드(현 구현) 차이 ★재개 시 확인
- **설정:** 레퍼런스엔 "닉네임 변경"·"데이터·익명키 삭제"가 있으나, 현 `Settings.tsx`는 닉네임 **읽기전용**·개발자모드 토글·법적고지 "준비 중"·"홈으로"만 구현(닉네임 변경/데이터 삭제 **미구현**). 버전은 "1.0.0" 하드코딩(package.json은 0.0.0). → 목업을 as-built로 그릴지, 레퍼런스(의도)대로 그릴지 확인.
- **홈 빈상태(곡 0):** as-built는 "아직 녹음한 곡이 없어요" 빈 카드 표시(Home.tsx:70-78). 레퍼런스 "곡 0개라 섹션 숨김"과 표현 차이 — 확인.
- **온보딩 착지:** 코드는 홈 직행(App.tsx:31). (구 명세 §A는 스튜디오 직행이라 stale.)
- 상세 화면별 as-built 구성요소는 [화면명세_구현대조_갭분석.md](화면명세_구현대조_갭분석.md) §4 제안 명세 참조.
