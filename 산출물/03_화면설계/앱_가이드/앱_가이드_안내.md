# 하모니 앱 가이드 — 전체 기능 도움말 세트

> 발표·온보딩·제출용 **화면별 도움말 세트**. 커뮤니티 가이드 스타일(폰 목업 + 번호 콜아웃 ①~⑥ + 단계 설명 + 핵심 루프 띠)을 앱 전체 기능에 적용했다. **as-built 화면 기준(2026-06-23)** 이라 실제 `apps/miniapp`과 일치한다.
> 각 가이드는 **SVG(벡터 원본, 정본)** 와 **PNG(2x 래스터, 슬라이드·공유 편의용)** 로 제공한다.

## 가이드 목록
| 순서 | 화면 | 파일 | 담은 내용 |
|---|---|---|---|
| 00 | 전체 흐름 | `00_전체흐름.svg` / `.png` | 시작 → 홈 → 스튜디오 → 커뮤니티 전체 여정 + 핵심 루프 |
| 01 | 홈 | `01_홈.svg` / `.png` | 스튜디오(새 곡)·커뮤니티(둘러보기·얹기)·이어하기·설정 진입 |
| 02 | 스튜디오 | `02_스튜디오.svg` / `.png` | 녹음·메트로놈·코드/멜로디/드럼·재생바·레이어 추가/제거·합주 반복·이름 지어 저장·올리기 |
| 03 | 커뮤니티 | `03_커뮤니티.svg` / `.png` | 올리기·들어보기(재생바)·담기·합주해서 올리기(출처)·좋아요·신고 |
| 04 | 설정 | `04_설정.svg` / `.png` | 이모지 프로필·닉네임·버전·개발자 모드·법적 고지 |

## 비고
- 폰 목업·콜아웃·단계 카피는 **실제 화면(as-built)** 기준. 03 커뮤니티는 `../커뮤니티_이미지/커뮤니티_도움말_가이드`와 동일본을 세트에 포함한 것이다.
- 00·01·02·04는 커뮤니티 가이드를 템플릿으로 멀티에이전트 초안 → 사람/Claude 검수(렌더 확인)로 확정했다.
- **PNG는 resvg(시스템 폰트, 2x)로 렌더**. 일부 도구 이모지(⚙️·🛠 등)는 PNG에서 단순화되어 보일 수 있으며, 정확한 표현은 SVG가 기준이다.
- 기능 정의: [커뮤니티 기능명세서 v4](../../05_개발설계/하모니_커뮤니티_기능명세서.md). 화면 정의: 화면명세서·스튜디오/커뮤니티 화면명세서(as-built 절).
