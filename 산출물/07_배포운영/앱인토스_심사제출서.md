## 2. 제품 설명 (심사 제출용)

하모니는 사용자가 악기 음색(피아노·기타·베이스·드럼)을 고르고 코드·멜로디·드럼을 연주·녹음한 뒤, 친구가 공유한 트랙 위에 자기 악기를 얹어 비동기로 한 곡을 완성하는 음악 창작 도구다. 입력은 터치와 카메라 손 제스처(MediaPipe) 중 택1이며, 합주는 공유 코드 + 1.5초 폴링으로 처리한다(실시간 세션 아님). 자체 로그인·회원가입은 없고 토스 익명 식별과 닉네임만 사용한다.

기능 정본은 [서비스 기능정의서](../01_서비스기획/서비스_기능정의서.md)(FR-ID-01 ~ FR-JAM-01), 사용자 흐름은 [PRD](../01_서비스기획/제품요구사항정의서_PRD.md) 2절을 따른다. 여기서는 중복하지 않는다.

## 4. 사용자 식별·인증

- 토스 로그인·자체 로그인·소셜 로그인 모두 미사용. 비게임 전용 `getAnonymousKey`로 미니앱별 고유 익명키를 받고, 닉네임 1회 입력만 받는다(DL-016, 근거목록 #2~#4).
- `getAnonymousKey`는 클라이언트 식별용이며 서버 인증 토큰이 아니다(근거목록 #4). 공유·합주 엔드포인트는 입력 검증으로 보호한다([PRD](../01_서비스기획/제품요구사항정의서_PRD.md) 6절).
- ⚠️ **제출 전 차단(미해소):** `apps/miniapp/src/lib/identity.ts`의 `getUserKey()`는 현재 mock fallback(`anon_…`)이다. 실제 `getAnonymousKey` 호출로 교체해야 한다. 작업 `TASK-20260622-033`([배포 실행절차서](배포_실행절차서.md) D절). — 상태: **미완료**.

## 5. 권한 요청 (카메라)

| 권한 | 사용 목적 | 선언 위치 | 실기기 확인 |
|---|---|---|---|
| 카메라 | 손 제스처로 코드 연주(FR-PLAY-02). 라이브 스트림은 표준 Web API `getUserMedia` 사용 | granite.config `permissions: [{ name: 'camera', access: 'access' }]` | 부분 |

- 마이크는 요청하지 않는다(소리는 앱이 생성, 외부 녹음 없음).
- 위치·앨범·연락처·클립보드 쓰기 권한 미요청(클립보드는 공유 코드 복사 용도로 표준 Web API 사용).
- 카메라 거부 시 터치 입력으로 자동 폴백한다(FR-PLAY-02, 동시 바인딩 금지).
- 실기기 근거: 2026-06-21 S23 Ultra 토스 샌드박스에서 카메라 권한 허용·프리뷰 표시 확인. 손 추적·제스처 매핑은 미검증([실기기 검수표](../06_테스트/앱인토스_실기기검수표.md) RT-04~06).
