# 배포 실행 절차서 (하모니)

> 백엔드는 **배포 완료**. 미니앱 토스 배포는 사람/팀 단계.

## A. 백엔드 (AWS Ubuntu) — ✅ 완료
실행 결과(DL-021): Ubuntu 26.04 · Node 24.17 · systemd `harmony-api`(:8080) + `nginx`(TLS) + `certbot.timer`(자동갱신). 외부+브라우저 왕복 검증.
- **고정 HTTPS:** `https://3.39.167.74.nip.io` (nip.io + Let's Encrypt). AWS 보안그룹 80·443 오픈.
- 재배포(코드 변경 시): `apps/api`를 서버로 scp → `bash deploy/deploy.sh` → `sudo systemctl restart harmony-api`.
- 절차/스크립트: [apps/api/README.md](../../apps/api/README.md) · `apps/api/deploy/`(deploy.sh·nginx-harmony-api.conf·harmony-api.service).
- ⚠️ SSH 키(pem)는 저장소 미반영(DL-021). 노출 키 로테이션 권장.

## B. 미니앱 (토스 앱인토스) — 사람/팀 단계
> `ait deploy`는 **토스 콘솔 로그인 + 앱 등록**이 필요해 AI가 단독 실행 불가. 절차:

1. **앱 등록:** 토스 개발자 콘솔에서 **harmony 앱 등록**(현재 `granite.config.ts` appName=`meetup-lite` 임시). DL-018 주제 확정 후 진행.
2. **백엔드 URL 주입:** `apps/miniapp/.env`의 `VITE_API_BASE=https://3.39.167.74.nip.io` 확인.
3. **로그인:** `cd apps/miniapp && ait login`(브라우저 인증).
4. **빌드:** `ait build` (또는 `npm run build`).
5. **배포:** `ait deploy` → 토스 콘솔에서 심사 제출.
6. **샌드박스 선검증:** 배포 전 `granite dev` + 실기기([실기기검수표](../06_테스트/앱인토스_실기기검수표.md)) 통과 권장.

## C. URL/롤백
- cloudflared quick tunnel(`harmony-tunnel.service`)은 **백업**(현재 disable). nip.io 장애 시 `sudo systemctl enable --now harmony-tunnel` 후 로그의 URL을 `.env`에 반영·재빌드.
- 인증서 갱신은 `certbot.timer` 자동. 수동: `sudo certbot renew`.
- 백엔드 롤백: 이전 `server.mjs`로 교체 후 `systemctl restart harmony-api`. SQLite 파일(`/opt/harmony-api/data/harmony.db`) 백업 권장.
