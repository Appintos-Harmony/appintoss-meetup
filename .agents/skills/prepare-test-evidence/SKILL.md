description: 테스트·검증 실행 결과를 재현 가능한 증거로 정리하고 증거 목록에 연결할 때 사용한다.
---

테스트 증거는 실행하지 않으면 만들지 않는다(CLAUDE.md §15.4).

1. 실행한 명령을 원문 그대로 기록한다(셸·인자 포함).
2. 각 테스트에 대해 기록한다: 테스트 ID, 관련 요구사항 ID, 환경, 사전 조건, 절차, 기대 결과, 실제 결과, Pass/Fail, 실행자, 실행 일시, 로그·스크린샷 경로, 결함 ID.
3. 실행하지 못한 항목은 `Not Run`, 접근 불가는 `Not Available`로 표기한다. 추정으로 Pass를 쓰지 않는다.
4. 로그·스크린샷은 경로로 연결하고 `평가증빙/테스트증빙_목록.md`에 행을 추가한다.
5. 완료율은 `완료 수 / 전체 수`로만 적는다.
6. 비밀값·실제 개인정보를 증거에 포함하지 않는다.
