---
name: verify-change
description: Claude Code 또는 다른 구현자의 diff를 독립 검증하고 회귀·권한·예외·테스트 누락을 찾을 때 사용한다.
---

1. 관련 작업지시서와 수락 기준, 요구사항 ID를 읽는다.
2. diff와 관련 코드를 확인한다.
3. 점검: 정상 경로, 객체 단위 권한, 중복 요청, 정원·경쟁 조건, 오류 응답 일관성, 데이터 일관성, 개인정보·삭제 경로, 문서·테스트 누락.
4. 가능한 검증 명령을 실행한다. 실행 못 하면 `Not Run`, 접근 불가는 `Not Available`.
5. 발견 사항을 P0~P3으로 분류하고 재현 절차·관련 파일을 남긴다.
6. 직접 수정이 요청되지 않았다면 리뷰 중 코드를 바꾸지 않는다.
7. 결과는 `독립검토서`(REVIEW-…) 형식으로: 판정(Accept/Accept with Conditions/Rework/Reject), 수락 기준별 결과, 발견 사항, 실행 명령, 남은 위험, 사람 승인 질문. 증거 없으면 `검증 불가`.
