## 4. 어떻게 작업하나 (행동 1건 = 1 TASK)

- 합의가 사는 곳: `산출물/09_AI개발파이프라인/독립검토서/`(REVIEW-…) + `산출물/00_프로젝트관리/의사결정_기록.md`(DL-…).

- 커밋: 자동(conventional 메시지). 헬퍼 `커밋.mjs`는 `--path`로 파일을 명시 스테이징한다(`--all`은 옵트인). 푸시는 사람 허락이 있어야 하고 `main` 직접 push는 금지(PR).
