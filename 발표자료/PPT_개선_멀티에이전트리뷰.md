## 1. 한 줄 총평 + 가장 큰 3가지 문제

**총평:** 엔지니어링 자산(Loop·Harness·AI 교차검증)은 다른 팀이 못 보여줄 실물 수준인데, 슬라이드가 (1) 자기 성과를 **구버전 수치로 과소 보고**하고 (2) 교수 최강조 **Loop/Harness를 전용 슬라이드 없이 도구 나열로** 흘려 점수를 스스로 깎고 있다. 추정 78~82점 → stale 정정 + Loop/Harness 승격 시 88~92점.

1. **Stale 수치가 "정직성"을 자랑하는 발표를 자기모순에 빠뜨림.** "12/12 통합"은 실제 34/34(`통합테스트_결과서.md:19`)와 충돌하는데 대형 스탯으로 노출. "실기기 미완·토스 콘솔 단계·appName 미변경"도 실제(실기기 9건 Pass·테스트 트랙 출시 완료·appName=harmony)와 어긋남. **틀린 수치 하나가 58/58·7/7 같은 진짜 증거까지 의심으로 오염시킨다.** 교수가 결과서를 펴면 즉시 드러나는 단일 최대 리스크.
2. **교수 1순위 Loop/Harness 전용 슬라이드가 없음.** 자산은 실재(`루프_가드.mjs:115-177` 종료코드 강제, `검증_전체.mjs:18-35` 11검사, `loop-engineer.md:8-16` 10스테이지)인데 '루프'라는 단어조차 없다. 25% 배점 핵심을 못 담음.
3. **정보 밀도 과부하 + 후반 레이아웃 단조.** 도형 30개+ 슬라이드 다수(특히 AI 도구활용 슬라이드가 가장 빽빽한 아이러니), 여러 슬라이드가 '상단 스텝+좌 박스+우 스탯+하단 배너' 동일 골격 반복.

## 3. 신규 슬라이드 — Loop Engineering (AI 도구활용 앞 삽입)

**제목:** Loop Engineering — 코드가 강제하는 자율 엔지니어링 루프 1바퀴

핵심 3줄:
1. `loop-engineer` 한 번 호출 = Ready 작업 1건을 10스테이지로 처리하고 **AI Review에서 사람 대기로 멈춘다.** 푸시·머지·배포는 루프 밖(비협상). — `.claude/commands/loop-engineer.md:8,11-16,77-79`
2. 안전 게이트는 프롬프트 재량이 아니라 **종료코드로 강제** — STOP(10: main/detached/Ready아님/레이스), 범위위반(11: allowed_paths·forbidden·보호구역·무게이트 코드), 반복 캡(12: 상한 20). — `루프_가드.mjs:115-135,153-177`
3. 검증→실패→수정→재실행 실증: 1차 빌드에서 자동 게이트가 **사람 눈 전에 구현오류 2건을 차단.** — `평가증빙/루프실행_로그/2026-06-23_TASK-20260623-010.md`

다이어그램(생성→검증→수정→재생성 원형):
```
SELECT → PREFLIGHT(가드 GO/STOP 10) → IMPLEMENT(allowed_paths)
  → VERIFY(검증_전체 --code: tsc+vitest) ─[FAIL]→ REPAIR(≤2) → 재VERIFY
  → CHECK-DIFF(가드 GO/STOP 11) → COMMIT(green만) → REVIEW(Codex) → STOP(사람 대기)
```
각 노드에 종료코드 뱃지. 캡션: "게이트 FAIL이면 커밋 안 함 → revert·보고."

## 4. 신규 슬라이드 — Harness Engineering (Loop 뒤)

**제목:** Harness Engineering — git을 메시지 버스로 쓰는 자동화 평가 하네스

핵심 3줄:
1. 단일 오케스트레이터 `검증_전체.mjs`가 검사들을 **AND 게이트로 묶어 종료코드 1개로 접는다**(hardFail 1건이면 전체 FAIL). 기본/--strict/--code 3모드. — `검증_전체.mjs:18-35,60-61`
2. 검사: 비밀값·내부링크·산출물(필수 15종)·작업지시서(**구현자==검토자면 차단**)·팀공유문서·코드(tsc+vitest). git 훅 백스톱: pre-commit(비밀값)·pre-push(main 차단).
3. 그 위 3에이전트(CLAUDE/AGENTS/CHATGPT_PRO)가 **git 문서(TASK·REVIEW·diff)를 메시지 버스로** 상호검증 — 구현 AI ≠ 검토 AI를 코드로 강제.

시각: 3층 스택(상 사람승인 3조건 AND / 중 검증_전체→검사 6칸 / 하 git훅 2개) + 우측 콜아웃 "AI는 자기 권한·게이트를 못 넓힌다".
