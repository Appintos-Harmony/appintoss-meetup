# 발표 대본 — Loop · Harness · 에이전트 (비전공자도 이해하는 쉬운 설명)

> 교수님 1순위(Loop·Harness)와 "에이전트를 어떻게 만들었나"를 **비유로 쉽게** 말하는 대본. 슬라이드 12·13·14에서 그대로 읽어도 된다. 모든 내용은 저장소 근거(file:line) 기반.

## 슬라이드 12 — Loop Engineering
**한 줄 비유:** 공장 자동 라인에 빨간 비상정지 스위치를 단 것처럼, AI가 선을 넘으려 하면 사람이 아니라 **코드**가 라인을 즉시 멈춘다.

**대본(30~40초):**
"이 그림은 AI가 일하는 모습을 공장 자동 라인에 비유한 겁니다. AI는 한 번에 딱 한 가지 일만 맡아서, 왼쪽부터 오른쪽으로 단계를 밟습니다. 만들고, 검사하고, 틀리면 스스로 고치고, 통과해야만 다음으로 넘어가죠. 핵심은 이 안전장치가 '부탁'이 아니라 '코드'라는 점입니다. 검사 프로그램이 합격이면 0, 불합격이면 정해진 숫자를 내고, 불합격이면 다음 단계가 아예 안 돌아갑니다. AI가 말을 안 들어도 라인이 멈추는 거죠. 그리고 서버 배포나 코드를 합치는 일은 AI가 절대 못 하고, 빨간 벽에서 무조건 사람을 기다립니다. 실제로 이 검사가, 자기 자신을 잘못 건드린 AI의 실수까지 잡아낸 기록이 남아 있습니다."

**핵심 3줄:**
1. AI는 한 번에 한 가지 일만 — 고르고→검사(타입·테스트·문서)→틀리면 고치고→통과해야 다음. 이 한 바퀴가 '루프'.
2. 안전장치가 '말'이 아니라 '코드' — 검사가 합격(0)/불합격(숫자) 신호를 내고, 불합격이면 다음 단계가 실행 안 됨.
3. AI가 절대 못 하는 3가지: 배포·코드 합치기·작업 폴더 밖 수정 → 여기서 멈추고 사람 대기. 검사가 AI의 실수 2건을 사람보다 먼저 잡은 기록 있음.

## 슬라이드 13 — Harness Engineering
**한 줄 비유:** AI가 낸 답안을 사람이 받기 전에, 6개의 자동 채점기가 한꺼번에 검사하고 '전부 만점'이어야만 통과시키는 시험장.

**대본(30~40초):**
"AI는 빠르지만 가끔 틀립니다. 그래서 저희는 AI가 낸 결과물을 사람이 받기 전에 자동으로 채점하는 '시험장'을 만들었습니다. 명령어 하나를 실행하면 여섯 가지 검사가 한꺼번에 돕니다. 비밀번호가 코드에 섞이지 않았는지, 문서 링크가 깨지지 않았는지, 필요한 산출물이 다 있는지, 그리고 코드가 실제로 컴파일되고 테스트를 통과하는지까지요. 핵심은 여섯 개가 '전부' 합격해야만 통과한다는 겁니다. 하나라도 빨간불이면 멈춥니다. 특히 '만든 AI'와 '검사하는 AI'가 같으면 기계가 자동으로 불합격시켜서, 자기 답안을 자기가 채점하는 일을 막습니다. 저장하고 올릴 때도 안전망이 한 번 더 잡아주고, 같은 검사가 GitHub 서버에서도 자동으로 다시 돕니다."

**핵심 3줄:**
1. 한 번에 6가지 검사(비밀값·링크·산출물·작업기록·팀문서·코드 컴파일+테스트)가 동시에, **모두 합격(AND)**이어야 통과.
2. '만든 AI'와 '검사한 AI'가 같으면 자동 불합격 — 자기 답 자기 채점 금지.
3. 안전망 2겹(저장 전 비밀값 차단·메인 직접 반영 차단) + 같은 검사를 GitHub 서버에서도 재실행.

## 슬라이드 14 — 에이전트를 어떻게 만들었나
**한 줄 비유:** 한 명의 만능 AI 대신, 회사처럼 11개 직무로 쪼개 각자 '업무 매뉴얼' 한 장씩 쥐여줬다.

**대본(30~40초):**
"저희는 만능 AI 한 명에게 다 시키지 않았습니다. 회사가 사람을 뽑을 때 직무기술서를 주듯, AI에게도 직무기술서를 써줬습니다. 마크다운 문서 한 장에 '네 역할은 화면 설계, 쓸 수 있는 도구는 이것, 지켜야 할 규칙과 절대 하면 안 되는 일은 이것'을 적어 한 명의 담당자를 만듭니다. 이렇게 11명을 만들었고, 합주앱이라 '피아노 음원 담당' 같은 전용 전문가도 넣었습니다. 자주 반복하는 일은 '업무 절차서(스킬)'로 빼서 — Claude용 7개, Codex용 3개 — 다음에 또 그대로 꺼내 씁니다. 핵심은 셋입니다. 역할은 나누고, 절차는 재사용하고, 최종 결정은 항상 사람이 합니다."

**핵심 3줄:**
1. 에이전트 = 마크다운 1파일(직무기술서) — 역할·허용 도구·규칙·금지를 글로 정의. 코딩이 아니라 글쓰기로 AI 팀원 생성.
2. 필요할 때 담당자만 호출해 분업(화면=UX, 서버=백엔드, 검사=QA). 합주앱이라 피아노 음원 전용 전문가도 추가.
3. 3층: 역할 에이전트 11 / 재사용 스킬(Claude 7 + Codex 3) / 도구·MCP. 같은 일은 절차서 재사용. AI는 승인자가 아님.
