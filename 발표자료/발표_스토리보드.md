# 발표 스토리보드 (PPT 제작 전 흐름 정리)

발표는 6월 26일 14:00. 이 문서는 PPT를 만들기 전에 발표 흐름·메시지·증거를 한 번에 정리한 것이다. 발표·시연이 평가의 50%라서 여기서 막히면 점수가 깎인다. 제품은 하모니(harmony) — 앱인토스 위에서 도는 악기 합주 미니앱이다.

## 1. 발표 제목
- 주: **"하모니 — 혼자도 합주, 코드로 합주"**
- 부: 악기를 쌓아 한 곡을 만들고, 공유 코드로 남의 연주 위에 얹는 앱인토스 미니앱

## 2. 발표 목표
- 평가 4축(발표/산출물/AI 활용/배포 가산)을 한 흐름으로 보여준다.
- 제품이 실제로 돈다는 걸 라이브로 보여준다. HTTPS 배포가 끝났으니 목업이 아니라 진짜 화면으로 한다.
- AI 활용은 "많이 썼다"가 아니라 역할 분리·독립검토·사람 승인이 git에 추적된다는 걸 증거로 보여준다.

## 5. 슬라이드별 상세

### S1. 표지 (20초)
- 핵심 메시지: 제목 + 팀(4인) + 한 문장 소개.
- 화면: Toss 블루 배경, 앱 로고/아이콘, 부제 1줄.
- 증거: [README](../README.md). 미확정: 팀 최종 슬로건.

### S2. 문제 (40초)
- 핵심 메시지: 합주는 사람·장소·악기가 동시에 맞아야 해서 혼자서는 못 한다. 악기를 다룰 줄 몰라도 합주에 끼기 어렵다.
- 화면: 모이기 어려운 합주 상황 vs 혼자 악기를 쌓아 완성한 한 곡 대비.
- 증거: [PRD](../산출물/01_서비스기획/제품요구사항정의서_PRD.md) §1.

### S3. 해결 / 제품 (50초)
- 핵심 메시지: 피아노·기타·베이스·드럼을 터치와 카메라 제스처로 연주하고, 트랙을 쌓아 혼자 합주를 만든다. 코드 매트릭스(C~B × maj/m/7/m7)로 코드를 모르는 사람도 반주를 깐다.
- 화면: 악기 4종 + 코드 매트릭스 + 멀티트랙 레이어 화면.
- 증거: PRD §2·§3. 미확정: 최종 UI 세부.

### S4. 핵심 사용자 흐름 · 시연 (60~90초)
- 핵심 메시지: 연주 → 녹음 → 공유 → 얹기 → 합주 듣기. 코드 한 줄로 남의 연주를 받아 그 위에 내 악기를 얹는다.
- 화면: 코드 매트릭스로 반주 녹음 → 멜로디 건반/지판으로 한 트랙 추가 → 피아노롤에서 빨간 재생위치선 드래그로 음 편집 → 공유 코드 생성 → 코드로 가져와 드럼 얹기 → 트랙별 악기로 합주 재생.
- 시연: 배포 URL(https://3.39.167.74.nip.io)에서 라이브. 백업: 화면 녹화·스크린샷.
- 증거: PRD §2. 합주는 공유 코드 + 1.5초 폴링 기반(실시간 협연 아님)이라는 점을 분명히 말한다.

### S5. 설계 (50초)
- 핵심 메시지: 무의존 백엔드 + 정적 프론트 + nginx 리버스프록시의 단순 구조. 합주 데이터는 트랙(owner·events·instrument·style) 단위로 서버에 저장하고 공유 코드로 묶는다.
- 화면: 구성도 — vite 빌드 정적 파일(/opt/harmony-web) + node:http API(:8080) + node:sqlite, nginx가 정적 서빙과 /api 프록시를 동시에 한다.
- 결정·근거: 의존성 제로(node:http + node:sqlite, Node 24)로 가져간 건 7일 안에 배포·유지보수 부담을 줄이려는 선택. 합주는 1.5초 폴링으로 처리 — 실시간 소켓을 빼서 구현·운영을 단순화했다. 엔드포인트는 /healthz, POST /sessions, GET /sessions/:code, POST /sessions/:code/tracks 4개.
- 증거: [시스템 구성도](../산출물/04_시스템설계/시스템_구성도.md), [테이블 정의서](../산출물/04_시스템설계/테이블_정의서.md).

### S6. 품질 (50초)

- 화면: vitest 통과 캡처, 통합테스트 결과, 배포된 HTTPS 화면.
- 증거·수치: vitest 7파일 58개 통과(chordReducer·poly·events·tuning·noteEdit·notes·loop), 통합 34/34 (API 12·보안 7·클라 6·실기기 9; 2026-06-25 재실행, 커밋 c13b818). 실기기 9건은 S23 Ultra 사람 육안 성공(증빙 사진 9장 EV-201~209/IT-RT-02~12, Figma 화면설계서에 보관: https://www.figma.com/design/AeH33UjgzpSj4FDl98pFoT/). 배포 = AWS EC2 Ubuntu 26.04, nginx + systemd harmony-api(:8080) + Let's Encrypt(certbot), https://3.39.167.74.nip.io 가동 중.
