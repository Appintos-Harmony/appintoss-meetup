# 하네스 소개 슬라이드 (개요)

> 학과 공유·발표용 5분 구성안. 상세는 [하네스_소개](../산출물/09_AI개발파이프라인/하네스_소개.md).

1. **문제**: AI는 빠르지만 틀린다. "AI가 했으니 믿어라"로는 점수가 안 나온다. 오류·문서 불일치·검증 누락을 누가 잡는지가 핵심이다.
2. **3에이전트 하네스**: ChatGPT Pro는 통제(작업지시·독립검토·출시판정), Claude Code와 Codex는 실행(구현·검증), 사람은 승인. 구현자와 검토자를 다른 모델로 분리했다. 통제면 ChatGPT Pro는 **실제 별도 모델**이다, Claude Code가 작업지시·검토 프롬프트를 작성하면 사람이 ChatGPT Pro(및 Gemini Pro)에 입력해 독립 판정·4-AI 토의를 받았다(산출물은 토론기록 DEBATE-011·013). 여기에 더해 **Claude Code ↔ Codex 이종(異種) 교차검토**는 실행 로그·REVIEW로 증명된다 · 구현한 모델과 다른 계열 모델이 결함을 잡는다.
3. **흐름**: 작업지시서 → 구현 → 자동 검증 → 다른 계열 AI 독립검토 → 합의 → 사람 승인 → 커밋/머지 → 다음 작업에 재사용. 대화 기억이 아니라 git 문서를 메시지 버스로 쓴다.
4. **증거**: 독립검토서(REVIEW) 28건(006~054), git 이력, 자동 검증 PASS.
   - 실사례 ① TASK-010(커밋 헬퍼): **Claude Code 구현**의 경로 우회(pathspec magic) 결함을 **Codex 독립검토**가 NO-GO로 잡아냄 → 수정 → 재검토 → 사람 승인(REVIEW-20260620-011).
   - 실사례 ② TASK-009(공개 커뮤니티 보드, `Community.tsx`): Codex 독립검토가 공개 보드의 보안 결함을 No-Go(REVIEW-038)로 막고, 수정·재검토를 거쳐 보안 블랙박스 **7 PASS / 0 FAIL**로 Go(REVIEW-038 → 039 → 040)까지 끌어올림.
5. **재사용**: 새 프로젝트에 `CLAUDE.md`·`AGENTS.md`·skills·템플릿·CI 검사를 복사 → 값 치환 → git init → 검증. 반나절 세팅.
6. **결과와 한계(정직)**: AWS에 HTTPS로 배포 완료, 단위 58/58·통합 34/34(2026-06-25 재실행, 커밋 c13b818 기준; API 12·보안 7·클라 6·실기기 9). 실기기 9건은 아이폰13·S23 Ultra 2기기, 이상혁·양록빈 육안 검증(증빙 사진 9장 EV-201~209/IT-RT-02~12, Figma 화면설계서 보관). 앱인토스 2026-06-26 테스트 트랙 출시(버전 20260626-1) → 2026-06-27 정식 전체공개(프로덕션) 출시 완료(조장 이상혁 Go 승인). 잔여: 검증_전체 --strict 재측정 Not Run, POL-04 연령확인 미구현, shadow moderation 무통지, 번들 사이즈 한계, 합성 음색 폴백, TDS 부분 적용, 정식 환경 per-user 식별 검증 권장.
