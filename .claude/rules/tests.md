# 테스트 규칙 (CLAUDE.md §15)

- 테스트를 실행하지 않고 `Pass`·`통과`·`all tests pass`로 쓰지 않는다. 실행 안 한 검증은 `Not Run`.
- 결과서 필수 증거: 테스트 ID, 관련 요구사항 ID, 환경, 사전 조건, 절차, 기대 결과, 실제 결과, Pass/Fail, 실행자, 실행 일시, 로그·스크린샷 경로, 결함 ID.
- 단위 우선 대상: 모집 상태 전이, 참가 신청 중복 방지, 정원 계산, 승인·거절 권한, 주최자 취소, 날짜 검증, 안전 규칙 필수값, 사용자 삭제.
- 통합 최소 시나리오: 생성→목록→상세, 신청→승인→상태, 정원 초과 차단, 취소→정원 복구, 권한 외 수정 차단, 모임 취소 전파, 신고→운영자 처리, 삭제 요청→접근 불가, 잘못된 입력 오류 일관성, 재배포 후 데이터 유지.
- 완료율은 추정하지 않고 `완료 수 / 전체 수`로 기록한다.
- 증거 파일 경로는 `평가증빙/테스트증빙_목록.md`에 연결한다.
