# 코드 규칙 (CLAUDE.md §13.1·§14 발췌·강제 기준)

- TypeScript strict mode. `any`·무분별한 type assertion·빈 catch·무시된 Promise 금지.
- public API·도메인 경계는 명확한 타입을 가진다. 도메인 규칙을 UI 컴포넌트에 분산하지 않는다.
- 모든 mutation은 인가(객체 단위)와 입력 검증을 거친다.
- 중복 참가 신청·정원 초과를 **서버에서** 막는다. mutation은 idempotency 또는 중복 방지 전략을 가진다.
- 날짜·시간은 저장 형식과 표시 타임존을 명시한다(UTC 저장 권장).
- 에러는 사용자 메시지·운영 로그·원인 코드로 분리한다.
- 비밀값을 저장소에 넣지 않는다. 테스트용 우회 경로를 production 경로에 남기지 않는다.
- 주석은 선택 이유·도메인 불변식·앱인토스 제약·보안 주의·제거 조건이 있는 기술 부채에만. 코드를 그대로 번역하는 주석 금지.
