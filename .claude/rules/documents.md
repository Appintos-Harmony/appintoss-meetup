# 문서 규칙 (CLAUDE.md §8.1·§11)

- 산출물·발표자료·평가증빙은 한글 경로·파일명. 영문 `docs`/`presentations`/`project-evidence`·중복본 금지. 예약 영문: `apps`·`packages`·`infra`·`tooling`·`.claude`·`.agents/skills`·`CLAUDE.md`·`AGENTS.md`·`README.md`·`SKILL.md`.
- 파일명은 밑줄 구분, 금지 문자(공백·괄호·슬래시·콜론·물음표) 없음. 날짜 파일은 `YYYY-MM-DD_문서명.md`.
- 모든 주요 문서에 메타데이터(status/owner/reviewers/last_updated/related_requirements/related_adrs). owner·reviewer·승인자는 **실제 사람만**.
- 사실/가정 구분(`Assumption`·`Open Question`·`Decision Needed`). 법률 문서는 초안 표기.
- 같은 내용 복제 금지 → 기준 문서 링크. 빈 목차·장식 표현("엔터프라이즈급·완벽한·혁신적인") 금지.
- 존재하지 않는 회의·조사·수치·테스트 결과를 만들지 않는다.
- `HUMAN_APPROVAL_START`~`END` 구역은 AI가 수정하지 않는다.
- 경로 변경 시 링크·`산출물_목록`·요구사항 추적표를 같은 변경에서 함께 수정.
