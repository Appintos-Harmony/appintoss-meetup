앱인토스 관련 사양은 기억이 아니라 공식 근거로만 확정한다(CLAUDE.md §4).

1. Apps in Toss MCP 연결 여부를 먼저 확인한다. 미연결이면 멈추고 "미검증"으로 표기한다(추정 금지).
2. 확인 항목: 지원 SDK·생성도구, 비게임 출시 체크리스트, WebView 제약, 토스 로그인, 소셜·만남 분류, 개인정보·삭제, 심사 기간·제출물.
3. 공식 문서와 **설치된 패키지 타입 정의**를 함께 대조한다.
4. 확인일·문서명/URL·버전·적용 결정·담당자를 `산출물/02_정책준수/공식문서_근거목록.md`에 행으로 추가한다.
5. 불명확하면 `Open Question`으로 남기고 구현하지 않는다.
