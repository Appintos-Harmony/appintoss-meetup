---

코드만 먼저 넣고 테스트·문서를 미루지 않는다(CLAUDE.md §5 vertical slice·§21).

1. 작업지시서의 수락 기준·allowed_paths·검증 명령을 요약한다. 범위 밖 변경 금지.
2. 한 slice에 포함: 요구사항 ID, UX 상태, API 계약, DB migration, 권한 규칙, 단위·통합 테스트, 운영 로그, 문서 갱신.
3. 작은 검증 가능 단위로 구현하고 각 단계 검증 명령을 실행한다.
4. 서버 측 불변식(정원·중복·상태 전이·권한)을 테스트로 고정한다.
5. 결과를 §7.3 계약으로 반환한다(변경 파일·실행 명령·실제 결과·생략 검증·남은 위험).
6. P0 변경은 다른 계열 AI 독립 검증 + 사람 승인 전까지 완료로 표시하지 않는다.
