---

배포 준비는 AI가, 실제 실행은 사람이 한다(CLAUDE.md §16·§18 Gate 3).

1. 통합테스트 핵심 시나리오 통과와 P0·P1 0건을 확인한다(증거 링크).
2. 환경변수 검증, 빌드, staging 배포 절차를 실행 가능한 명령으로 정리한다.
3. 배포 실행절차서·롤백 계획서·출시 점검표를 채운다(실제 명령·기대 결과).
4. 배포 후 스모크 테스트 항목과 오류 급증 시 중단 절차를 정의한다.
5. 시연용 고정 데이터·계정·백업 영상 준비 상태를 점검표로 남긴다.
6. staging 검증 없는 production 배포를 준비물에 넣지 않는다. merge·tag·배포·심사 제출은 사람 승인 게이트로 표시.
