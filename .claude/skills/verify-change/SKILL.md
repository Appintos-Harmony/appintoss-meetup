---

Claude Code가 Codex 구현을 검토하는 절차다(CLAUDE.md §7.4).

1. 관련 작업지시서·수락 기준·요구사항 ID를 읽는다.
2. diff와 관련 코드를 확인한다.
3. 점검: 아키텍처 적합성, 객체 단위 권한, 입력 검증, 중복/경쟁 조건, 오류 응답 일관성, 개인정보·삭제 경로, 문서·추적성 동기화.
4. 가능한 검증 명령(typecheck·test·build)을 실행한다. 실행 못 하면 `Not Run`.
5. 발견 사항을 P0~P3으로 분류하고 재현 근거를 남긴다. 직접 수정은 요청 시에만.
6. `독립검토서`(REVIEW-…)로 판정·근거·사람 승인 질문을 반환한다.
