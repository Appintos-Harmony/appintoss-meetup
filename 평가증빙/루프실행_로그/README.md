# 루프 실행 로그 (증거 sink)

자율 엔지니어링 루프(`/loop-engineer`)가 한 바퀴 돌 때마다 이 폴더에 실행 증거를 남긴다.
보호 구역(`00_진행사항.md`·`01_인수인계.md`)이 아니라 여기에 기록하므로, 루프가 사람 승인 문서를 건드리지 않는다.

## 파일 규칙
- 파일명: `YYYY-MM-DD_TASK-…-NNN.md` (한 iteration = 한 파일).
- `_상태.json`은 런타임 반복 카운터(휘발성) · gitignore됨. 증거 아님.

## 기록 형식 (CLAUDE.md §7.3 결과계약)
각 로그는 다음을 포함한다. **검증 결과는 게이트 명령의 원문 출력을 붙인다**(지어내지 않는다).

```
- 작업 ID / 최종 status
- 확인한 입력·근거 (작업지시서·요구사항)
- 가정·미확정
- 변경 파일 (allowed_paths 안)
- 실행한 명령 (코드게이트·검증_전체·커밋 등)
- 실제 검증 결과 (원문 출력 / 종료코드)
- 실패·생략한 검증 (Not Run / Unverified)
- 남은 위험
- 커밋 SHA
- 다음 사람 확인 항목 (머지·푸시·교차검토)
```

## 무결성 규칙
- 실행하지 않은 검증은 `Not Run`, 미확인은 `Unverified`로 적는다.
- 푸시·머지·배포는 루프 범위 밖(사람 게이트). 로그는 항상 `AI Review` 상태에서 사람 대기로 끝난다.
- 독립검토 초안이 같은 세션/모델이면 `same-family-draft`로 표기한다(진짜 교차검토는 사람 구동 Codex).
